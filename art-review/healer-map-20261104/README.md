## 正式代码接入验收（2026-11-04）

入口：`integration.html`。其中界面与动画由正式 Godot 规则和渲染代码在后台 SubViewport 中生成，使用演示摆位、隔离的临时存档，没有操作用户存档或更新手机。原 `index.html` 保留设计确认记录。

- 行动菜单增加治疗 MAP，疗愈师8格、济世术师10格，均为单体。三档治疗及HP代价沿用确认表；支付后至少1HP。满血可获得强身，满血且已有完整两回合强身则拒绝并不扣费。
- 强身集中参与物防计算，不修改基础防御，不增加魔防；物理攻击、反击、战术攻击、主角物理MAP和魔剑物理反噬均生效。装备物防正常叠加。
- 施放回合N记录到期N+2，在该己方阶段开始清除，普通战斗与演习共用到期规则。图标、2/1角标、绿色物防+2同时显示于地图详情卡与完整人物详情，到期一起移除。
- 第三次使用单独的移动负荷字段，移动-2、最低1格，至下个己方回合结束；不套用主角虚脱的伤害削减。进阶不刷新每人每场三次额度。
- 确认时重算目标，一次性写入生命、次数、行动与强身后保存，再播放只读动画。存读档与回溯保留对应状态，重试及战后队伍持久化清除临时状态。
- 复用已由原作程序与本地音频模型确认的恢复起音 `rm_sfx_21`，0.30秒播放一次。动画基础1.20秒、进阶1.40秒，音效尾音不阻塞操作，无额外前后等待。

治疗专项143项、原有5个主角MAP228项、音效264项检查通过。正式截图覆盖两职业×三档、强身2/1/0、完整详情、施法代价及1280×592、844×390、512×300视口，含两职业行动菜单共120帧/图，文字安全区检查无错误。结果保存于 `integration/`，图像可见像素与透明轮廓、脚部固定、视频编码和静态页面路径另由 `tools/integration_verify.py` 验证。

后台渲染使用 `tools/integration_capture.sh`，启动前注入已验证的禁止显示/激活窗口守卫。受限环境的初次探针因默认用户日志路径权限退出，设置独立临时日志并按本机权限流程运行后渲染成功。引擎退出偶发既有8个ObjectDB／2个resource清理告警，未出现GDScript或布局错误。浏览器连接本轮返回 `browser.user is unavailable`，未声称完成浏览器交互验收；本地服务HTTP 200与静态资源路径另行检查通过。

## 已确认规则

|职业|MAP|距离|三档治疗量|生命代价|
|---|---|---|---|---|
|疗愈师|愈护之环|最远8格，单体|A / A+3 / A+6|0 / 最大HP15%向上取整 / 最大HP25%向上取整|
|济世术师|济世·愈护之环|最远10格，单体|A+2 / A+6 / A+10|同上|

A为人物攻击基础值（力量）。每场每名角色各自最多3次，施放消耗行动；支付后至少保留1HP。第三次移动-2（最低1），至下个己方回合结束。排除施法者本人，治疗不超过目标缺失生命；满血可加防。

目标获得「强身」：物防+2，持续施放当回合与下一回合，重复施放只刷新时间。第3回合施放，角标2；第4回合角标1；第5回合己方阶段开始移除图标与绿色加防文案。没有护盾值、魔防、群体恢复或额外治疗次数。

## 来源与生成

`tools/capture.gd`通过现有`background_guard.m`预加载保护，在后台实际Godot phone视口取图，未前置或激活游戏窗口。底图为当前M12丘堡粮站与F41沙城守井战，摆位均为可站立地面；目标精确处于曼哈顿距离8/10格。完整截图保存在`reference/`，地图区裁切用于网页演出；不是iPhone录屏。

角色复用当前正式地图图集，只机械拆分手臂/法器并旋转。`tools/prepare.py`逐帧验证待机回到原图、下摆/脚部像素不动。未重绘身高、腿长、头脸、服装或职业身份。

两套六帧治疗特效和一个强身图标由**内置image_gen**生成。完整提示词和默认输出位置见`sources/prompts.json`；工作区保留原始生成文件于`../../source/healer-map-20261104/`，未把超大源图作为运行预览资源。网页素材在`assets/`，效果定帧在`posters/`。特效按同一脚底基线注册，输出192像素帧；强身图标48×48，UI倒计时独立绘制，不烘焙成图片。

## 预览检查

`sources/browser-cases.json`记录两职业×三档的浏览器显示；`browser-buff-checks.json`记录强身2→1→到期、满血加防与切换单体目标；`browser-mobile.json`记录390px窄屏控件和文字检查。`sources/qa.json`汇总实际范围。

姓名/强身采用现有12px位图字体，说明采用现有8px字体；所有状态文字检查背景安全区域。人物详情背景按原九宫格固定边角绘制，不整图拉伸。图标在深浅背景检查透明轮廓，交付PNG无损压缩；实际像素与字节数见`sources/asset-manifest.json`。

当前Godot后台取图结束时曾报告8个ObjectDB对象、2个资源的退出回收警告；图形已完成导出，脚本与文字布局无错误。该记录不作为正式游戏回归通过证明。本轮未执行玩法回归、存档迁移、移动端打包或真机更新。
