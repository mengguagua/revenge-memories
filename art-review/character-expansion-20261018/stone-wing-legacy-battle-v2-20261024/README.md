# 石翼兽：战斗保留旧版

按本次反馈，战斗场景全部沿用旧版四足石翼兽的形象和姿势。蓝紫新版只保留在地图待机与四向行走中。

- 旧战斗八姿势直接取自现行 `actual/assets/innate-enemies-20261023/class-3-battle.png`，仅作最近邻技术放大。逐姿势缩回原尺寸后 RGBA 像素完全一致，没有重绘或调色。
- 裂石爪沿用旧版俯冲准备、伸爪接触、回收顺序：50 fps，共 46 帧，第 27 帧接触（零基 tick 26）。
- 碎岩喷吐及远距喷吐沿用缩颈、张口、回收顺序：50 fps，共 54 帧，第 35 帧接触（零基 tick 34）。石块复用现行 `stone_low.png`，没有新加炸裂或额外命中。
- 战斗待机、受击、未命中、退场和厚石甲也使用旧姿势。退出活动列表的是本轮新增、被否决的 208 帧重绘节奏对照。历史生成源图和修订前数据留在 source 中。
- 九条地图动作与两个地图形象配置保持原样；本轮只替换八条战斗动作及一个战斗形象配置。游戏运行素材、卡牌结算与设备均未修改。

检查范围：旧素材像素一致性、全部帧和特效边界、资源路径、地图配置一致性，以及 11 段战斗视频的帧数和时长。已离线查看深浅底和导出视频连续帧；本轮未进行浏览器交互验收。
