## 性别与职业路线

本轮为男性职业路线：**术法师（15）→ 博学术师（19）**，对应原“男魔道士 → 贤者”。女性现行路线为 **女法师（16）→ 女魔剑士（11）**，对应原“女魔道士 → 神官”。当前没有单独的“女博学术师”职业条目。

依据：[职业命名记录](../../../docs2/职业命名提案-0.9.0.md#已接入的己方职业名称)、[完整游戏设定](../../../docs2/完整游戏设定.md#51-职业线与分工)、[运行职业名称](../../../actual/data/class_names.json)。本轮仅更新美术对照，未改变职业路线或角色性别。

## 动作理解与注册

- 地图待机使用本职业原三相与 `[0,1,2,1]` 顺序，每相依次14、8、14、8个原生帧。固定头、颈、躯干及站立脚，保留杖手、杖头和袍摆变化。六个素材槽保留原别名关系 `[0,1,2,1,0,1]`。
- 四向行走使用已核实的原生32×24图块，原每相16帧、两相循环。向上为背面，向下为正脸，左右为对应侧向。头颈和上身共用固定区域，脚尖与下摆交替，杖手保持原动作含义；向左由同一右向素材精确镜像。
- 战斗原作画布80×64，素材320×256。0为持杖待机；16～20为披风逐渐收拢；21～30为自由手由低位伸出、向外展开、抬至面前、举起释放；31收势；32～36保留另一套伸臂、放低与收势。常规攻击施法、恢复与吸血使用各自原生程序。
- 注册使用生成图的完整透明角色、等比缩放与整数定位，之后统一固定身体、腰带、靴子和完整长杖。披风使用已绘制布料按原生收拢宽度重新采样；经过脸前的手和袖口保留完整轮廓。最终36张素材均为单一连通图形，未裁切可见像素。

## 覆盖与规则边界

新增3个场景入口、97项动作对照：地图待机1项、四向行走与停止8项、原生法术变体84项、战斗待机/未命中/受击/退场4项。84项包含14类法术及近远距离、目标条件变体，**属于职业动作库，不表示每个人物已学会全部法术**。实际权限仍由个人法术表、已解锁槽位与现行规则决定。

[角色/法术/动作/结算映射](action-effect-mapping.json)记录逐变体的原生程序、帧数、结算时刻与接触计数。所有法术效果、释放与结算程序沿用原生数据；本轮不新增连击、伤害、恢复次数、觉醒或阶段恢复表现，也未将职业样板接入游戏角色业务代码。
