# 驭魔师 · 待机、四向行走与战斗全动作

驭魔师形象、地图与战斗动作已获用户确认。本轮雷电落地共用效果另待验收，见[双方雷电修订](../thunder-ground-impact-v1-20261024/README.md)。仅隔离美术对照，未改游戏运行、伤害、召唤规则、存档或测试包。

原作19号敌方为人类兜帽长袍施法者：头上两处突出是布帽形状，浅色胸前部分是领口与内衬；前景露出的前臂依次托掌、举掌到头顶、向前伸掌，后侧手臂在举掌时收向腰前。没有魔杖、浮球或生物角。新稿采用柔和蓝紫哑光长袍、淡紫领饰和暖肤色，保留深色轮廓及褶皱阴影；头发被帽子覆盖，无发丝或衣服高光。

地图为3张独立待机、6张独立方向步态及已验证的左右镜像，共14个原槽位。待机保持0／1／2／1、14／8／14／8 ticks，播放两周期88帧；行走每相16 ticks，播放三周期96帧。头部与腰部基准固定，前臂、衣摆与脚步保留各自相位；上行只见后帽，左右前景手臂在胸前、远侧部分被长袍遮挡。所有姿势按统一地面线注册，无整图平移或呼吸缩放。地图与战斗固定区域、相位差异和透明边缘分别检查。

战斗使用原作0／4／5三个姿势，6槽位背景图集与80×64逻辑画布。原作66条攻击法术变体（11种法术、近远阵位与重甲目标组合）的身体帧序、位移、翻转、FPS、总时长和结算点全部保留。19号全是背景帧，不能套用其他职业OAM翻转时的16像素修正。48条变体仅复用已逐帧证明原生效果轨道相同的既有蓝紫法术素材；其余18条保留自身原作效果。没有将其他职业的身体帧或不同长度的死亡／美杜莎时序套过来。

原作法术目录是美术参考。当前F43_e8「沼泽驭魔师」magic_flags=17，对应鬼火31与召唤37；目录里的其他攻击法术不代表该关卡已解锁或本轮授予能力。

## 召唤 · 两名骸卫

原作没有本页可独立对照的召唤战斗程序，新增演示明确标注为自定演出；左侧仅显示原作共用施法姿势。160帧中托掌→举掌→伸掌→回位，蓝紫雾光先聚拢，再显出两名已确认形象的骸卫，第81页帧开始显形，透明度逐级增强，雾光收尽后两名骸卫留在原地。效果不包含攻击或伤害，不增加魔物种类。

该演示遵守现行每波最多2名骸卫的上限；实际F43规则仍是第3回合起、最多2波、间隔3回合、成功每波扣2HP，召唤物入场回合不行动且无经验／掉落。动画没有修改这些规则，也没有将友方幻影表现为敌用召唤。
