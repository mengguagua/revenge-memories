## 制作范围

使用内置 ImageGen，以已验收的弓箭手与枪兵待机首帧为编辑目标，以男主作为体量参照。提示词要求在原姿势中心线附近增厚肩胸、衣甲、手臂与腿靴，不增加细碎装饰或颜色。原始生成图离线保存在 `source/`，不作为运行资源。

- [弓箭手完整提示词](source/archer-prompt.txt)，源图 `source/archer-generated.png`。
- [枪兵完整提示词](source/spearman-prompt.txt)，源图 `source/spearman-generated.png`。
- 注册到原 96×96 画布后，恢复已验收头部区域像素，保留脸和发型／头盔识别。
- 统一作 102/96，即 6.25% 的最近邻等比放大，重新对齐 `[48,80]` 脚底基准；没有按武器长短单独定身高。
- 敌我使用同一体型，分别保留蓝／砖红阵营色；输出仅深蓝、阵营色、米白、肤色四种不透明颜色，二值透明，轮廓不裁切。
- 保留各自已验收的阴影参数；原姿势与单手持枪／拉弓的关系保留，实际观感由用户验收。

`tools/prepare.py` 仅做生成稿的限色、头部区域复用、缩放注册、阵营调色和无损压缩；不绘制替代人物。

## 实际地图预览与验证边界

`tools/capture.gd` 位于审核目录，在受后台防抢焦点保护的临时 Godot 进程中加载真实 M11 地图及现有绘制代码。只在该进程内替换纹理缓存的待机首帧；保存路径指向 `/private/tmp/`，不修改用户存档、运行资源或游戏包。输出包含原有站位与五角色并排两组相同镜头对照。

[验证记录](verification.json) 检查男主截图像素完全一致、并排两张实际地图截图的变化仅发生在四个样板位置，以及运行代码/素材和原审核映射哈希保持不变。[素材清单](image-inventory.json) 记录像素尺寸、字节数与缩放。服饰色和肤色面积计数仅辅助检查，不等于视觉验收。

背景截图优先无损优化；若仍超过 200KB 参考体积，保留完整场景分辨率与地面纹理，理由记录在验证清单。未绕过已有浏览器本地访问限制，不声称完成浏览器内实播。
