# 隼骑士 · 飞行骑枪修正

本轮修正我方隼骑士战斗投枪过短、难以识别的问题。飞行图直接复用已确认手持骑枪的完整原图，保留针尖、锥形枪身、外扩护手、短柄、尾端和橙色扣饰。可见长度由30增加到53.75逻辑像素，约增加79%。

- 更新普通、重装目标、远距双方位置等六种投枪变体，共用同一飞行骑枪图。

- 原始武器为 `../falcon-knight-complete-v1-20261023/source/lance-clean.png`（1808×267），原始生成母图保留在同目录 `lance-master.png`。本轮仅进行技术性等比重采样及透明画布合成，无新增绘图。
