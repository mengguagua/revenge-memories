# 大骑士 · 待机配色统一

仅供「角色重绘 · 全动作对照」验收，未接入游戏。

以已验收的向左行走稿为配色标准，将待机骑手的头盔、胸甲、肩甲、臂甲、手甲、腿甲，以及马具金属边饰中的白灰大面，统一为低饱和淡金与暗金。灰白马身、面部、鬃尾、长枪和深色鞍布保留。

- 沿用原八色调色板；淡金 `#b5a273`、暗金 `#817454`。
- 六个原生槽位同步修改，每帧 205 个像素仅改变 RGB；透明度、尺寸、轮廓和登记位置保持。
- 双前腿抬起 → 四腿站定 → 双后腿抬起 → 四腿站定；原 14／8／14／8 帧节奏和固定中心保持。
- 四向行走稿、阴影及其动画保持原版本。

本轮用既有像素素材的材质区域进行配色映射。原稿保留在 `gold-knight-idle-v2-20261020`；未调用图片生成工具，图片和演示仅保存于对照页，不回传至对话。
