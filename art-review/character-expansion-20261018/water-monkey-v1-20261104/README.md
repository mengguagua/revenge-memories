## 动作修订V2

- 地图待机由48帧延长至180帧，完整和破损均约3秒一轮，四向行走不变慢。
- 近战参照普通士兵219帧的跑近、出手、收势、跑回阶段，第83帧单次命中。因空手比长枪短，接近位移从士兵的72调整为88；两种状态都跑到可见士兵身前攻击并回位。
- 主体按普通士兵约32逻辑像素高校准，脚底同为128。完整炮管可高出头部，破损炮体变矮不会缩小主体；不在切换动作时单独变更显示比例。
- 水炮重制为有厚度的高压水束，飞行显示框52×24，命中水花42×44。旧的极小水滴发射姿势不再进入当前时间线；仍只有一次命中，不新增连击或范围伤害。
- 已核对现行普通士兵受伤：同一张姿势明暗闪烁、轻微位移、命中音，没有连续后仰身体动作。水猴完整／破损受伤都改为固定待机姿势，复用士兵28帧的1点扣血参考节奏；真实战斗停留随伤害数值而变。
- 复用既有rm_sfx_03命中音，可在页面手动开启，默认关闭。页面加入普通士兵作为身高与接触位置参照，不会写入实际战场。

证据和源动作见[source/motion-v2-20261104/reference-audit.json](source/motion-v2-20261104/reference-audit.json)。这轮记录和V1记录均收在主对照页默认折叠的历史修订中。

## 数值与运行规则

等级3；本体22；背炮耐久10；力量5、技巧4、速度8、幸运0、物防3、魔防1、移动5。背炮独立物防2、魔防1。

- 机械掌击：1格，物理总威力5，基础命中85%，负重0、攻速8。
- 水炸弹投掷炮：1–3格，物理总威力8，基础命中75%，负重5、攻速3。命中速度－1，最低0，持续至受击者下一次行动结束；重复命中只刷新时限。一次出手一束水炮，不附送攻击或范围伤害。
- 机械傀儡经验：先算普通同条件经验，再乘1.5并向上取整，沿用原单次经验上限。普通同条件击败经验35时为53，并非所有友方固定取得53。伤害经验同样乘1.5；部位破坏不另发击杀奖励。
- 同阵营在场存活战斗单位仅剩机械傀儡时，移动＋3，即5→8，不叠加。每个本方回合优先向最近合法边缘撤离，不主动攻击，仅掌击近身自卫。重新出现非机械友军时恢复正常行为。
- 到边缘即退场，不计击杀、不发击败经验、不掉击杀战利品；已取得的伤害经验保留。不能穿墙、穿占位或瞬移。
- F21撤离时可从船舷下水，海面代价1；普通战斗仍走甲板和跳板。已接入海图撤离通路。
- 部位独立扣耐久，不传导或溢出到本体。破坏立即禁用水炮，本体与基础掌击保留；同次交锋重新检查后续攻击。追击固定目标，部位已坏则取消部位上的后续追击。

完整结构见 [design.json](design.json)。持续时间、伤害传导、撤离时下水等细则已随本次确认接入。
