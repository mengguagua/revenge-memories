# 我方黄金骑士 · 左右行走固定点

本轮只消除整图横向晃动。打开[全动作对照](../index.html?action=professions-class-7-ally-maps-tactical-walk--walk-right#motion-player)切换向右／向左，或查看[连续循环视频](overview.mp4)。未接入游戏。

两相骑手头颈处有完全相同的多色像素块，原先相差约6个输出像素。本轮仅对四张图做整数横向平移，将该像素块登记到同一位置：4×4区域为(62,41)–(66,45)，中心点为(64,43)。向右两帧分别平移+5、−1像素，向左两帧分别平移−5、+1像素。左右仍保持精确镜像。

不重绘、不缩放、不改变上下位置。逆向平移能够逐像素还原原图的全部不透明内容，原腿部动作、颜色、16帧／姿势节奏和固定地面阴影保留。此前向上、向下以及待机素材保持。

[制作脚本](../tools/register_gold_knight_side.py)包含无损平移、定位块一致性和精确镜像检查；[素材清单](asset-manifest.json)记录路径、尺寸、字节数、平移量与哈希；[检查结果](verification.json)另记录动作签名、视频帧数／时长、标题安全区及工程文件哈希。

仅左右行走及其对应停止展示共4个动作内容签名变化，其余543个动作保持。游戏工程没有修改。本轮未调用图片生成工具，也未向聊天输出任何图片；只提供对照页面链接。针对纯位置调整执行必要的像素与导出检查，未启动游戏窗口。
