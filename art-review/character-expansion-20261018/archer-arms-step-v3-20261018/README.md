## 对应这次反馈

| 问题 | 本轮修改与检查 |
| --- | --- |
| 待机看不到弓背面的手臂 | 补出肩部至持弓手之间的可见手臂，位于弓后；在最终合成结果中检查实际露出的肤色部分。 |
| 拉弦前臂分成两块，角度不对 | 将腕部黑色分隔线移除，前臂与拳头为同一个连续肤色区域，轻微向上倾斜。侧向使用对应镜像。 |
| 向下、左右缺持弓手臂 | 补全可见手臂与袖口连接，再把完整弓箭置于前景；不再仅放一只悬空手掌。 |
| 弓弦黑点过多 | ImageGen 重绘两段连续浅色弓弦。缩图采用原图笔画覆盖率保留细线，避免最近邻采样交替取到浅色中心和深色边缘；核对最终像素中的两条浅色路径均连续。 |
| 侧向两步都像前跨 | 原作侧向帧 2／6 改为站直，3／7 保留前跨；头、上身和整组手持物不变。分别检查两帧腿部轮廓宽度和落脚基线，另导出专用两帧对照。 |

保持原作方向映射、相位别名和时序：行走每姿势 16 帧；待机 14／8／14／8 帧、60.0988 fps；待机 0／1／3／4／5 共图，2 为另一相位；左右同相位镜像。待机的手臂和完整弓箭仍整组上下移动，固定身体底图保持不变。画布继续为行走 128 × 96、待机 96 × 96，均为原作四倍尺寸，角色仍用四色。

## 检查边界

检查最终帧的配色、透明度、尺寸、固定区域、相位和镜像；专门检查拉弦前臂连通、持弓手臂露出、弓弦浅色路径连续、站直与前跨轮廓区别、视频帧数与时长。查看项目地面和深浅底色的导出画面，核对离线演示标题与文字安全间距。

数值检查不代替用户对造型和动作的验收。浏览器本地文件实播仍未执行，未绕过此前的访问限制；使用对照页共用的离线渲染器核对。本轮没有启动 Godot 或修改测试包。
