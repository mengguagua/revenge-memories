## 形象与动作

保留现有长发、头带与无袖分片长裙，低饱和蓝紫衣料搭配自然肤色；头发为单一深蓝，衣料哑光，浅色领口和裙边属于衣服结构，不增加发丝或布料高光。角色单帧共用8色：`#172638`、`#4f4f7d`、`#bbc1d6`、`#dda77d`、`#373e64`、`#a394b1`、`#77604f`、`#77b8c7`。新增木色与柔和蓝色只服务于魔杖，避免扩大整套衣服的色彩数量。

- 地图待机沿用三姿势与六槽别名 `0/1/2/1/0/1`；人物头颈、腰胯和双脚固定，保留原有袍摆局部动作，持杖手与杖保持相连。
- 待机仍为 `0/1/2/1`、`14/8/14/8` 帧，展示两轮共88帧。
- 四向行走沿用现有原作八槽及左右脚姿势，每相16帧，两相一轮，展示三轮共96帧；不改支撑脚与抬脚，不给人物增加整体平移或上下浮动。各方向头部与腰部固定区域逐像素一致，杖的握持点在同方向两相中固定。
- 原作没有魔杖，本轮新增持杖手势与装备遮挡；原有头部、身体基准、脚步顺序和袍摆循环保留。下半杖身可自然经过裙摆与靴后方，手指盖在握柄前。
- 战斗按原作敌方三姿势绘制：站立、前手举臂蓄力／后手向后持杖、前手伸臂释放／后手收杖。保留原有头部朝向、长发飘动方向和裙摆，整幅姿势等比缩放与整数登记，不扭曲关节。
