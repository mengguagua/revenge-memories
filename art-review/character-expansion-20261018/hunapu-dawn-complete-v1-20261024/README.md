## 形象与武器

延续战士阶段的年轻面孔、暖肤色、短蓝发与步战轮廓。用浅蓝胸肩甲、护膝、深蓝分片战衣、护臂、长靴及短肩披加强进阶感，大幅减少咖啡色。头发统一纯色，衣料哑光；保留必要的结构阴影、浅色甲面与深色轮廓。最终人物帧仅使用10种颜色及二值透明度。

长剑按用户参考重做：银色几何镂空剑框、蓝色中脊、细长剑尖、圆形深蓝宝石护手、深银开口剑柄和短蓝羽带。完整剑尖、护手与羽带均保留透明间距。它是本轮进阶形象的剑型设计，不新增或发放装备；守约剑仍按现行人物与持有条件使用。

持弓采用相同护甲，弓为深蓝弓臂、浅蓝饰面与银色端部；箭为实体箭。持弓场景不同时持剑、持盾。满弓、放箭和准备姿势统一脚底与人物尺度，松弦后手中没有仍待发射的箭。
