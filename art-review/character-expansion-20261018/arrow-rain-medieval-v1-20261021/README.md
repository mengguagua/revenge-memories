# 箭雨：六支中世纪西式箭

同场飞行箭由最多三支增至六支。保留原有三条箭线，沿各条原轨迹增加一条向下错开6原生像素的箭线；新增箭与原箭使用相同生成、飞行和消失节奏。只增加飞行箭的视觉数量，没有复制命中光环、碎光或额外伤害结算。

箭的轮廓重新设计为中世纪西式箭：金属菱形箭头和短套筒、细长箭杆、三片鹅羽式尾羽及窄箭尾缺口。三相共用同一轮廓与调色板，只保留少量高光变化。友军统一蓝白近色系，敌军统一暗蓝近色系；箭尖依照各近远阵形的实际飞行方向朝前。

仍使用原48×16画框及注册点，输出192×64四倍位图，完整保留透明边缘。人物、施法动作、原箭位置、飞行速度、命中与消散效果、命中帧及总帧数不变。双方近距、远距和重甲参考共12个动作变体同步，其它已完成法术和地图动作保持。
