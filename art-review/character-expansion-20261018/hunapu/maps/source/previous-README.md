`mapping.json` 与 `frame_mapping.json` 内容相同。每个场景记录原源、原尺寸、四倍尺寸、原脚底锚点、生成源裁区、等比缩放、登记偏移、单帧路径、实际字节和时序。四倍仅提高宽高像素数，逻辑绘制倍率为0.25；地图占格不扩大。

行走原六槽为下0/1、上2/3、右4/5；左向按原系统水平镜像，另交付显式左向独立PNG。腿帧每16 tick切换、两帧32 tick，使用60.0988Hz连续时间相位；移动一格16 tick，不因换格重置腿相位。剧情及大地图待机保持对应方向第一帧，不虚构呼吸姿势。战斗待机原六槽是重复的固定朝向，并非六方向；独立姿势0/1/2按`[0,1,2,1]`、`[14,8,14,8] tick`播放，六槽恢复为`[0,1,2,1,0,1]`。

复核原图后，战斗移动与待机的小直边盾已恢复到原手位与遮挡关系；盾面深蓝、浅金属直边、铜色细缘，与男主衣装统一。剧情和大地图原源无盾，保留无盾旅行形态。战斗移动原0/1裁紧后RGBA字节在水平镜像下完全相同，因此新1帧以新0帧镜像并按源1帧脚底位置登记，未创造新的步相。

美术通过内置`image_gen`生成与定点修正，完整原稿和未选版本均留在`source/`。`register_frames.py`只做技术裁切、等比注册及图集合并，`build_previews.py`制作审核预览，`verify_deliverables.py`验证路径、尺寸、字节与锚点。所有运行PNG使用ImageMagick等比采样与oxipng无损压缩，没有颜色量化或艺术性代码绘制。现在同时测量脚部横、纵位置：横向误差最多0.5输出像素，纵向最多1输出像素，分别相当于0.125和0.25逻辑像素；不允许为容纳剑尖而横向挪动整个人物。

待机1及其重复槽3/5已通过ImageGen适度缩短外露剑身，保持剑角、手位、身体和盾，修正原登记代码把过长剑尖连同整个人物向左clamp的问题。修正后三槽脚部中心及脚底均为`[50,80]`，与原目标完全一致。其他待机姿势为`[50,80]`或`[50.5,80]`。仅1/3/5和待机图集的交付PNG发生变化；其余PNG与修正前逐字节一致。

`deliverables/`共25张PNG：3张透明图集、18张原槽位独立帧、4张显式左向镜像帧。单帧最大9,348字节，图集最大41,832字节；逐图尺寸、大小、SHA-256见`qa-report.json`。每张独立帧均低于20KB，图集均低于50KB；未以牺牲透明轮廓或细节换取体积。

`previews/`包含三类原作/新图深浅背景对照，以及剧情、世界、战斗移动、战斗待机分别的原节奏GIF。已检查发梢、剑尖、盾边、靴底、裙甲覆盖、朝向与步相连续性。未启动Godot、未激活任何游戏窗口、未修改`actual/`，也未在实际游戏场景接入验证。
