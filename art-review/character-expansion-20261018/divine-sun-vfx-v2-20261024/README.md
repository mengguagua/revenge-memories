# 日冠聚光 · 特效 V2

2026-10-24，按用户要求丰富「开始聚光变大 → 变赤红发射 → 命中后爆炸」，并适当降低特效饱和度。近距、远距两项对照同步更新，供视觉验收。

## 动作与效果

|显示帧|阶段|表现|
|---|---|---|
|1–20|聚光|浅金光点持续增大，内卷光丝与旋转日轮逐渐凝聚；末段由金转暖红|
|21–34|发射|带浅金亮芯的柔和赤红弹体，焰尾朝后，弹头沿原路径前进|
|35|单次命中|在原目标坐标产生第一道爆裂闪光，仍在原第35帧结算|
|36–48|爆炸扩散|放射状日焰展开，随后中心透空、火环裂解为碎焰|
|49–53|余烬|碎焰保持向外扩散，逐渐减淡，不反向缩回中心|
|54|结束|特效清空，保持原动作结束时间|

对应关系：`角色169／class21神躯 → 1006日冠聚光 → 冠部蓄光、赤红弹体、一次爆炸 → tick34（显示第35帧）`。仅丰富当前一次攻击的视觉，不增添伤害次数、连击或其他能力。全程54帧、50fps、1.08秒。

原始身体帧、位置、朝向、旧版左侧参考和结算保持。近景预览范围包含整个发射路径与爆炸，方便检查目标处的特效完整性。
