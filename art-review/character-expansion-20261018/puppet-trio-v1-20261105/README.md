## 本轮补齐、待确认的边界

- 独眼“本地”按“本体”理解。普通命中率最终减半并向下取整，只保护本体；不保护部位或队友。普通100%变50%，真正“必中”不参与减半。非法目标和超出射程不因必中变合法。
- 独眼治疗暂定本方回合开始一次。范围为切比雪夫距离1的八邻格，含斜角；同阵营存活、在场的战斗队友各回5，封顶最大HP；不回自己、不复活、不修核心，不治疗对手或事件物件。核心破坏立即停用。
- 飞枭穿透当前有效物防2、最低0，只影响物理打击，包含其正常物理反击；魔法、持续伤害和反伤不穿透。战后移动在本方主动交锋（含反击、追击）全部结束后判断，未命中也可，需本体存活且引擎有效。仅一次最多3距离，不是剩余基础移动，不能再攻击或施法，反击不触发；核心破坏取消未用的再移动。基础移动8、速度11和翼组飞行保留。地形具体成本留待接入时与现有飞行规则对照。
- 普罗米修斯生命核回复在本方回合结束一次，待机、反击和额外移动不重复触发。正常伤害归零时立即回复24并将生命核置0，保留火核当前状态，不重置已消耗行动；不记击杀、不掉落、不发击败经验。后续正常追击仍可继续攻击复苏后的本体。直接击破生命核同时关闭回复与复苏。
- 公共经验×1.5、最终180上限。V=min(255,B+floor(B×(等级-1)/10))，再套友方职业／等级与伤害公式；不是固定发90、82.5或135。部位只有伤害经验，自动消耗核心无额外部位经验；最终本体死亡才是击败。
- 仅剩机械战斗单位时，独眼移动4→7、飞枭8→11、普罗米修斯6→9。沿合法路径到最近可达外缘后消失，不计击杀、无击败经验或击杀掉落，已得伤害经验保留，不阻挡胜利。Boss同样遵守撤离；逃离不触发复苏。具体Boss关卡的胜利交互待用户指定投放时确认，本轮没有安排任何章节或关卡。

## 美术与动作

内置ImageGen生成整套像素姿势，提示词及全部原始输出保存在source目录并用.gdignore隔离。展示用副本由程序裁切、等比最近邻注册与24色优化，不拼接肢体、不用代码画角色或特效。登记13次生成／修订；最初普罗米修斯与FX留作历史源图，预览用修正后的完整轮廓版本。

共3类单位、8种核心组合、16个地图／战斗场景配置、192张完整姿势图片（含对称角色的整帧方向镜像）、12种位图特效和106项动作。独眼／飞枭分别完整与破损；普罗米修斯分别双核完整、火核破坏、生命核破坏、双核破坏。涵盖待机、四向移动、近战靠近／攻击／回位或原地施法、士兵固定姿势受伤闪烁、核心破坏、倒地、撤离，以及八邻格治疗、战后3格、回合回复与消耗核心复苏。

左右侧走单独生成交替腿姿势；独眼与飞枭仅对称装备的整套右／左向做完整镜像，普罗米修斯双侧独立生成。飞枭地图原图的翼拍跨过均分行界，因此按实际完整透明轮廓测量24个独立矩形切图，保留翼尖、钩爪且无邻图串入。

移动端按真实原生像素验收：独眼战斗主体约36像素、飞枭中间翼位约44像素、普罗米修斯约56像素；地图素材密度2，主体约24／24／30逻辑像素。网页提供原生1倍、整数2倍及地图实际1倍，深浅背景可切换；原生整姿势和方向对照保存在qa目录：[实际1倍深底](qa/native-1x-dark.png)、[实际1倍浅底](qa/native-1x-light.png)、[四向与交替腿](qa/map-directions-light.png)、[动作关键帧](qa/action-contact-sheet.png)。独眼大眼、飞枭背部引擎与Boss橙绿双核在小尺寸下分别可辨，无明显人脸。
