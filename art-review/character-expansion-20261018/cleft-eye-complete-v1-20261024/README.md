## 形象与部位

原作是悬浮单眼球体：前方是眼白与瞳孔，后方是短细尾，球壳边缘有少量短棘。没有手臂、腿、翅膀、头发或衣服。地图背面下缘的浅色小块属于尾根；向下行走时上方弯曲部分是绕到身体后方的尾，不是角。地图原图底部的黑色横条是地面阴影，不作为尾部绘入新角色。

使用柔和蓝紫球壳、浅色眼白与深色不透明瞳孔。保留阴影和轮廓，哑光处理，不增加眼部闪点、衣服或头发。瞳孔不再把底色当作眼睛颜色，在深浅背景都能完整阅读。

## 原姿态、中心与遮挡

| 场景 | 处理 |
|---|---|
| 地图待机0→1→2→1 | 保留尾部弯曲、视线由偏下到向上的变化；固定球壳轮廓，去除原图的整体上下浮动。 |
| 向上0／1 | 展示背部，不画瞳孔。固定球壳，尾根与尾梢交替弯曲，不误作双脚。 |
| 向右2／3 | 眼睛朝右，细尾在左后方上下摆动；球体不随尾尖移动。 |
| 向下4／5 | 视线向画面右／左交换，后侧尾部相应弯曲；共用球壳外轮廓与两像素边缘，眼部变化保留在外壳内部。 |
| 向左6／7 | 原CPU源帧逐像素等于向右2／3镜像，仅在已验证的关系上复用。 |
| 战斗0→1→3→2→0 | 原作的正视、下右视、下左视、上左视与复位。不是闭眼动画；保持球体与尾不动，只替换眼部。 |
| 战斗4→5→6→0 | 原作的尾下摆、上卷、上摆和复位。保持球体和眼部不动，只替换后侧尾。 |

地图按主体球壳登记，不按含尾尖的整图包围盒逐帧居中。上下、侧向和待机分别固定同方向的球壳；向下两相另核对主球壳透明轮廓和曲线边缘的逐像素一致。眼部和尾部在固定外壳中变化，不通过整体左右／上下位移制造动作。复用现有柔和阴影位图，阴影位置固定。

四向行走采用原CPU战斗地图渲染CHR19八槽资料。八张源图RGBA摘要与CPU记录逐项一致，不使用旧的场景动作表与图块银行混合参考。[八槽来源核对](source/source-walk-verification.json)。
