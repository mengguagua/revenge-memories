人物头部、下肢、正面盾牌、已有步态及中心定位沿用确认稿。刺击姿势原来被枪杆遮住的胸甲与盾缘，使用ImageGen恢复图补回狭窄旧杆区域；恢复图没有替换整个人物。清理旧枪尖、后柄及脱离人物的轮廓残片，检查深浅底透明边缘和完整连接。
