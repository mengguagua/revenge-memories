# 咒法师：手脚交错

待机和向下行走改为右手抬起配左腿、左手抬起配右腿，中间仍是双臂放下。只交换原有左右腿部袍摆相位（旧三姿势的下半身改按2／1／0配对），没有重新拉伸或旋转腿部。

保留刚调整好的24°抬臂与内收6输出像素；头部、躯干、手臂的全部像素、眼睛明暗、双臂放下姿势、六色低饱和蓝紫、14／8／14／8帧节奏不变。向下逐像素复用待机，平移[16,16]输出像素；向上及左右行走沿用已确认资源。
