# 正确的原生战术移动参考

此目录仅保存原 ROM 的只读提取参考，不改游戏代码或旧冻结素材。

真实路径为 `bank006:L06BA0A → bank011 dispatch3 → L0BB59D/L0BB5B1`。职业与阵营决定 CHR：`L0BB719/L0BB7F5`；动作八槽来自 `L0BB669/L0BB745`。渲染器是 `bank015:L0FE80F`，布局/图块指针来自 bank8，`$0589=0`。已执行原 CPU 并捕获实际 OAM 和 CHR 写入，再用独立 ROM 表解码验证全部352槽一致。

每个 `class-N-side.png` 有8帧，顺序：上0/1、右0/1、下0/1、左0/1。原右向镜像和各tile镜像已经烘入原图，不应再额外镜像。严格可复用的全图镜像关系见每条 `exact_mirror_aliases`。16tick一相、32tick循环，由原 `$36 & $10` 决定；边界0/15/16/31/32等已原CPU验证。

`source_anchor`是原tile登记基准（原actor_origin向下8像素），不是解剖脚底。另存 `native_actor_origin`。飞行单位下方分离黑条等不能直接当蹄或翼尖登记。

`overlay.json`包含44组原生职业侧、当前24个游戏职业到原生22职业的映射、原程序出处、OAM、每帧边界、镜像证明、旧来源对比及正确静态待机复用证明。当前必需范围为22盟+10个已启用敌职业；其余敌组只标原作参考。

旧 `original-walk-N.png` 使用的是 village/world 的 `L08A779`/bank10 OAM，再配固定CHR26。原村庄初始化 `L079136/L079158` 在默认设置后会改用CHR30；真正战术移动还会按职业切到19/26/27/28。因此旧图是跨场景混用的历史提取，不能继续声称正确原作战术图。旧文件和对应已画稿都保留，供重审与局部复用。

先前class6半头缺失的FF分析亦须纠正：FF是tile索引，CHR26下为空而CHR30下有38个非零像素。新战术源使用CHR19及另一套布局，不能把旧跨bank空缺称作原作损坏。

主角战术显示按class21而非个人story sprite1。名字1/2/42在同一class21得到完全相同8OAM。游戏自定义23映射21，24映射11；没有把23/24越界传进原22职业表。

`static-idle-reuse.json`要求完整RGBA字节相同，或精确alpha与全局双向一一对应的palette结构；只允许整数平移/严格水平镜像。不是目测“像”便算复用。动态新美术是否通过仍须单独审查。
