## 核心与反伤

按用户最新口径，**本体获得双防＋10和“被攻击后固定反伤2HP”**，不以命中或本体掉血作为反伤条件。

- 本体每次被合法直接攻击后固定反伤2HP；命中、未命中均触发，远程攻击本体也触发。反伤不乘必杀、不递归、不增加反击或武器挥击。
- 核心是独立弱点：攻击核心不反伤；伤害不传导、无溢出到本体。核心归零立即失去双防＋10和反伤，本体现有生命、锤击威力和移动保留，不在后续动作中恢复核心。
- 同次交锋后续攻击固定原目标；核心已被破坏，则取消对它的追击，不自动改打本体。正常近身武器反击仍受现行规则控制，不能把“攻击核心不反伤”理解为敌人完全不能反击。
- 反伤可使友方归零，不保底1HP；致命攻击本体时按攻击前核心状态反伤一次，可以同时倒下。毒、场景持续伤害不触发；MAP只伤本体，每次释放对该目标触发一次，不按格数重复。这些边界是本轮拟定细则，尚未进入运行代码。
- HTML是一次攻击固定命中／未命中示例，不自动添加反击或追击。总威力14时：完整本体物理伤害1、魔法2，均反伤2；核心物理11、魔法12，无反伤；核心破坏后本体物理10、魔法12。保留现行普通伤害最低1的规则。

## 经验与公共特性

基础价值70，沿用当前敌方等级增长：`min(255,70+floor(70×(等级－1)/10))`。等级5的敌方经验价值为98，之后按友方职业、等级及现有伤害经验公式计算普通值，再乘机械傀儡1.5倍、向上取整，全敌军单次最终上限180，不提前按100截断。不是固定发105经验。

例如当前艾琳职业系数8、等级5系数7，对等级5伪泰坦的普通击败值为55，机械倍率后83；普通士兵等级1示例为119；将敌方等级切换到15仅作公式演算，可观察180上限，不代表其它章节投放。核心伤害有伤害经验，破坏无额外击杀奖励；撤离无击败经验，已得伤害经验保留。关卡通关经验不额外乘倍率。

同阵营在场存活战斗单位全部为机械傀儡时移动＋3，4→7，不叠加；每个本方回合优先撤离，到最近合法可达外缘立即消失。无穿墙、穿占位、瞬移或新增游泳能力；核心破坏仍保留这项公共特性。逃脱不计死亡、击杀、掉落或击败经验，不阻挡胜利。重新出现非机械友军则恢复普通行为。
