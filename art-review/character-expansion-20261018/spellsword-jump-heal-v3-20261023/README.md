# 女魔剑士侧向双臂、跳跃腿部与友方绿色恢复

本轮只更新美术对照，未改游戏运行代码、法术费用、目标、恢复量或结算规则。

- **左右行走不甩手。** 固定每个方向从剑尖到腰部的完整上身、持剑臂和空手臂。保留上一版并腿与跨步两相的腿部像素，以及固定地面阴影。向左仍为整幅向右姿势的镜像；待机、向上和向下保持。
- **前跳与后跳消除腿部抽搐。** 前跳伸腿段2—7、收腿段8—9、后跳25—26与27—28各自使用一致的腰胯与腿部基准，避免快速交替时腿长、膝盖、靴子和衣摆突然换位。保留上半身朝向、持剑、转身、落地和收势，原每帧位移继续产生跳跃轨迹。清除局部拼接留下的纯深蓝孤立发尾碎片，没有删除脚或手。
- **友方恢复改为绿色并化成雨滴。** 当前已有恢复动作的女魔剑士、疗愈师与博学术师共18组距离／目标变体同步更新。蓄力及目标处光环采用柔和绿、薄荷绿和浅绿，沿用原光环可见尺寸、位置与阶段；结算后12帧开始从目标光环分解为雨滴，六相每相6帧，在原有收势时长内向下落并消散。原唯一恢复结算、人物动作、目标与总时长保持，不增加第二次恢复。敌方效果保持。

绿色光环与雨滴由内置 image_gen 制作，原图与提示词保存在 [source/generation-record.json](source/generation-record.json)，以三种绿色整理为透明像素素材。原效果源图没有被覆盖，新效果使用独立ID。
