# 双方骑士 · 完整重绘

本轮已重新绘制双方骑士的待机、四向行走和战斗动画，更新「角色重绘 · 全动作对照」。当前为美术验收稿，未接入游戏。

本轮使用内置image_gen绘制7个独立地图姿势和12个独立战斗姿势，并对奔跑后蹄落点、腾跃姿势、准备动作前蹄以及投枪武器状态进行了画面修订。双方共用同职业的完整造型，分别使用蓝白和蓝紫16色调色板，包含各方地图14槽、战斗14槽。

- 整体：完整骑手、马身、衣甲与鞍具连续绘制；不再拼接上下半身，也不对腿部逐行压缩或做关节形变。
- 中心：完整姿势等比缩放并按同一参照点作整数定位；待机及同方向行走使用一致比例。战斗平地动作定位在同一面部参照，原作冲锋、腾起、跃出与回位作为动作本身保留。
- 配色：盟军以柔白与蓝色为主，保留少量肤色、木色与金属高光；敌军以暗蓝、蓝紫与冷色高光为主。地图和战斗共用各自16色调色板。
- 动作：待机0／1／2／1相位，14／8／14／8帧；四向行走两相各16帧。左右行走复用完整待机0／2姿势并镜像，原作此两组图形对应已核对。
- 战斗：双方各7种攻击配置和4种通用反应。普通攻击盟军270帧、敌军273帧；原作释放、命中、远距与重甲目标时间轴分别保留。投枪准备仅有一根水平长枪，释放后为空手，飞行投枪同步重绘为独立四倍像素素材，保留原逻辑画布、锚点、飞行范围与轨迹。没有增加连击、伤害、防御、魔法或觉醒能力。
