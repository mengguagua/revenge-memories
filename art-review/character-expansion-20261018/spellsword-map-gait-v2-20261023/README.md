# 女魔剑士 · 地图待机与步态修订

本轮只修我方地图待机、四向行走及对应停止姿势。战斗身体、攻击／法术程序、特效与其他角色保持；不接入游戏运行代码。

- **待机两条腿。** 重绘源图去掉中央多余肤色条。以腰部以下的完整下半身统一两腿和双靴，不再只固定脚踝而叠上其他相位的小腿。三相分别屈肘、展前臂、抬肘；肩、肘、腕和握剑手随剑一起变化，不冻结持剑臂。
- **前后行走。** 两腿从固定髋部沿窄而平行的步道前后交替，交换低位支撑脚与稍高的后脚，保留两只靴子，减少向左右外甩。头颈和躯干中心区域固定。
- **向下持剑手。** 改回右臂从画面左肩出发、前臂经过胸前握剑，空左臂位于画面右侧；保留正脸、肤色和眼睛。
- **左右行走。** 每方向第一相为双腿并拢通过、两只脚错开可见，第二相为低位前后跨步。向左依原作镜像关系使用完整向右姿势，身体和持剑臂一同转向。
- **阴影。** 待机和所有行走方向复用项目已有的地面阴影素材，位于人物后方，位置固定；深浅底均能显示。未把阴影混入腿部。

保留蓝白、肤色、玫瑰腰带及少量冰蓝的六种材料，头发保持纯深蓝，武器和服饰沿用上一版。使用内置 image_gen 重绘，提示词和原图见 [生成记录](source/generation-record.json)。原图离线保留，交付单帧使用无损索引色图片。
