# 原作动作审计（只读基线）

仅针对敌方 class 11 蚀躯与 class 14 断路匪。本目录没有修改共享对照入口或游戏。

地图待机采用原静态图集的0、1、2、1顺序，分别停留14、8、14、8 tick；四向行走采用经过原作CPU/OAM复核的8槽图集，up 0/1、right 2/3、down 4/5、left 6/7，每相16 tick。两种图集的锚点分别是[12,20]与[16,24]，不可混用。

生成时按原头颈、腰胯与接地坐标注册；手臂伸出导致的图像外接框变化不能作为整体平移依据。原下沉动作必须保留；不叠加全身上下抖动。
