## 制作

使用内置 ImageGen，仅编辑四个朝向的脸部与刘海内侧。[完整提示词](source/eyes-prompt.txt)，原始生成图保留在 `source/eyes-generated.png`。通过 ImageMagick 将新脸部局部合成回原帧，原头发外轮廓、身体、四肢、武器和阴影保持。

四个局部修改区域记录于 [face-regions.json](source/face-regions.json)。每个方向仅制作一次面部补片，再用于该方向全部相位；正面两个深色眼睛、侧面一个深色眼睛，均用肤色与头发隔开。保持原有四色和二值透明度。Pillow 用于读取和像素验证，没有程序绘制眼睛或人物。
