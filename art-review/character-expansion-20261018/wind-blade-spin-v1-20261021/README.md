# 风刃：放大后原地旋转，再发射

风刃保留原放大过程，放大完成后利用原有16帧停留段（第56至71帧／索引55至70，约0.266秒）绕固定中心旋转一圈，第72帧／索引71仍按原时刻发射。旋转第一相与最后一相分别为0°和360°，与原直立风刃对齐，衔接后续原飞行姿态。

旋转采用已有风刃整图的最近邻旋转，不重新绘制形状，不改变投射物数量。以原可见风刃中心登记，正确保留原镜像和翻转偏移，增加透明画布避免转动时裁掉尖端。敌方的风刃、扩散与消散使用简洁暗蓝色；友军完全保留原白色、浅蓝及淡紫像素配色。

人物动作、放大节奏、发射与命中时刻、发射后的轨迹、收势及总帧数保持。双方近距、远距和重甲参考共12个动作变体同步，先前火球、雷电、诸神黄昏、圣光萤火虫和地图稿保持。
