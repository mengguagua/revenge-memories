# 骑士待机与侧向行走 · 衔接修正

本轮修正双方骑士的待机、向左与向右行走。仅对照稿，未接入游戏，待用户验收。

上一版以y=54横线拼接三张不同姿势，横线穿过了骑手衣甲和鞍具。不同稿件的轮廓与材质在此处不一致，造成服饰割裂；把腿连通视为通过也不足以保证正确的解剖衔接。

本轮取待机第0姿势作为完整主体，保留骑手、服饰、盾牌、鞍具、马腹和尾巴。四条马腿只在各自可独立分离的y=64以下处理，前两行腿根连接像素固定；下段按照膝部与蹄部的路径弯折，所有像素来自同一张原像素稿，没有再拼入另一个姿势的马腹或服饰。

- 主体与腿根的y=0至65区域在所有姿势中逐像素一致，尾巴完整固定。
- 四条马腿各自连通，互不合并，且与固定主体保持连接。
- 左右按x=64镜像，中心稳定。
- 待机仍为0／1／2／1相位和14／8／14／8帧；左右行走仍为0／2两相，每相16帧。
- 双方各自配色、原作时间轴、向上与向下素材、全部战斗素材保持。原始稿及上一版留档不覆盖。

`asset-manifest.json` 记录腿根、弯折路径、逐图尺寸及大小；`verification.json` 记录完整主体和连接像素一致、四腿独立连通、镜像、原时序与未改素材检查。`export-report.json` 为18个地图动作静帧与10段演示的导出和解码检查。检查不等于用户视觉验收；本次未启动Godot或回传聊天图片。
