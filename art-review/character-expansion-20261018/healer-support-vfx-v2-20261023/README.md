# 疗愈师／济世术师 · 四种辅助法术特效修订

本轮修改我方疗愈师、济世术师的远程恢复41、吸血42、传送43、全体恢复44，共48项原作变体。人物、法杖、宝瓶、地图动作以及已确认的恢复40保持，仅更新美术对照。

## 本轮效果

| 法术 | 修订后的效果 | 结算与动作 |
| --- | --- | --- |
| 吸血42 | 原橙色效果改为柔和红色；起始目标处出现抽取旋纹，红色能量由目标持续牵引到施法者。 | 人物原动作、原能量球位置与唯一伤害／吸血结算保持；能量流是视觉表现，不新增伤害次数。 |
| 远程恢复41 | 复用已确认恢复40的绿色光环、雨滴；雨滴由36帧延长至54帧，约0.9秒。 | 原施法和恢复结算保持；必要时在原作结束后延长少量展示收尾。 |
| 全体恢复44 | 全阶段改为绿色；多处光环化成绿色雨滴，雨滴后在下方汇成一片同色泉水，出现水花、波纹并收束。 | 沿用原作可见光效落点，雨滴和泉水只延长展示，不追加治疗。光效落点不代表增加受术者，空白占位特效也不当作新目标。 |
| 传送43 | 在受术者原作参考位置增加蓝色光柱，由地面升起，在原结算后散成蓝色光丝。 | 不改变施法者动作、合法落点或行动规则；光柱不表示增加行动。 |

原作人物帧、位移、帧率、时序与结算时刻逐项保持。原作播放结束后，较长的绿色收尾会在对照页明确标为“原作结束，新稿……收尾”，左侧停留原作末帧，右侧人物维持原站姿。敌方及其他职业法术不在本轮修改范围。
