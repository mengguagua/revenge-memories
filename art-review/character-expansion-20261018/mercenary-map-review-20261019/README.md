## 服饰与姿势辨认

已核对 class8 的原生战术移动八帧及待机三种姿势。衣服下方是分片短衣／裙摆，腰带以下仍保留腿部长度；单侧肩饰、束发、衣襟和靴子属于既有佣兵重绘身份。新图将这些结构简化为清楚的大色块，体量以 0.8.7 已验收的男主、弓箭手、枪兵为对照。

- 待机：头身和双脚保持固定，单手在身前持一把直剑；持剑整臂和剑改变位置及倾斜。保留 0→1→2→1、14/8/14/8 tick 源节奏。六个图集槽位按 0/1/2/1/0/1 复用。
- 向上：背面头部固定，交替支撑腿，剑位于画面右侧。
- 向右：人物朝右，剑仍在画面左侧，直立和跨腿两帧区分。
- 向下：人物朝前，剑位于画面左侧，交替落脚。
- 向左：人物朝左，剑在画面左侧，直立和跨腿区分。
- 左右方向分别制作，未将整幅图镜像后造成武器换手。向上第二相位仅重组已有腿部图层，不翻转身体或武器。
- 阴影：沿用已验收的 11×3 连续投影，透明度 0.38、偏移 [0,-1]。阴影固定在地面锚点，抬脚不会撤掉脚下投影。
