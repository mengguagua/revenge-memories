# 我方女魔剑士 · 全动作

本轮依用户补充只制作我方。原作职业11的敌方是僵尸，其动作不作为女性剑士使用，未制作或新增敌方女魔剑士。

本轮为美术验收稿，未接入运行场景、游戏规则或应用导出。

## 形象与武器

以已确认女法师的深蓝、蓝色、米白、肤色与柔和玫瑰腰带为基础，仅增加少量冰蓝。以高束长发、白色肩部防护、分片短战衣和完整护臂、靴边表现进阶；保留肤色和眼睛，头发纯色、衣料哑光。长剑参考用户冰晶剑：修长尖刃、浅冰蓝剑面、银白外缘、翼形护手和深色握柄。剑的造型不增加冰冻能力、伤害或额外命中。

生成源图完整保存在 source/，生成记录见 [generation-record.json](source/generation-record.json)。低透明外发光不进入交付单帧，材料统一为六种哑光颜色。姿势作统一缩放与整数像素定位，没有整体非等比拉伸；以头部、落脚位置核对对齐，保留完整轮廓与剑尖。

## 动作范围

共80项：9项地图对照、4项战斗待机及受击反应、67项战斗攻击／法术变体。制作58张交付单帧：6待机槽、8行走槽、44战斗槽。

- 地图待机使用原作0／1／2／1，每相14／8／14／8帧，展示两次循环88帧。固定头颈、躯干基准和落脚点，持剑臂及衣摆按各相变化。
- 四向行走使用原作每相16帧、三次循环96帧。上、下方向交替抬腿并保留双脚，向下正脸；侧向头、躯干与持剑姿态一起朝向行进方向。向左使用原作关系，镜像整幅向右动作。无整人左右／上下偏移。
- 普通攻击保留原作起步、起跳、滞空交替腿、空中转身、落地斩、起身、退步和收势顺序，共312帧，结算在零起算128帧，仅一次结算。19号原作斩弧完整保留在原位置，未增加额外剑击。
- 雷剑保持独立原作高举剑姿势，159帧，零起算122帧结算；六种距离／目标变体各自保留。
- 施法保留原作徒手准备、伸手、上举、释放及收势，剑在原作空手姿势中不强行出现。十类法术保留各自原始程序与总时长，9类同名法术的54组变体复用术法师已确认素材和效果阶段；恢复保留原作。未新增法术解锁。

职业参考库不等于全部角色已学会所有法术。现行设定中艾琳使用剑与个人法术，实际装备、学习、恢复和引光剑使专属规则继续由游戏原规则控制。本轮不表现未解锁专属能力。对应记录见 [action-effect-mapping.json](action-effect-mapping.json)。
