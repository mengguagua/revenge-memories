此前使用原作绿色草地的做法不符合本项目。现在左右人物对照均采用本项目实际使用的地面素材，保持原生像素密度、整数最近邻放大。

- 剧情：`actual/core/story_hub.gd` 中P00的石板材质与变体排列，来自 `actual/assets/battle_tiles/battle-tiles.png`。
- 战斗地图与待机：`actual/data/stages/M11.json` 的实际 `art_atlas`、`art_layers`，取首个部署位置周围地面，图集为 `actual/assets/battlefield-0.3.0/terrain.png`。

这些是从正式素材与布局复现的地面样本，并非游戏运行截图。具体图集校验值、取样坐标和格子ID保存在 `background-provenance.json`。
