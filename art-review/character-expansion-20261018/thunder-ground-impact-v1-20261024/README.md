# 双方雷电 · 落地冲击先于电弧分裂

统一双方10组战斗角色的60条「雷电」变体：艾琳双阶段、女魔剑士、术法师、执令术师、女法师、隙行术师、济世术师、博学术师、驭魔师。每组覆盖近距、双方远距与重甲目标组合。用户已确认本次雷电效果。仅修改隔离美术对照；不改运行场景、测试包、法术解锁或伤害。

以前的目标雷电首次出现就有分叉，缺少落地点的冲击反馈。新演出让单股闪电从上向下落，在原结算帧明确撞到地面，先出现紧凑爆闪，再扩成冲击冠、压力环与飞散碎屑，8帧后才出现分叉电弧，最后碎成小电屑渐隐。只有一次冲击，不反复落雷或额外结算。

| 相对原结算 tick | 新效果 |
|---|---|
| −6～−1 | 单股雷电从高处快速下落，未分叉、未触地 |
| 0～1 | 原结算时刻触地，紧凑白蓝爆闪与冲击冠 |
| 2～4 | 冲击向地面两侧扩散，压力环和碎屑强化冲击力 |
| 5～7 | 压力环继续扩张，中心爆闪减弱，仍不分叉 |
| 8～11 | 落地点开始向外分叉电弧 |
| 12～16 | 电弧进一步分裂、向外碎散 |
| 17～19 | 残留小电屑 |
| 20～23 | 电屑逐级渐隐 |
| 24起 | 本次落雷效果清空 |

落地点根据原雷电纹理底端的可见像素注册，新雷电尖端、地面冲击和后续电弧共用这一点。近景保留施法者并聚焦画面下部的落地过程，完整场景保留全部天空落雷。双方使用同一套16张透明索引PNG，六色白蓝／蓝紫阶梯与少量冷色碎屑阴影，无柔光底色残留、火焰色或永久地坑。

人物素材、人物帧序、前后手臂、位移、翻转、施法者既有蓄力、FPS、总帧数、原结算时刻与结算次数保持。落雷从结算前6帧开始显露，只延展视觉下降阶段，不提前或延后结算。雷剑和其他法术不在本轮修改范围内。
