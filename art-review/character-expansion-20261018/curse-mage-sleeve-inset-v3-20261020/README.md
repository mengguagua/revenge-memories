# 咒法师 · 袖袍外摆收拢

仅更新待机与向下行走对照稿，未接入游戏。

抬起的袖袍向身体内侧平移6输出像素，即1.5个原生像素；两侧镜像处理。袖袍图层相对肩位的向外伸出量由22缩为16输出像素，减少约27%。抬臂角度、高度和像素形状保持，双臂放下姿势不变。

头部、面部与眼睛、躯干、中轴、下摆、六色低饱和蓝紫和原节奏均保留。向下仍逐像素复用待机三姿势。用户已确认的向上、向左、向右行走沿用原素材、登记位置和动作。
