# 双方剑豪 · 待机、行走与战斗动作

2026-10-22。新增职业10「剑豪」的双方六个场景、40个动作，更新「角色重绘 · 全动作对照」。职业进阶为佣兵8 → 剑士9 → 剑豪10。冻结原始资料中的职业10沿用原名「魔战士／dread_fighter」，页面名称采用本项目现行设定。

## 形象与配色

使用内置 `image_gen` 设计新形象，采用比剑士更宽的米白肩甲、分层短衣、臂甲、护膝和软质短披风。保留自然肤色、眼睛和纯深蓝发色，不使用盾牌。原作地图上身后宽大的部分按披风处理。

盟军地图与战斗身体统一六种颜色：直接沿用已确认剑士的深蓝 `#172638`、蓝色 `#3976B5`、米白 `#E4E1C8`、肤色 `#DDA77D`，仅增加深蓝褶皱 `#2C527E` 和少量柔和金色扣件 `#B5A16C`。米白用于完整衣边和甲片，不添加头发、衣服的高光色或灰色过渡色。敌方保留深蓝轮廓、蓝紫衣料和浅冷色甲片，肤色仍保持自然。

生成源图、每组提示词与原作参考保存在离线 `source/`；完整源图不直接作为运行或交付素材。新身体姿态采用完整画稿等比缩放和整数定位，不通过代码绘制人体或扭曲关节。定位后的共享头部保留各自剑刃的前景遮挡，避免靠近面部的剑被头部覆盖。地图待机直刃复用已确认剑士所用的原生直刃，登记到剑豪各相的原剑尖和自身剑柄位置，避免旋转小尺寸生成刃片时形成假锯齿。

## 原作部位与动作含义

| 原作槽位 | 对应动作与本轮处理 |
| --- | --- |
| 地图待机0、1、2 | 固定头身与站姿，持剑臂依次向内收，披风在另一侧；保留三相与0→1→2→1循环 |
| 地图上0、1 | 背对镜头，右侧持剑，披风覆盖后背；左右脚交替支撑，不在后脑画正脸 |
| 地图右2、3、左6、7 | 各方向独立宽步与交叉步；侧脸朝相应方向，持剑侧与披风侧按原槽位，不镜像整个人物代替原作方向 |
| 地图下4、5 | 正面双眼，左脚与右脚交替支撑；一脚抬起、另一脚落地 |
| 战斗0、1、2 | 长剑斜挂在背后，双臂放下→伸臂→抬臂握柄；站姿和头部基准固定 |
| 战斗3、4、5、6 | 逐步压低双膝蓄势，手臂保持握柄动作，脚部依原作站位变化 |
| 战斗7 | 原生第8姿态向左10、向上24个逻辑像素后的离地身体，叠加原生两段起跳残影 |
| 战斗8、9、10、11 | 空中屈腿、拔剑举向上左、转为上右举剑并以双脚落地准备下斩；没有增加挥击或结算次数 |
| 战斗12、13、14 | 低位斩击收势；13使用同一12身体并叠加原生刀弧；14为上举恢复姿势 |
| 战斗15 | 原作有意保留的透明离画区间，保持为空，不用待机或额外身体补齐 |
| 战斗16、31 | 与0相同的原生待机背景槽位；敌方保留背景存储向左16逻辑像素的偏移 |
| 战斗32 | 与14相同的举剑身体，原生背景上传仅多1个浅色填充像素；重绘保持同一完整举剑姿态，用于雷之剑原程序 |

战斗动作允许原本的下蹲、起跳和原程序位移；登记基准固定，不另加整幅角色的摆动。地图各方向共用固定头部，保留自身武器遮挡、原有腿相和完整四肢连接。首批重复支撑腿、低持待机剑和落地仍抬腿的画稿已另行重做，未作为对应槽位的最终素材。

## 覆盖与验收

双方各20个动作：地图待机、四向行走、四向停止，共9项；普通攻击、六种雷之剑变体，以及战斗待机、未命中、受击、退场，共11项。新增40项后，对照页为85个场景、687个动作；647个既有动作内容摘要保持。
