# 咒法师：战斗服饰与三种法术

敌军咒法师的三组战斗身体采用与行走稿相同的低饱和蓝紫调色板，保留原服饰轮廓、位置和所有源图。友军服装保持。

- 火球：沿用原三相火焰，头顶六级蓄大（0.5到1.2倍），停留由35帧增加到43帧；相应收紧最后飞行段，原总帧数、命中时刻保持。
- 雷电：起手不再出现头顶闪电，替换为法杖从倾斜到举定的三步动作；复用现有疗愈师法杖的杖头和干净杆身像素，手指覆盖杖杆。释放后的目标落雷逐帧保持。
- 诸神黄昏：五枚火焰先贴地22帧，再以8帧间隔逐枚斜上飞出28帧。只改82帧的轨迹段，近距敌军为全片19.52%，友军为19.85%；起手和后段爆发保留，不新增伤害次数。
- 敌军火焰共用暗蓝、灰蓝和冷亮芯三色；友军保留原红色火焰。三种法术的双方近距、远距和重甲参考共36个动作变体同步处理。
