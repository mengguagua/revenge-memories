# 士兵系职业名称统一

按现行游戏设定 `docs2/完整游戏设定.md` 与用户确认，统一展示为 **士兵 → 重装兵 → 壁垒卫士**。

| 游戏职业 | 原职业编号 | 对照页角色 | 已有对照内容 |
| --- | --- | --- | --- |
| 士兵 | 6 | 盟军士兵、敌方士兵（原“枪兵”） | 双方战斗地图待机、四向行走、战斗动作；盟军另有剧情地图 |
| 重装兵 | 2 | 盟军重装兵（职业样板） | 盟军战斗地图待机、四向行走、战斗动作；敌方暂无独立稿 |
| 壁垒卫士 | 22 | 盟军壁垒卫士、敌方壁垒卫士 | 双方战斗地图待机、四向行走、战斗动作 |

角色选择、职业／场景、动作目录与新导出的标题均使用上述名称。重装兵移除内部 `sol` 名称后缀，保留职业样板提示。枪兵与士兵是同一职业，不重复创建角色或更换美术；原角色 ID、源职业编号、素材路径、帧顺序、动作节奏和结算时刻保持。

页面上方增加三个进阶阶段的已有角色入口。原动作链接继续有效。构建工具也会把旧稿中的枪兵别名归一，避免重建后恢复旧称。本次仅更新美术对照页及其名称来源，不修改运行游戏、卡牌、职业数值或升级规则。
