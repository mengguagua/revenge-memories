# 双方弓骑士 · 全动作重绘

2026-10-23。职业20，进阶为「弓箭手 → 狙击手 → 弓骑士」。本轮补齐双方战斗地图待机、四向行走、四向停止与战斗，共6组场景、44项动作，供视觉验收。

## 形象与配色

新形象采用白马、加厚米白肩甲及胸甲、开放面甲、大型箭袋和大型反曲弓，强化骑乘后的力量感。地图弓具补齐上、下弓臂和弓弦，以固定握点登记，保留完整武器轮廓。

盟军采用弓箭手的深蓝、蓝色、米白、自然肤色，加木色与少量冷色阴影，共六色；敌方采用对应蓝紫色材质。头发为纯色，服饰哑光，白马及护甲的桃色杂点已清理；肤色保留在骑手面部和双手。飞行箭矢沿用已确认的木色箭杆、米白箭头与尾羽，保留本职业较长的原生箭矢轮廓。

## 动作与中心

地图待机按前双腿抬起、四腿站定、后双腿抬起、四腿站定循环，姿势0→1→2→1，原生保持14／8／14／8帧。骑手头颈、胸腹、鞍位和马身使用同一完整上身区域，腿部在其下换姿，避免人物整体晃动。

上、下行分别保留伸腿、收腿的两相，人物中心固定，下行保持正脸双眼。左右行走整幅复用原作已证明一致的侧向姿势0／2；右行只对完整姿态镜像。原生每相16帧、32帧一循环，对照页展示三个循环；方向停止保持32帧。源图的对应关系已逐像素核对，未套用其他骑兵职业的额外动作帧。

盟军战斗依次为低位持弓、备箭、抬弓、直立举弓、上弯满弓与释放收势，对应原姿势1、13～18；敌方保留自己的1、5、6三相程序。射击时马匹四腿站定。双方近远距离、重甲目标与盟军圣弓共18条原生攻击程序完整保留，每次程序仍为一次命中；未因大型武器增加连击或额外效果。

## 制作与验证

形象、完整姿势与独立大弓由内置 ImageGen 绘制。[初始提示词](source/generation-prompts.json)及[实际修订提示词](source/actual-pose-prompts.json)完整保存。原图位于source，离线保留；运行帧经过六色材质登记、整幅等比缩放、整数定位及透明轮廓检查。地图握点和弓弦登记记录在[素材清单](asset-manifest.json)。

[原作参考与时序](native-reference-audit.json)记录双方动作程序及源图摘要；[角色、武器与效果对应](source/action-effect-mapping.json)记录释放与结算。当前工程以职业、装备执行动作，没有相应独立角色卡牌定义，因此以现行普通弓／圣弓程序为依据，不新增卡牌能力。

[验证结果](verification.json)：44项均可播放，原有731项动作摘要保持；18条攻击的每帧姿势、位移、外置效果、帧率与结算时刻一致。地图固定中心、原生侧向复用、双阵营材质、38张角色帧的完整透明轮廓及资源尺寸已检查。47段播放文件包含44段全景及3段近景，已解码核对帧数和时长，另保存地图相位与射击关键姿势的原作同步检查图。

画面检查采用深浅背景姿势板及对照播放器相同数据的离线合成器；浏览器页面未重新渲染。本轮只更新美术对照，未接入游戏业务代码或重新打包，等待用户视觉确认。
