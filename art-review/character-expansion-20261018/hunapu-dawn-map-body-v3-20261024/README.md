## 本轮修正

- **剧情向上**：抬起的膝与脚跟收在髋部下方，沿前后方向后摆，脚尖不再向两侧外撇。两相均保持佩剑在原侧，双手与腿反向摆动，肩、肘和上身有连贯的小幅转动。
- **剧情左右**：重新制作完整人物的站直／跨步姿势，手臂前后摆动、肩胸转动和衣摆随步态一起变化。没有沿腰线裁切、单独替换腿部，也不冻结整块上身。头部和腰部中心保持稳定，局部关节保留自然动作。
- **战斗地图左右**：按原作正面持械横向移动重做，脸、胸与双肩朝前，盾牌由弯曲前臂持在胸前，盾面覆盖前臂和部分胸口。原作向右2／3槽位采用窄步→横跨，向左6／7采用横跨→窄步；剑盾摆放遵循各方向原图，不再解释为侧身向左或向右行走，也不额外套用一套固定手位规则。

剧情与大地图继续共用同一套人物。集中阴影、战斗待机，以及已完成的普通／必杀第二剑和火花演出保留；本轮只更新三个地图场景组的24项行走与停止对照。
