# 枪兵待机、侧向迈腿与男主大地图阴影修订

本轮双方枪兵先更新对照页，等待用户验收；不接入游戏。友军剧情仅同步同款待机首帧。

- 待机重新使用独立的固定身体、单根长枪、连续裸露持枪手臂。正面脸、躯干、另一只手臂及双脚固定。长枪和持枪手臂保留原作偏移 `(0,0)、(-4,0)、(-4,-4)` 及原作别名/节奏。枪杆在身体后方遮挡，持枪手臂在前方，肩部作为固定遮挡点；不从含武器的旧身体复制枪尾。
- 左右行走保留已有固定头部和躯干，以及原有手臂/长枪相位；腿部改为支撑与向后抬脚、前跨与后脚的交替姿势。左向由右向同相位镜像，6 对应 2、7 对应 3；每姿势 16 原作 tick。上下行走不变。
- 使用四色与二值透明，输出仍为待机 96×96、行走 128×96；独立地面阴影保留。
- 男主大地图改用已验收的剧情地图连续 11×3 阴影，同位置偏移及透明度；人物像素和战斗地图阴影不变。此项同步游戏测试包 0.8.5，弓箭手保留 0.8.4 已接入版本。

美术通过内置 ImageGen 编辑生成，原图与完整提示词保存在 [source](source/)：`idle-layers.png`、`idle-prompt.txt`、`side-walk.png`、`walk-prompt.txt`、`walk-alternation-prompt.txt`。原图离线留档；交付图通过 ImageMagick 做切图、尺寸注册、限色、图层遮挡、镜像及无损压缩，不用代码绘制人物部位。

查看 [动作总览](overview.mp4)、[逐图尺寸与字节数](image-inventory.json)、[验证记录](verification.json)。技术检查包含别名、方向、固定部位、调色板、透明度和未修改动作摘要；实际动作观感以用户验收为准。浏览器本地访问限制保持原状，采用同一对照渲染器导出验证，不声称已完成浏览器实播。
