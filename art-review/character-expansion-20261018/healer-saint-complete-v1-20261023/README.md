# 疗愈师 → 济世术师 · 我方全动作

本轮同步“优化问题1”对话中的现行职业名称，并制作我方疗愈师、济世术师。只更新美术对照库，未接入游戏运行逻辑；视觉验收待用户确认。

## 入口与形象

- [全动作对照](../index.html)：默认进入济世术师待机，页面上方新增两职业的待机、四向行走、战斗法术及恢复入口。
- [疗愈师地图全姿势](class-18-maps-light.png)、[疗愈师战斗全姿势](class-18-battle-light.png)：白色兜帽、单层肩部、蓝白长袍及细长法杖。
- [济世术师地图全姿势](class-17-maps-light.png)、[济世术师战斗全姿势](class-17-battle-light.png)：双层白肩披、长披巾、玉绿额饰与几何纹垂带，身形保持修长；宝瓶依用户参考保留细长颈、圆腹和小底座。

沿用女法师的深蓝、蓝色、米白及自然肤色，增加一种柔和玉绿色，移除大面积红灰。头发单一深蓝，衣料哑光，无光泽渐变；保留眼睛、肤色、必要轮廓与衣褶分区。两职业均为女性形象，与原作人物部件对应。

## 原作动作与效果约束

疗愈师43项、济世术师97项，共140项。包含每职业地图待机、四向行走、四向停止、战斗待机／未命中／受击／退场，以及114项法术的近远距、阵营站位与重甲目标原程序变体。新增97项济世术师动作，疗愈师原有43项更新形象。

- 地图待机沿用原作14／8／14／8帧顺序，两次循环88帧；行走每相16帧，32帧一轮，展示三轮96帧。头颈和躯干固定，长袍与脚步换相，不增加整体摆动。济世术师向上原作两槽完全相同，新图同样保持相同。侧向停止使用对应原作槽位，四向均保留连续地面阴影。
- 疗愈师保留原作持杖与双手举起两个战斗姿势，杖与持杖手一起运动，完整杆身不残留到另一帧。
- 济世术师保留原作12个战斗槽位，按伸臂、举臂、手到额前、收势的原程序顺序播放；宝瓶由另一臂稳定托住。白瓶不是额外投掷物，不新增攻击次数、治疗量或技能。
- 济世术师的火球、雷电、诸神黄昏、圣光、风刃、箭雨、光环、鬼火、史莱姆，共54项变体，复用已确认术法师的同名特效；各阶段对应本职业的原始施法和结算时刻。人物动作行、时长和接触时刻保持不变。
- 恢复40复用已确认的柔和绿色光环，在原结算后12帧开始转为绿色雨滴，36帧内完成收尾，不追加恢复结算。疗愈师此前已确认的绿色恢复程序完整保留。远程恢复41、吸血42、传送43和全体恢复44保留各自原作效果，不混为新的绿色治疗能力。

这是职业动作样板库。芙拉、米蕾、赛琳等角色仍按各自已学法术、消耗和目标规则行动；展示完整原作变体不等于为所有同职业角色解锁全部法术。卡牌／效果与触发时刻逐项记录在 [动作效果对应表](action-effect-mapping.json)。
