# 断路匪待机 · 颈肩衔接修订

后续已补下颌线与颈部轮廓变化：[最新修订](../brigand-idle-jaw-v3-20261023/README.md)。下文保留本版制作记录。

修复待机时头颈像与身体分离的问题：废弃旧版跨过下颌和衣领的固定复制框，重绘连续的下颌、颈部、V领和肩部色面。保留蓝紫少色衣服与纯色头发，去掉横在喉部的深色带。

三姿势按右肩前提、回中、左肩前提、回中播放，仍为原 `0/1/2/1` 与 `14/8/14/8 ticks`。肩臂动作收敛：第0到第2姿势的左臂肤色质心垂直差由3.31降至2.43输出像素（约减少27%）；持斧手由2.77降至0.36输出像素。这是局部形态量取，不等于整个人物的位移。头部地标最大差约0.081输出像素，腰部约0.201；下半部与脚底固定。

本轮只更新敌方断路匪的地图待机美术对照。待机输出帧为96×96，源图与三姿势绘制提示词保留在本目录。使用内置 `image_gen.imagegen` 编辑，源图见[生成记录及完整提示词](source/generation-record.json)。

已人工检查深浅底四连帧、实际显示尺寸及新旧对比，颈部肤色从脸到领口连续，手与斧头完整。32项必要检查涵盖色面连通、注册、透明度、尺寸及原循环。浏览器工具拒绝读取当前的 `file://` 页面，因此本轮采用离线逐帧与视频导出检查，没有声称浏览器实测；最终视觉效果供用户确认。

单动作集成的14项检查通过，导出视频为88帧、1.464256秒。最新共享对照数据已更新；其余117个配置、1222个动作的内容哈希保持一致。
