地图行走现为经 CPU 与独立 ROM 表解码交叉验证的 bank011:L0BB5B1、CHR19 原生八槽，输出 128×96；顺序 up 0/1、right 2/3、down 4/5、left 6/7，每相 16 tick。6/7 与 2/3 原始完整 RGBA 确认互为镜像；其余六张均 ImageGen 新绘。源 CPU 已执行方向翻转，播放不再额外镜像。静态 96×96 三相及已审战斗素材保持原文件。

此前“ROM FF 为空导致缺半头”的说法撤回：旧参考把村镇 OAM 错配 CHR26，正确村镇 CHR30 的 FF 并不为空；旧混合源也不是原生战术行走。本轮按正确 CHR19 原槽直接绘制，不称作补头修复。旧稿、旧映射与对照仍保留在历史文件中。

上向右杆小浅色端低于头顶，下向左杆底部长浅色端，侧向左上短木尾与右下钢尖，均按本职业可见轮廓处理，中段保持身体遮挡；不推断隐藏枪端旋转路径。脚位按可见靴 ROI 整帧平移登记，衣摆不当作隐藏髋膝。新图不声称每一服装边缘逐像素一致；同方向头部约有 1–5 输出像素自然描绘差异，未为凑武器端点移动身体。

透明边缘在深浅底实看。前向 v2 半透明雾底由 ImageGen v3 专门清除；代码没有抠背景。保留画布内 PNG 原始 alpha；靴底使用可见 alpha>4，横向选取 alpha>=128 的靴底；画布外仅有 alpha1–3 微弱噪声被登记裁掉，零 alpha>4 轮廓裁切。新行走独立帧 5,510–6,026 字节。

`battle/frame_mapping.json` 与 `maps/frame_mapping.json` 记录源帧、别名、输出、尺寸、字节、哈希、提示词与登记依据。所有原始生成图、失败稿及提示词保留在各 `source/` 中。技术处理仅使用矩形裁切、统一等比缩放、整帧平移、原规则镜像与无损压缩；透明像素隐藏 RGB 归零不改变任何可见像素。
