# 源角色部位与动作

- 本单位是敌方男爵（徒步重甲），并非因关卡称“盗匪”而改为轻装强盗。
- 肩颈浅色宽弧属于护甲/衣领；长盾在前臂。腰下是分片裙甲，后方延伸的片状轮廓不计作第三条腿。
- 新设计保留重甲层次，改为银灰短发露面、深钢甲/铜边、酒红分片腰布与长盾。源盔上角饰不作为身体头顶长度；人体登记取源头部约y30至靴底64，另保留原参考完整盔饰。
- 原0与13紧边RGBA逐字节相同，13=0左移16原像素；24=13。参考证明另存，切勿按盟军普通别名处理。
- 源25横举投枪；原27有真实手臂变化，和本类13的差异不只是去枪，必须单独绘制，不能套骑兵19规则。
- 战术移动旧参考正在全局重审，暂停按旧sprite51绘制；静态待机与battle源不受此问题影响。
