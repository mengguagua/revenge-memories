# 盟军重装兵地图结构

原版真实战术CHR19已与CPU表核对，6独立姿势+2严格全画布镜像。静止6槽另取独立24×24源图。

静止左侧突出物位于x4–8,y9–12，黑轮廓+紫甲色，与胸肩连为短护臂/握持块；三相没有独立白色刃或连续细杆，不能补长枪。右大方盾明确。移动侧面单独存在短白色外伸段，不可反推静止长枪。

地图盾为原图明确结构，战斗关键姿势没有独立巨盾轮廓；两种场景按各自源结构制作，不强行统一遮挡。

盾相补充：0/1上框大致同高，1新增的低位白块不支持整盾下移；2右侧白边向下延伸。按各相上缘/侧缘/低位块分别对应，不将三相强行解释为整盾等距下移，也不将不连续低位块连成长盾或擅称裸手。
