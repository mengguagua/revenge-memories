# 第一章敌方妖术师：原图辨认

来源为 class15/enemy，战斗三张完整身体帧是 0、4、5。原框80×64、输出320×256；待机和前伸姿势的头顶到衣摆约32原像素，举臂姿势的上端更高，不能把举手后的整图高度当作身体变长。

明确可见：尖顶兜帽、宽大的浅色肩领/前襟边缘、覆盖下身的长袍及向右铺开的衣摆。下肢大部分被袍子挡住，不能按衣摆折线推断裸腿、髋或膝。头部内侧还有浅色须状细节，与外侧宽领边分开处理，不把它当作一只额外的手。

- 0：身体朝屏幕左方略俯，手臂收在宽袖边，袍下端固定。
- 4：双臂上举；屏幕左侧臂接近竖直，右侧臂向右上张开。袖口与露出的手必须区分，不把整段绿色袖子画成裸臂。
- 5：身体略前倾、两臂向左推出，前后手有高度差，袍下摆仍在原位置。
- 源图没有手持法杖、书本或常驻火球。法术特效是外置资源，不能把新法球画死在身体图里。

新设计方向：炭黑与深梅紫的分层长袍、灰白宽领、暗铜扣件，浅肤色的清楚面部、兜帽内灰发与修整的灰须。保留原短而宽的罩袍轮廓、遮挡和手臂动作，重新组织衣襟/肩片/袖口与饰边；不套用男主的蓝发白衣裙甲，也不靠原图颜色做整片替换。

地图移动原六槽实际只有两步相，仍按原时序和源别名处理；地图待机独立辨认。当前只准备参考，游戏资源未修改。
