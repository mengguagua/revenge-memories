## 颜色和透明度

每张男主角色图严格使用4种不透明颜色：`#172638` 深蓝轮廓、`#3976B5` 蓝、`#E4E1C8` 米白、`#DDA77D` 肤色。透明背景单独保存。没有棕金配件、材质渐变或额外高光；透明边缘使用像素图的硬边导出，原始生成图和原始alpha另行保留。

地图阴影为独立固定地面层，复用原生投影位图，不加入角色调色板。它在角色脚底基准处绘制，避免跟随四肢抖动或被精灵画框底边裁掉。原地图地面仅为对照页的原生草地贴图预览，不修改游戏地图。

## 动作约束

- 剧情行走：固定头部与躯干，组合四肢局部变化；佩剑保持收鞘。
- 战斗地图行走：固定头身、剑及持剑手，组合腿脚、持盾手和盾的变化。
- 战斗地图待机：固定头身底图与腿脚，组合双臂、剑和盾；举剑允许遮挡部分头发，面部位置不变。
- 待机大小修订：三种姿势共用同一裁图范围和约90.14%的等比缩放；可见高度由71降至64像素，对齐原作16像素的四倍高度。脚底基准仍为y=80，不分别居中或归一化各帧。缩放前文件保留，实际交付使用 `deliverables/hunapu-idle-size2/`。检查见 `idle-size-qa.json`。
- 四向、镜像关系和原有节奏不变。战术左向严格复用原生证实的跨相镜像6←3、7←2。

`layer-contract.json` 记录允许变化的局部区域与保护区域。`layers/` 保存固定底图、活动部件和遮罩；`fixed-layer-qa.json` 检查固定区、面部和躯干区域的RGBA一致性，并确认活动像素实际发生变化。该检查不替代用户对姿态和美术风格的判断。

## 来源与复现

使用内置 ImageGen 进行重绘；没有用代码画人体或武器。最终提示词为 `source/hunapu-four-color-prompt.txt`、`source/hunapu-story-four-color-prompt.txt`。原始生成图为相邻同名PNG，最终选源由 `selected-sources.json` 指定。

技术流程：`tools/register.py hunapu hunapu-story` → `tools/assemble.py` → `tools/scale_idle.py` → 检查深浅背景、连接处与动画 → `tools/package.py` → 根目录工具 build/export/validate。技术处理只做裁图、同组等比缩放、四色情况下的统一调色板导出、图层组合、原投影复用与压缩。

第一轮12色候选已被用户否定，保存在 `candidates/*-color12-rejected/`，不得误当最终稿。其它兵种在缩减范围前产生的试稿没有交付或挂入对照页。
