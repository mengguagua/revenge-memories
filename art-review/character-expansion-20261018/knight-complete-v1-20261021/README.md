# 骑士 · 双方全动作补齐

本轮新增独立职业编号4「骑士」，对应「骑兵1 → 骑士4 → 大骑士7」。待用户进行视觉验收，未接入游戏或测试包。

- 双方各20个动作：战斗地图待机、四向行走、四向停止，战斗普通攻击、6种投枪配置及待机／闪避／受击／退场。
- 地图固定头部与上半主体的同一像素区域，马腿按原相位运动。待机按0／1／2／1顺序、14／8／14／8帧循环；行走两相各16帧。左右行走使用原生待机0／2相对应的腿姿，已核对原作紧轮廓RGBA完全一致。
- 战斗平地姿势按面部定位点登记，去掉素材本身的多余横向和纵向位移；冲锋、转身、跃起和回位属于原作编排，保留原轨迹。敌方背景姿势补偿原生16逻辑像素偏移，避免OAM与背景姿势切换时跳位。
- 友军最多16色蓝白配色，提高柔白面积，保留少量肤色、木色、米金及清楚的阴影；敌军最多16色暗蓝、蓝紫与冷色高光。地图与战斗使用各方同一调色板，不做灰色整体罩层或抖动量化。
- 投枪沿用已确认形象，友军木色枪杆与金属枪头，敌军蓝紫色；原轮廓、方向和轨迹不变。
- 普通攻击：盟军270帧、命中第194帧；敌军273帧、命中第197帧（从0计）。双方投枪第21帧释放，近距分别第54／53帧命中；重装目标和远距配置保留各自原表，不复用一条时间轴。

## 素材依据

使用已存在的编号4骑士地图三姿势、正背面稿和12张战斗姿势稿，登记、精简颜色并补齐原作槽位。保留头盔、骑士甲、盾与骑枪，未借用骑兵1或大骑士7的身体。敌方为同职业对应姿势的独立调色版本，使用敌方自身原生动作表；没有把双方原作像素声称为完全相同。

原始稿保留在 `../professions/class-4-ally/`。本轮各方28张独立帧（地图14＋战斗14），均为96×96、128×96或320×256；透明轮廓清理后做最近邻登记，固定上半区域，未裁掉可见武器／四肢。大图集仅用于离线验收，已无损压缩。
