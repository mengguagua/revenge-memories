# 独眼、飞枭、普罗米修斯 · V2 美术预览

[全动作对照](../index.html) · [交互预览](index.html) · [V1 历史稿](../puppet-trio-v1-20261105/index.html) · [数值](design.json) · [动作与结算](action-effect-mapping.json)

- **独眼傀儡**：地图待机改为双侧同步、足底固定；核心完整和破损的四个向上姿势都显示背甲。治疗场景取 F25 当前地图数据第 `(14,6)` 起的 8×5 格及实机敌军枪兵。默认六名枪兵中五名受伤，另有八名受伤、空地及核心破损示例。只有实际回血的在场队友出效果；空地、满血、本体及对手无治疗特效。
- **飞枭傀儡**：青钢、骨白和旧铜，双喷口嵌入背甲；完整引擎在爬升、俯冲和战后再移动时表现尾焰。攻击是起飞、收翼、俯冲、双爪命中、回位，只结算一次；引擎破损仍能靠双翼完成，取消尾焰、穿甲和战后移动。
- **普罗米修斯傀儡**：窄腰、长肢、高肩鳍、无脸面罩，炭黑、骨白、暗红褐。火焰分为蓄势、长焰推进、卷焰冲击、余烬四段，只有火之核心完整时可用。最终击败时站姿留在原点，爆炸峰值隐藏本体，碎片和烟散去。生命核心仍可用时先站姿复苏，保留原来的火核状态。双核四种外观均可选。

三种新角色的主体和特效预览 PNG 统一压低饱和度，以现有敌军弓箭手等像素素材为调色参考。保留外轮廓与核心、喷口和火焰的亮度差。地图和实机枪兵使用原配色。设计数值、经验及撤离规则沿用 V1，本轮没有改运行代码或投放关卡。

生图使用内置 ImageGen，工具没有提供模型选择，当前环境也未配置 OpenAI API 密钥，因此没有验证是 2.6。可单独选择的型号见 [OpenAI Images API 模型列表](https://developers.openai.com/api/reference/resources/images/methods/generate)。[原图与提示词索引](source/prompts.json) 对应 `source/` 隔离目录；未采用的生成姿势不放入预览素材。

[素材记录](asset-manifest.json) 逐张记录用途、像素尺寸和压缩后字节数；[定向检查](qa/verification.json) 包含运行目录比对、资源与时间线检查、页面交互和画面合成检查。合成图用于核对原生像素、透明轮廓与动作构图，不等同于浏览器截图。本地文件未在浏览器中渲染验证。
