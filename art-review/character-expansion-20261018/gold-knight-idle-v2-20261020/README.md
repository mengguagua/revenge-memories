## 动作与配色

- 循环：双前腿抬起 → 四腿站定 → 双后腿抬起 → 四腿站定。沿用原 14／8／14／8 帧保持时间，以 60.0988 FPS 播放两遍，共 88 帧。
- 马身、头颈、骑手、长枪、鞍具和尾巴使用同一张登记底图，只有前后两组腿的局部图层替换。画面中心不漂移。
- 第三姿势使用站定帧的完整双前腿，两只前蹄分开着地；两条后腿同时抬起。生成原稿缺失的远侧前腿已补齐，发布素材未使用缺腿原稿。
- 六个原生槽使用三张关键姿势及原有别名。站定帧完全相同，保留原朝向、逻辑尺寸和锚点。
- 三姿势统一 8 种不透明颜色，以灰白、低饱和淡金为主，去除亮黄／橙色碎高光及蓝色鞍布；角色有效边界约 76 × 70 输出像素，保持上一版体量。

## 制作与保存

使用内置 **image_gen edit**，参考旧版黄金骑士、原作三个姿势和已验收男主地图形象。两轮完整提示词保存在 [source/prompts.json](source/prompts.json)。原始生成图保留在 `source/`，作为离线制作源图，不属于运行素材；第二轮原稿仍存在远侧前腿缺失，登记时以站定帧的完整双前腿替换。

最终将生成稿按最近邻登记到 96 × 96 透明画布，统一调色板，并以站定帧固定人物、马身及武器。可复现脚本为 [revise_gold_knight_idle.py](../tools/revise_gold_knight_idle.py)，检查脚本为 [verify_gold_knight_idle.py](../tools/verify_gold_knight_idle.py)。

运行候选每张约 3 KB，输出 PNG 仅有 0／255 透明度。图集、对照图、视频与逐图尺寸和字节数见 [asset-manifest.json](asset-manifest.json) 和检查结果。原始生成图为保留的制作源图，未为体积降低其原始质量。

只改变一个待机动作的内容签名，其他 546 个动作保持原签名；4595 个被记录的游戏工程文件哈希保持一致。未启动游戏窗口。检查包含固定部位逐像素一致性、两只前蹄、抬腿后原落地点清空、帧序与时长、透明边缘、深浅背景、导出视频解码画面和文字内容安全区。
