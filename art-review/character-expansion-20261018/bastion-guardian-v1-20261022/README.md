# 双方壁垒卫士 · 全动作重绘

双方身体使用同一套14色材质索引。盟军为柔白甲片、弓箭手同系主蓝3976b5、深蓝轮廓，保留自然肤色、木色与钢色。敌方为暗蓝紫、冷蓝紫甲片及克制的肤色。头发内层统一纯色，去掉原亮发丝；衣料采用主色与必要暗褶，不保留亮斑高光。白甲保留基本明暗，避免轮廓合并。

完整人物由内置 ImageGen 参照既有姿势重新绘制；生成提示词和原始源图保存在[source目录](source/)。地图3个待机姿势、6个独立行走姿势，左右行走按照已核对的原作整图镜像。战斗14个独立姿势，映射到16个原作图槽。投枪复用已确认的手绘木杆钢头枪，并使用本职业80×16逻辑画布与40×8锚点。未切割或拼接四肢，未对肢体做拉伸变形。

地图以固定头部参照登记，待机画布96×96、行走128×96；每对行走姿势共用统一缩放比例。战斗画布320×256，身体图以同一头部参照登记。生成图只作整图等比缩放、整数平移与材质调色；战斗程序本来包含的接近、回位和受击位移保留。敌方背景姿势13／24相对盟军保留原作-64输出像素平移，投枪25／27保留-96像素平移，避免切换图槽时错位。

原作待机采用14／8／14／8帧循环；行走每相16帧，两相32帧周期。双方普通攻击均535帧、结算第245帧（从0计数）；投枪各距离、对重甲的不同时间表分别沿用各自原作，未用一方程序替代另一方。无新增攻击次数或额外能力。[职业与武器动作对应记录](action-contract.json)列出普通武器、投枪、动作及唯一命中时刻。
