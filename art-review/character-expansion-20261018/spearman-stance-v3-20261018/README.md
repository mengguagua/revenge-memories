# 枪兵侧身持枪与站直／跨腿修订

> 2026-10-18 更新：用户已验收。本版双方枪兵已接入 0.8.6 测试包，友方剧情统一为待机首帧静态形象。下文保留制作阶段记录。

本轮仅修改双方枪兵对照素材与友军剧情静止形象；游戏代码、运行资源和 0.8.5 测试包不变，等待用户验收。

## 本轮理解与姿势

上一版把“脸朝前”扩大成了正面身体和对称站立，枪杆还被身体遮到背后。这一版重做完整待机姿势：身体与裙甲侧向，前腿向侧前方踏出，后脚落后；头、躯干、两条腿及放松的手臂固定。另一只手在胸前明确握住枪杆，完整长枪和连续裸露持枪手臂作为一组移动。枪杆从左下枪尾斜穿身体前景至右上枪尖，不作为背部装备。固定头部和放松的手在需要时遮挡前方运动层。

左右行走按用户明确允许的简化方案制作：双腿站直并落地一帧，跨腿一帧。不是宣称已实现两条腿完整交错步态。保留原有头部、上身、手臂与长枪相位，左向为右向同相位镜像。上下行走保持不变。

待机保留原作局部位移 `(0,0)、(-4,0)、(-4,-4)`、别名 `0=4、1=3=5` 和循环 `0→1→2→1`，各段为 `14/8/14/8 tick`；行走每姿势 `16 tick`，均采用原作 `60.0988 fps`。原有独立连续阴影、简洁四色、二值透明和四倍输出尺寸保持。友军剧情仅引用待机首帧静止展示。
