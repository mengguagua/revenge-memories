HUNAPU / PHYSICAL

刀风压阵，剑弓分别出手

破阵：宽3格、深2格。进阶后纵深扩到4格，忽略25%有效物防。基础版采用灰蓝刀风；进阶版改为青蓝主体、银白刃缘和青紫尾迹，铠甲碎屑保留少量暖铜色高光。刀风沿攻击方向推进；持弓版本切换为同角色弓箭造型，抬弓、拉满、放箭，使用实机箭矢逐目标单箭命中。

  1. 蓄势：双脚固定，举剑；弓版抬弓并拉满。
  2. 释放：挥剑时推出刀风；松弦时箭矢同时离弓。
  3. 命中：按阵列纵深先后结算。
  4. 收势：手臂和武器归位，双脚始终不迈步。

EILEEN / MAGIC

焰环扩散，中心格更强

焰环：3格内选点，覆盖菱形5格。进阶后4格内选点，覆盖菱形13格；中心格保留额外＋4伤害。窄而明亮的中心火柱与低位外焰环共同表现一次爆发。

  1. 蓄势：双脚固定，举剑聚起火种，随后以约102°弧度下劈。
  2. 释放：单次下劈引导火种落向选点，双脚固定。
  3. 命中：火柱与焰环同步结算一次。
  4. 收势：余烬消退，不追加灼烧伤害。
