# 全部战斗地图 · 场景与行动说明

打开本目录 `index.html`。页面参照「角色重绘 · 全动作对照」的深色分组、筛选与双栏展示方式，整理当前五章全部40张独立战斗地图：31场主线、9场支线。第一至五章分别为7、8、8、10、7张；序章无战斗，不另计。

## 使用

- 按章节、队伍、主支线筛选，或搜索编号、地点、任务。左右方向键切换当前筛选内的地图。
- 左栏显示无人物遮挡的初始场景全景，右栏可切换部署、交互、首领／敌军、剧情友军、预定援军、坐标和步兵通行。
- 点击地块固定说明；选择交互卡片定位可操作格。G切换网格，Esc清除选点。原生1×与放大2×保留完整图像，可在视图内滚动。
- 展开下方说明查看胜负条件、道路与建筑、初始兵力、剧情、战后去向和固定补给。目录卡片可直接切换地图。
- 页面使用本地脚本与图片，无需服务器或网络。下载压缩包解压后打开 `index.html`；“角色动作对照页”是项目内的参考链接，需要原项目目录，地图展示自身不依赖它。

## 图像与规则口径

场景由当前Godot地图绘制方法导出，调用现行图块、自然物和完整建筑素材，包括第五章低饱和修订；这是初始场景全景，不是逐关实际出阵的试玩截图。人物由可关闭的战术标记表示，未改动人物待机、移动或战斗动画。

每格原生16像素，外围各留32像素背景。坐标从地图左上角(0,0)开始，外围不属于地图。图像保留原生完整尺寸，PNG无损压缩，WebP目录缩略图使用无损编码。

地形名、回避、三类移动费用、初始任务提示与出口来自引擎读取结果。步兵／骑兵／飞行采用士兵、骑士、飞马三类规则进行对照，通行图不包含当前人物移动力、占位或敌方威胁，不代表可达范围。建筑操作优先采用配置的指定门前格，无指定时才按站格／邻接规则。守井按站位守护解释。

部署标注为候选格，不承诺实际出阵人数或名册。剧情友军独立列出。援军口是预定位置，实际触发与落点受回合、空位与剧情状态影响。召唤、开门、船车移动、撤离、记录损失与战后分支等动态状态，以游戏实际流程为准；此页不模拟战斗。标记重叠时合并显示，点击可查看同格的全部对象。

## 文件与更新

- `images/`：40张完整场景PNG。
- `thumbnails/`：40张目录缩略图。
- `maps-data.js`：离线说明、网格和标注。
- `sources/`：40份关卡配置快照与逐关说明文本。
- `manifest.json`：地图数量、原图尺寸、体积与SHA-256。
- `runtime-info.json`：后台引擎导出的地形原始记录，不进入下载包。
- `verification.json`：数据、资源与页面验证结果。
