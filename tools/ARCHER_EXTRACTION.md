# FE2 弓箭手原版资源提取

`extract_archer.py` 只新增或替换弓箭手的地图图标、战斗身体帧和箭矢，不重新生成已经修正的村庄人物、中文文字或其他角色。

```sh
/Users/gcc/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 tools/extract_archer.py --source /private/tmp/fe2-analysis-20261012
```

来源为 `minirop/fe2` 提交 `956365ef33c63751e7afd03f05e600d7728549da`。游戏运行只加载 Godot 资源，不加载 ROM。

友军与敌军分别使用 `archer_arrow_ally.png`、`archer_arrow_enemy.png`。箭矢为 24×8，逻辑源位置为射手脚底加 `(0,-25)`。`L0FCB12-L0FCB2A` 的 OAM 镜像将每片图块 x 转为 `8-x` 并反射图块像素；因此完整 24px atlas 反射时，敌方绘图左上角需额外偏移 `(-8,0)`。该偏移只影响绘图，不改变箭的逻辑移动原点或接触判断。

## 动画时间与结算

原版普通弓攻击为 `bank005:L05B27A`，必杀为 `L05B2AB`，两段架弓程序相同。身体姿势顺序 `[0,1,2,0]`，等待为 `[16,16,1,0]` 个 NTSC 帧。射出后身体立即回到姿势 0，箭单独飞行。保持射手身体原位。

`L059673/L0596C5/L0596FD` 建立箭的 pose0、movement24、y103。movement24 经 `bank000:L00AE84 -> vector29 -> L00B125` 得到 14 个逐帧位移：

`[-16,-16,-14,-13,-12,-12,-12,-12,-11,-11,-11,-11,-11,-11]`，y 位移均为 0；默认右侧人物向左射箭，左侧人物反转 x 位移。

`L059D6D` 以对手 x±16 为接触阈值。当前原版原点 x176/x64 下，第 8 个位移帧越过阈值：箭 x69/x171。此时进行一次伤害结算；原始余下位移保留给未命中飞过动画，不代表第二次伤害。伤害后原程序等待 20 帧收束。

`L05B27A` 的 `1B 09` 使 `$04A6=9`，`bank000:L00BD80[9] -> L00BE1B` 设置 `$06D0=8`，即原版声效 `0x03`。复用现有 `hit.ogg` 作为射出音效；命中、未命中和生命格减少继续使用各自原版已验证音效。

只恢复作者写入的等待帧数和逐帧位移。原 6502 动画指令分派、PPU 上传等开销不逐帧模拟，NES RGB 解释沿用工程现有色表。`data/archer_animation.json` 保存来源、调度与原始数据；`reports/archer-assets-verification.json` 保存尺寸、体积、透明度和字节核对结果。
