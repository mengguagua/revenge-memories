# 自然地形物件 · 0.1.3

用途：据点外围、战场内部山林、世界地图的完整树木与岩石。朴素复古配色延续当前图集；排列参考《外传》的疏密群落、错位树冠和不等高山峰，避免矩形林块连续盖章。

本轮通过 **built-in imagegen（内置 imagegen）** 生成透明源图；参考图只用于既有材质/配色与《外传》的地理符号，不改变角色资源。

- 原稿：`../../source/natural-0.1.3/nature-sheet.png`，1312×1199，离线保留并通过`.gdignore`排除运行导入。
- 完整提示词与参考角色：`../../source/natural-0.1.3/prompts.json`。
- 运行资源：本目录20张完整透明PNG，16×16至48×32/32×48；元数据、原稿包围盒与字节数见`nature.json`。
- 16个源物件：四种常绿松、四种雪松、四种峰岩、灌木与三种小石；另有四个单格完整松树尺寸，适用于狭窄森林格。
- 世界地理符号可按元数据`size`等比缩至半尺寸，使用最近邻，角色、建筑与瓦片的像素比例不拉伸。战场和据点使用原生尺寸。

`tools/build_nature_assets.py`通过透明连通区域分组切出完整物件，不按生成图的平均行高硬裁。每张PNG保留透明边距，统一二值透明、最近邻采样，再用oxipng无损压缩。逐图尺寸/体积在`../../reports/natural-0.1.3/image-manifest.json`。

布局固定写入`data/nature-layouts.json`及关卡/世界图的`natural_props`。群落含成年树、幼树、灌木、错位与镜像，岩体按断续弯曲走势组合；调整窗口和行走时不重新随机。视口边缘仅绘制完整物件，避免半截树。原逻辑地形、道路连接、碰撞、对象与任务条件保持原定义。

验收：10处据点、7个战场、39据点世界图；完整轮廓、通路/出口/建筑/角色避让、地图目标可达及五种横屏尺寸。图形验证使用启动前禁止显示/激活的后台Godot捕获。预览见`../../reports/natural-0.1.3/index.html`。
