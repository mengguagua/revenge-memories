# 战斗地图瓦片 · 朴素复古

本轮交付505个图集格、40个完整建筑/地形/装饰模块、16类基础材质及6组47变体过渡。原生16×16逻辑格；PNG、JSON、Godot TileSet与Tiled TSX均可复用。建筑不是将概念大图随意切块，完整组合可按JSON的footprint和tiles重组。

- `battle-tiles.png`：512像素宽、32列，最近邻采样，不开mipmap。
- `battle-tiles.json`：每格ID、分类、完整模块足印与来源切图边界。
- `battle-tiles.tres`：Godot实际保存/重新读取的TileSet；category/kind/name自定义字段，6组角/边匹配地形。
- `battle-tiles.tsx`：Tiled图集，tile ID从0起。
- `modules/`：完整PNG模块；包含雪屋、粮仓、营房、塔门、城墙角、牢门、木栅、粮车、药车、箱袋、雪林、岩壁、井、祭坛、军令箱、墓碑、七羽救济牌与投降旗。

战场美术层与逻辑层分别保存，不能把世界地图的地形编号直接送入战斗规则。`data/stages/*.json`的`map.tiles`保留明确的战术tile类别：48平地0、172森林1、94岩壁5、242沙地2、96水面7、196墙12、208石地板8、191木板6、66毒沼16、218恢复格15。石地板保留20物理回避；森林40。雪地按平地处理；矿道粗糙土面按平地处理。完整职业费用表覆盖23类。

模块category=-1表示不从图片猜通行效果。建筑实占墙格、可开的牢门和道路目标由关卡配置显式指定；装饰不任意改变地形。药车为事件对象，使用耐久、不能反击/接受单体支援魔法，不占人物装备槽或正式名册。

源图保存在`../../source/battle-tiles-b/`，已隔离导入；包括内置imagegen原稿、提示词及七羽图案的修订稿。构建脚本`../../tools/build_campaign.py`，资源构建`../../tools/build_battle_tiles_resource.gd`。图集切开/还原、透明轮廓、实际尺寸和文件大小见`../../reports/campaign/`。完整模块不可随机打散。

所有运行图使用原生格或整数放大；不非等比拉伸建筑或边角。素材图像先按美术用途制作，再无损压缩；原始生成图保留。
