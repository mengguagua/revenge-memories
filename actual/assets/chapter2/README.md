# 第二章海域资源

用于第二章 8 个关卡和东群岛据点，16 px 原生网格、最近邻整数缩放。材质与第一章已确认的朴素复古风一致，复用旧角色与战斗演出。

- `chapter2-tiles.png`：32 列，包含既有 505 个战场瓦片以及新增海事模块、海岸衔接。原有 ID 不变。
- `chapter2-tiles.json`：模块原生尺寸、切图矩形、透明像素范围、字节数与海岸 mask 映射。
- `modules/`：12 个完整独立 PNG，可直接在据点/事件船中复用，不依赖切半的树或建筑。
- 原稿：`actual/source/chapter2/maritime-source.png`，保留完整原始像素并通过 `.gdignore` 排除运行包。
- 提示词：`actual/source/chapter2/prompts.json`。使用 **内置 imagegen** 生成，`buildings-generated.png` 仅作为材质/画风参考。
- 完整切图在四种深浅背景、原生和 3 倍尺寸检查；保留实际 alpha、最近邻重采样，PNG 经 oxipng 无损优化。单个模块 315–1,664 字节，图集 88,415 字节。

地图由 `actual/tools/build_chapter2_battles.py` 独立构建，只输出第二章关卡；不会调用第一章全量构建器。正式游戏中，`logic_grid`/`map.tiles` 明确定义通行、森林消耗、岩壁和船舷阻挡；不从装饰图片猜测通行。

## 交互与视觉对应

- 海兵和玩家在甲板、跳板、沙岸、铺石古道行动；海面禁止步兵落点。
- 船舷使用连续木桩绳栏。完整船舱/桅杆有显式阻挡占格，登船口保留可见空隙。
- F22 备用跳板的 `opens` 与 `open_art_cells`、`open_art_props` 同步；放下后显示真实木板桥面，并覆盖旧船舷栏杆。
- 牢门采用动态 object 绘制，关闭与打开共用同一逻辑锚点；地图图层没有烘焙另一套门。
- F22 另外以完整栅栏模块构成两间实际围舱，四名俘虏坐标和属性保留。总闸在 [16,11]，同步打开 [24,8]、[24,16] 两个舱口；东侧 x26–27、y3–18 保留连续两格主通道。仅三名原本挡住新增栏杆的守军就近移位，人数、装备与属性不变。
- F26 居民船是 `event_boats`，路径 42 个海格，事件坐标不借用步兵单位。模块 `rowboat` 原生 32×48，格底对齐偏移建议 [-8,-32]。
- F21 己方船完整度在船旗事件上记录，不伪装成队伍成员或站在甲板上的一艘小船。
- F24 黑昼采用运行时地图染色 `[0.66,0.72,0.84,1]`。地表、静态建筑与自然物件变暗，单位、暖色航灯、画像与 UI 保持原色；正文介绍黑昼而不改变既有生命施法规则。
- F25 旧鹅卵石装卸区与石板主路分区；原六格阻挡建筑区改为完整箱袋、粮车和火盆，玩法字段逐项保持一致。开场对白明确引航者在东侧，与 [25,15] 牢门位置一致。
