## 能可靠比较的差异

当前40关是改编的独立遭遇，关卡没有原版 `stage/map` 对应元数据。原版80地图另列默认部署参考，**不按相似关卡编号、章节或名称拼成“外传同关”，也不给虚假的总体难度百分比**。

1. **18名角色按 `campaign.mapping.source_character` 比较。** 罗恩映射原Atlas，但改为弓手，基础HP、力量、技巧、速度、幸运、防御重配。达恩、兰斯、赫维、罗恩的入队等级降低，赛琳等级提高；同样基础属性下的等级变化也影响后续经验效率与培养空间。
2. **诺娅的六项个人成长率不同。** 相对映射的索妮娅，力量30%→40%，技巧、防御、HP各30%→20%，速度、幸运各30%→10%。其余17人的六项成长概率保持。没有独立的“职业成长概率表”，所以没有用职业基底冒充成长率。
3. **六兵装、两饰品的相同ID数值保持。** 引光剑的个人限制从阿尔姆改为艾琳，剧情取得节点也改变；因此数值相同不意味着实际获取时的难度收益相同。新增铜/铁装备59–66号不存在原版同ID对应，原值留空。
4. **胡纳普进阶六项最低属性与源23号勇者基底相同。** 当前基础移动为6，对比本地原版转职实现保留的源21号移动5。艾琳的源公主实现没有等价的最低属性表，本表不以0伪造差值；明确列出现有最低值、移动4→5及已学攻击法术逐次减耗1。
5. **普通职业共用基底保持。** `data/rules_full.json` 与 `actual/data/legacy/rules_full.json` 仅31号法术中文名“多拉→鬼火”不同，数值字段一致。具体关卡敌军大量覆盖这些基底，应看敌军明细，不把职业基底直接当作实际遭遇属性。

敌军明细保留 `raw_template` 对应源记录；只有模板能匹配且职业相同才给逐值差异。换职业的继承模板留空并标注原因。等级已改的记录明确写出“不是同级成长差”，避免把旧模板等级与当前等级混为一谈。

## 需要结合实玩判断的机制

40关本轮均获得胜利。共43次完整战斗尝试，其中2次正常战败后重试：S11的矿工被首领击杀，M42的主角第9回合濒死。F22另有1次自动策略到第91回合停滞，调整站位策略后第38回合成功，不属于游戏战败。成功流程记录新濒死6人次；S22有旧船员、同行伤者两名NPC损失。各关回合、伤情、重试、NPC情况与报告路径已并入工作簿及逐关CSV。S41另从第8回合补做可选领奖分支至第11回合，单独备注，不算失败重试。

这些结果来自真实历史检查点，在当前地图用正常控制器输入完成，并加速播放动画；**不是从新档一次连续通关五章，也不是移动真机测试**。回合数受到当次队伍成长、历史伤情和自动策略影响，不作为人类首次游玩的难度分数。统一证据见[40关覆盖汇总](../coverage-summary.json)。

- 战前回满HP是源复现已有行为。当前把恢复提早到结算/整备可见，不应把它误称为相对外传新增的无限战后治疗。
- 正式队员0HP转为濒死，需要有限救治份额；每人最多一次，全篇四种来源最多四份。主角濒死仍失败。它改变失败代价，但没有取消伤情对后续阵容的影响。
- 当前固定装备供应、持物100%掉落与空手普通10%掉落，让装备取得更稳定。一人一个携带槽，兵装、护盾、戒指无法同时装备。
- 护途盾是终战需要继续观察的强组合：最低进阶艾琳持盾为21物防、23魔防；J54首领半血后两类总威力均21，单击仅1点。这个公式不能代替整关的队友损失、目标压力与真实走图结果，本轮没有据此改数值。

## 数值口径与验收

工作簿含9张表、8个原生筛选表及8组冻结窗格。476条敌军/事件记录使用数量上限表示可重复出生模板；18名角色有324项初始/成长指标，另有23职业基底、两主角进阶、16项装备以及80原版地图。来源文件与字段保留在各表最后一列；[源码清单](source-manifest.json)记录读取版本。

攻击强度列由当前 Godot `combat_rules` 与 `item_rules` 直接计算：标准目标52HP、双防10、速度/幸运/地形回避0；只取一次命中的最高伤害，不计暴击、克制、追击和命中概率。J54数据列使用半血强化前属性，半血力量+3在能力说明中另列。神躯的贴身物理反击与主动魔法分开标明，HP费用范围为0–1。该列用于公式比较，不能称为实战平均承伤；驭魔师等AI也不一定使用其所有理论攻击。原版80图的防御为JSON裸属性，不含携带盾加成；当前逐关“实际物防/魔防”含当前装备加成，不能混用口径。

公式经过重算与错误扫描，导出后核对原生筛选、冻结窗格和数值类型。每张表做过代表范围视觉检查；长目标、压力条件、比较说明和来源按列宽换行，避免相邻列遮挡。内部预览留在 `_support/`，不作为额外交付图片。
