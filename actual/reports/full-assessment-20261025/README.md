## 实际修改

1. **存档与重试**：本关击杀数随重试归零；写入前校验可恢复性；主档与恢复副本分别原子替换；主档缺失/损坏时提供明确恢复入口；损坏原件保留；补齐剧情续读字段校验。[专项与证据](save/README.md)
2. **守卫与固定单位**：守卫保留驻点，进入实际武器射程或遭到真实攻击后警戒追击；未命中也记住攻击。固定脚本目标消失后恢复正常作战；召唤者在有限召唤间隔/耗尽后使用已有法术。终战首领移动0→4，固有攻击仍为1–2格，未凭空扩大反击射程。
3. **护送友军**：行走按敌军真实可移动攻击路径避险，受威胁时可选择合法位置后撤；武装流民在正式队员保护范围内支援。不会添加生命、无敌、额外移动或自动保胜。被包围而无安全位置仍需玩家解围。
4. **护途盾**：双防13→5，保留阶段恢复5、单携带槽和唯一救援来源。+13/+7/+5同源实际对照都保留。+5的单前锋样本仍19回合获胜，最低26/34HP、最大单击6；其他成员有被动反击和战损。修正的是全程恒1伤及稳定抹平伤害的保障，不宣称所有组合都被削成弱装备。[AI与强组合专项](ai/README.md)
5. **剧情和成长**：主目标明确存活人数、交涉和失败后替代路线；投降与死亡分支匹配真实对象；手机切队提示使用菜单名称；修复第四章训练菜单显示可转职却没有执行指令的问题。[剧情证据与运行画面](story/late-story-README.md)
6. **性能**：动画按需读取、旧图集释放、外侧触控轨道按状态重绘、药车提示缓存；470张PNG逐像素无损压缩。[环境、数据与限制](performance/README.md)
