# 守卫、自动护送与强装备组合验收

2026-10-25。当前源码已修复，手机未安装或更新。主任务的单一新档40关连续进度另在 `../campaign-final-r5/`；本目录的战斗位置夹具、历史领盾支路与界面夹具均单独标明，不能拼成新的连续通关记录。

## 最终改动

- `guard`／`guard_exit` 守卫先在原驻点警戒，正式战斗队员进入实际武器射程，或受到攻击后才追击。攻击落空也会记住警戒，避免小伤被阶段回血抹掉后重新站住。没有把全部驻点改成进入“移动＋射程”即集体冲锋。
- J54乌库布·卡基移动0→4，实际身体攻击仍1～2格；不会凭空对五格外反击。旧档只迁移已知移动0，保留HP、位置、随机状态和未知自定义移动，重试快照同样覆盖。
- F43驭魔师仍只有两轮有限召唤，冷却和次数耗尽后可以使用已掌握的鬼火。F24夺灯兵受伤且原地无目标时能移动回应远攻；离开航灯即撤销占领计时。F42／S41焚毁目标结束后转普通战斗。M15逃跑、S42前两回合等待、投降者停战均保留。
- 自动矿工、药车、解锁后的伤者等，按敌军真实移动、攻击范围、地形和单位阻挡判断危险，避免走入原四格距离规则漏算的截击范围。原位受威胁时可用普通移动退向预计承伤更低的空格；无更安全落点仍需玩家清路，不增加HP、无敌或移动预算。M11两组武装流民主动支援须有正式队员近旁掩护，受伤后不会仅因停止攻击就永久冻结在前线。
- 身体攻击的威胁预测按实际距离选择物理／魔法攻击。骸翼兽贴身对赛琳是9物理伤害，不能按默认远程蚀息预测成1魔法伤害。
- 护途盾最终为**物防+5、魔防+5、阶段恢复5HP**，保留单携带槽与唯一救援奖励来源。银盾仍是物防+7。数值放在战役饰品覆盖配置中，原版来源表没有改写；说明和实际状态页由同一配置计算，旧持盾存档不写入永久基础防御。

## 不能移动单位的逐类判断

[完整职责清单](unit-duty-audit.json)列出249个守卫定义、9个特殊角色／目标敌军，以及72个初始NPC：30个待救援锁定对象、22个非战斗岗位／见证对象、2个武装岗位守卫、18个自动护送／随行对象。数字是定义条目，不是独立实战次数。

罗恩与希雅入队前负责固定营地防卫，仍按原武器范围攻击和反击，不追敌离开岗位。船体、诊所医护、工班、囚徒、病人和剧情见证者不因此获得战斗能力；锁定者须先按任务解救。S42明确的前两回合等待是有限行动时机，不能与永久站桩混同。护送无法替玩家解决已经被敌人和地形包围的局面。

## 护途盾同源实际输入对照

从已真实取得护途盾的 `full-playtest-20261023/ch5/current/current-after-501.json` 继续，正常完成M52和J53各11回合。三组终战测试都从该支路的同一J53战后档开始，以普通整备取出西队行囊中的盾，再由两主角正常移动到相邻位置，于第2回合交换给艾琳。没有注入物品、属性、HP、坐标、随机种子或胜利标记。

之后只有艾琳主动向前攻击，仅用普通剑，不主动施法或治疗；其他正式队员原地待机，但仍会正常反击，且奥托濒死。因此这是**单前锋策略**，不能称为严格单人清场。
