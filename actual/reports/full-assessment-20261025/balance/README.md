## 驾驶器遗漏与真实难度分开看

### 治疗与支援站位

正式 `final-r1 → final-r3` 记录中，芙拉在M13、S11及其重试、S12、M14共0次主动治疗。她已拥有恢复法术：`magic_flags=5` 对应恢复与吸血，并非角色没有治疗能力。原S11专用计划只枚举攻击／移动，其他第一章推进分数也可能覆盖治疗计划。

因此，芙拉长时间Lv1、两次濒死，首先是**支援未得到有效使用的压力样本**，不能直接证明需要增加全体队员成长率。独立对照开始实际治疗后，S11／S12／M14均没有新增濒死，但M13和M15仍没有找到或执行治疗，说明后排跟进、站位与风险判断仍影响结果；不是严格控制所有变量的真人A/B试验。

当前白魔法不直接给战斗经验，支援角色主要靠过关经验或实际交锋成长。这是现行明确规则，值得在最终连续链中观察职业解锁与生存性；仅凭这次少量治疗记录，不足以立即增加支援经验。若后续确认合理保护并持续治疗仍导致支援角色整段流程无法成长，再做专门的有限支援训练方案，并防止安全地点无限刷经验。

### 转职与读档配装

- 正式压力链M14结束时，兰斯已经class1 Lv7，可合法晋升class4；当时的自动准备逻辑只在有救治份额且有伤员时回教堂，遗漏了独立的晋升需求。该M15样本包含**未利用已达门槛转职**的额外压力，不宜据此提高全队经验。
- 配装 helper 曾使用 `convoy.find(int(item))`。实际Godot验证：`[65.0].find(65) == -1`，尽管数值相等。读档后的JSON道具ID是浮点，导致候选评分选中了已有道具，却找不到索引而不装备。正式恢复链芙拉裸手、库存仍有铜法器符合这个遗漏；生产界面按库存索引操作，不受该驾驶器错误影响。该问题已交给主任务修正。
- 等级在晋升后重置为1，不能把“狙击手Lv1”看成比晋升前“弓手Lv7”成长倒退。应比较职业、基础值、移动与技能，而非只看显示等级。

### M15的失败与拦截

`final-r3` 中兰斯第6回合抵达北门(28,2)，第7—9回合继续堵门，HP从27降到17；第10回合剩8HP时撤往(23,4)，科兰随即从北门离开。队友并非完全没有攻击首领：第7回合胡纳普将其打到24HP，第8回合达恩打到16HP、贝克打到11HP；随后追击衔接没有完成。

新档队伍也不普遍弱于历史部署。以同一现行科兰、零地形回避、普通非暴击公式比较，正式M15兰斯单击11、达恩8、赫维默认火球11，均满足追击速度条件；这些是有足够生命和合法距离时的理论交锋能力，不是保证命中。历史部署的对应单击为8、4、9。主线之后通过正常重试在第7回合胜利，独立对照也在第7回合胜利。优先修正堵门者轮换、保护与追击配合，**没有证据要求降低科兰HP或取消逃离压力**。

### F22的配装攻速取舍

探索链三次F22的初始队员属性相同：艾琳Lv2、卡洛Lv2、米蕾Lv2、莉莎Lv1。原驾驶器出现轻伤前排撤回、主角独自暴露等问题，不能简单用失败次数衡量敌军强度。

F22首领持钢盾，物理防御为基础7＋盾5；艾琳和卡洛用铁剑普通单击仅1伤，法术则能绕过物防。莉莎的铁制法器增加威力和命中，但额外重量使默认火球攻速从4降为3；首领攻速4，因此会从不追击变为可追击。把铜制法器交给需要维持速度的莉莎、让医护角色承担较重法器，或选择适当距离输出，是已有装备与站位的真实取舍，不必把高重量装备一概加成或降低首领防御。

## 调整建议

1. **保留现行总体难度，先完成正确使用治疗、转职、库存和任务目标的完整连续链。** 当前两条第一章路径均可正常推进，且并非没有战损；不支持全局削敌、加成长率或放宽所有任务。
2. **成长统计按角色实际参战、晋升与招募时点归一。** 正式M13经验明显集中在达恩，S11集中在兰斯；这是击杀分配与行动贡献的结果。不要把晚加入贝克的低等级、晋升后的低等级、濒死后的停滞混成同一种问题。
3. **配装评估要考虑追击门槛、目标防御和任务时限。** 只按线性总分选“更强装备”，会错过法器重量、护盾换输出和追击首领的取舍。优先改善测试决策，不据此重写装备数值。
4. **最终观察后排与伤情是否出现不可恢复的累积困境。** 独立对照仍有三名队员在M15濒死，需继续检查现有救治、后续招募与队伍分工能否承接。这是待核实风险，不是立即全体回血或追加救治次数的依据。

本页所有公式比较都明确使用现行规则，历史部署仅作为数值参照；未把它们当作本轮连续通关。自动策略、随机成长和样本数量限制了对真人体验的推断。
