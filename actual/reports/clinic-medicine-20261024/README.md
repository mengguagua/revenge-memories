## 修改与依据

| 内容 | 本次修改 | 修改依据 |
|---|---|---|
| 赫维的岗位 | 从南村出发区移到北岸诊所侧院（24,5），显示“核对药单 · 照护伤者”。作为非战斗诊所人员留守，不接受玩家移动或敌军攻击指令 | 原剧情写明他不愿放下病人，旧部署却远离诊所，无法让玩家理解不动的原因。新位置避开访问入口（22,5）和送药点（22,6） |
| 药车为何移动 | 显示与车同行、按方向播放行走动作的运输员，名称改为“运药员与药车”。人物与车共用一个护送目标、一个落脚格和原有耐久 | 让移动有可见执行者，同时避免新增第二个自动单位造成堵桥或交付不同步。保持原有清路前进、敌近等待的护送逻辑 |
| 开场与途中提示 | 胡纳普说明诊所缺药和赫维职责，运药员解释清桥后推车；目标和战术提示明确“击败封路队长＋送达药车”。到达后说明推进院内卸药 | 不需要让远处的赫维从南村开口，也不会把药箱误认成会自行移动的道具。胜利条件与实际规则一致，不要求全歼 |
| 战后医疗交接 | 诊所保留运输员与送达药车。玩家和管理员核对药品、交接用药记录；完整对话结束后才写入交接完成标记 | 让赫维离开诊所有实际接手人和交接过程。中途存档保留剧情回调，不能刚点管理员就立即招募 |
| 主动邀请 | 送药关卡获胜、完成交接后，玩家再与赫维交谈，选择“邀请同行”。界面与招募入口同时核对条件 | 防止旧菜单、提前设置管理员标记或跳过对话绕过流程；保留“暂不邀请”，不自动入队，不复活旧档死亡角色 |
| 新版职业素材 | 运输员使用重绘页的 class-14-ally 村兵待机／四向行走；赫维使用 class-15-ally 术法师；诊所管理员使用 class-18-ally 司疗者 | 按用户指定的[角色重绘 · 全动作对照](../../../art-review/character-expansion-20261018/index.html)接入已选定素材，不重新采用旧候选图 |
| 旧图清理 | 删除旧村民 map、walk、hub 三张运行图及对应导入文件、缓存，共12个文件；将 civilian 的三个运行入口改指新版职业图 | 截图里的旧图来自 `actual/assets/party-0.7.0/civilian/`。旧路径已无运行引用；删除清单与原图哈希保存在[清理记录](retired-art.json)。原作对照源图属于验收依据，继续保留 |
| 旧存档兼容 | 只迁移尚未入队、存活的赫维及其重试快照；侧院格被占用时就近选择合法位置，不挪动其他单位 | 保留药车进度、伤势、回合、随机状态、地图几何和其他单位位置；已入队或已死亡的赫维不重新定位。无需改变存档格式 |

没有修改敌军部署、伤害公式、装备属性、角色成长或药车耐久。运输员的职业图用于表现护送者，不增加攻击、治疗或额外行动。
