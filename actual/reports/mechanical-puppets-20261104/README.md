## 当前规则

- F21在零起算(21,14)新增 F21_water_monkey_1，保留原9名敌军、指挥官与护船胜利条件。等级3，本体22，力量5、技巧4、速度8、幸运0、防御3、魔防1、移动5。背炮独立10耐久、防御2、魔防1。
- 友方普通攻击前选择本体或背炮，并显示对应耐久及伤害。部位伤害不传导或溢出；破坏不计击杀或掉落，立即禁用本次交锋剩余水炮；部位被破坏后的追击取消，不转打本体。MAP仍只扣本体。
- 默认近身机械掌击：物理威力5、命中85、攻速8。2–3格水炮：物理威力8、命中75、攻速3；一次行动选择一种攻击。命中速度－1，最低0，不叠加，保留到受击者下次行动结束。按现有交锋机制，攻击次序在交锋开始时确定。
- 战斗经验按同条件普通值×1.5向上取整，沿用100上限；伤害与击败均适用，部位破坏无额外击杀奖励。35→53只是示例，不固定所有单位的奖励；关卡通关奖励倍率不变。
- 同阵营在场存活战斗单位仅剩机械傀儡时移动5→8，每个本方回合撤离，近身仍可掌击自卫。按合法路径代价选最近可达外缘，并列上／右／下／左；不穿墙、不穿占位、不瞬移。F21仅撤离时允许以代价1下水，当前起点东行10格，分8＋2两回合。到边缘隐藏退场，不计死亡、击杀、掉落或击败经验，已得伤害经验保留。胜利不强迫追赶。
- 完整／破损均使用已确认V2像素动作：地图待机约3秒，近战219帧跑近／命中／回位，第83帧结算；水炮使用有厚度水束和命中水花。普通受伤沿用固定姿势闪烁、轻微位移及既有命中音。全场景保持对应炮体状态。

## 存档与资源

严格校验机械身份、独立耐久、移动与布尔状态；损坏、减速、撤离和退场状态随现有单位字典保存，兼容旧普通单位。旧的进行中F21不追加敌人；重新部署或重试会使用新配置。新战斗和整备清除临时减速；重试恢复初始背炮。检查使用历史F21记录副本和 /private/tmp 独立输出，未覆盖玩家存档。

删除20项、合计1,796,330字节：4张旧小水滴，12张后仰／过时跑动等姿势，3张包含旧姿势的检查图，1张边距不合格水炮源图。无当前动作引用被删除。混合图集重建，素材生成器不再生成这些帧；含有效姿势的混合源图继续隔离保留。逐项理由和删除前哈希见 [cleanup-manifest.json](cleanup-manifest.json)。
