# 有限战术补练

补练采用有教习与接应人员的营地演习。玩家主动从世界地图的「部队整备 → 战术补练」进入，不在已通关剧情关随机刷怪，不重复首领、招募、剧情交付或唯一装备。

## 首版规则

- 每个章节、每支队伍共享两次成功演习额度；两种演习可以任选。失败、主动退出和重试均不额外消耗次数。
- 「突破」：正式队员抵达白旗据点并结束行动，或击败全部对练者。
- 「护阵」：正式队员在白旗据点连续守住三个敌方阶段，或击败全部对练者。离开据点会中断累计。
- 单场最多十回合。领队退出或超时视为本场失败，可重试或回营。
- 成功后每位实际参训的正式成员获得60经验，包含本次演习倒地者；沿用现有等级上限和真实成长规则。原本濒死的成员不能参加，也不会借演习复活。
- 演习过程中不发战斗经验、不掉装备，不能通过反复攻击或中途退出累计收益。完成两次后仍可查看说明，但不再提供开始按钮。
- 本场倒地不形成新的永久伤势，也不消耗治疗机会。成功时恢复参训者原来的健康状态并结算经验；失败或退出则还原入场时的队伍、装备、行囊和随机状态。
- 合法的战中装备交换在成功后保留；失败或退出会一并还原，不复制装备。
- 第五章两队合流后关闭演习入口。当前总计八个章节/阵营额度池，全流程最多十六次成功演习；单个角色最多参加所属队伍的四个阶段。

## 验证与修复

状态与序列化验证303项通过，见 [checks.json](checks.json)：覆盖全部十六个配置的部署合法性、保存与恢复、重试、退出回滚、原有濒死保留、全员经验、装备交换、重复结算与两次额度限制。还注入非法 `training_active`、返回状态、计数和嵌套训练来源，确认拒绝异常记录，不在失败校验时更改队伍。

两轮真实按键试玩使用历史正式通关队伍的副本，正常确认主线胜利回世界地图，经整备菜单、补练说明与确认开始。没有修改队员属性、随机结果、位置、胜负或剧情进度。

第二轮首次发现敌方回合反击取胜时的升级页被普通战斗奖励分支覆盖，导致画面回到战场而结算仍等待确认。主流程修复后，第二轮四场重新通过，包括原先发生问题的T4W2。故障证据保存在 [修复前记录](play-round2-before-reward-fix.json) 和 [修复前检查点](round2-late/reward-stall-before-fix.json)。当前结果见 [第一轮](play-round1.json)、[第二轮](play-round2.json)。
