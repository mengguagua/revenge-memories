# 拒阵枪与精英击退

本次只新增一个武器类型，不改原有武器、角色或敌人的基础属性。

| 项目 | 设计 |
| --- | --- |
| 名称／ID | 拒阵枪／67 |
| 职业 | 士兵、重装兵、壁垒卫士（6、2、22） |
| 数值 | 威力 +3、命中基础 85、重量 3、额外必杀 0、射程 1 |
| 西队来源 | M13 南岗押送所胜利后，获救劳工交付一支 |
| 东队来源 | F24 海灯岛防卫胜利后，守灯人交付一支 |
| 装备规则 | 使用既有单装备槽；与盾、戒指等互斥，不增加额外槽位 |

定位为步兵控制武器。原铁枪威力 +2、重量 0；原钢枪威力 +4、重量 1。拒阵枪的伤害在二者之间，较重且不能远投，让击退有明确的攻速与射程取舍。骑兵、飞行职业不兼容，避免同时叠加高机动与无代价控位。两队分别已有奥托、洛德等适用角色，招募并非领取的条件。

## 结算规则

- 仅主动发起的相邻攻击；至少一次命中且对被攻击目标造成实际伤害。
- 完整交战（含正常反击、速度追击）结束后，双方仍存活才触发。
- 沿攻击者至目标的方向退一格；每次交战最多一次，反击不会触发。
- 目标身后有活着的单位、地图边界、不可通行地形或尚未破坏的障碍时，不移动，也不增加碰撞伤害。
- 固定剧情对象和锁定囚徒不移动。位移不刷新行动、不自动触发等待／撤离结算。
- 装备不相容、改用魔法、落空、零伤害或任一交战者死亡时不触发。
- 掩护者与目标因位移失去邻接后，依掩护系统立即取消关联。特殊AI按聚力起始位置检查位移打断。

装备说明、人物特性及预测接口均提供击退信息。无需新增动作资源，沿用该角色的长枪攻击，位移发生于真实交战结束。

## 存档与验证

新物品追加到现有ID表尾部，不重排旧ID。两个固定奖励分别以 `knockback_clear_rewards` 标记，重复结算、重新整理或读档不重复领取；自动供给保留在行囊，不替换人物现有装备。历史已清关记录在安全整备边界补发。

`knockback-checks.json` 是定向规则、供给和存档检查结果，使用受控夹具，不能代表实机通关。`knockback-play/round1/report.json` 与 `round2/report.json` 则记录历史真实检查点的独立菜单输入试玩：保留历史队伍和战损，正常重入关卡、正常装备拒阵枪，不注入生命、属性、随机数、位置或胜利。该范围不是从新游戏连续通关，也不是手机触摸测试。
