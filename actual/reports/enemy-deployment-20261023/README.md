## 身体演出与素材

石翼兽／骸翼兽／神躯各8个新无持械关键姿态及地图小像；骸翼兽采用灰骨身体，咬击／吐息独立编排。源图由内置imagegen生成，按追加要求降低饱和度、精简颜色；采用关键姿态与位移／特效组合，没有宣称所有动作逐帧重绘。

日冠聚光早期设计为光束，本次实际初版为纯金白集中光球（聚光弹），一次命中；石翼兽／骸翼兽头像同步新形象，骸卫／裂目兽头像由自身原地图帧裁出。
