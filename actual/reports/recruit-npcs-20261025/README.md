## 音乐制作与检查

《同行的新约》采用新写D大调短句作为引导，由本地离线 **Stable Audio 3 sm-music / same-s（MLX）**补充音色，最终混合为72%自写引导、28%模型生成层；没有取用原作旋律或录音。详情见[生成脚本](../../tools/generate_recruit_cue.py)及工程根目录 `source/recruit-npcs-20261025/audio/generation.json`。

[运行OGG](../../assets/music/20261025/rm_jingle_recruit.ogg)：44.1kHz立体声，27,283字节，2.000秒，不循环。解码检查为-17.96 LUFS，真峰值-10.62 dBTP，无削波；结尾100ms淡出。Godot实播生命周期验证了成功触发、场景音乐暂停和结束后的原位续播。见[音频检查数据](audio-checks.json)。本轮未获得人工听审结果，也未把波形检查标成听审；本地音频理解服务当时未运行。
