## 修改依据与行为

- **修复终战漏曲**：原调用仍检查原版关卡 62，本作 J54 实际为 534。音频层现按实际关卡映射到《天空不属于王座》。
- **保持战场音乐连续**：交锋、支援、敌我回合、最后一名敌人都沿用本关曲和当前位置，避免每次交锋重新开头。
- **按剧情区分据点**：原先所有据点统一播放 `village`；现按房间与明确剧情回调选择曲目。
- **柔和换曲**：跨场景约 0.6 秒交叉淡化；快速换场保留退出声部的当前增益，避免音量瞬间升高。
- **保存不切标题曲**：从世界、据点或战场打开保存／覆盖确认时延续原曲；标题发起读取／新旅程才使用标题曲。
- **提示互不抢播**：升级、濒死等短提示结束后恢复背景曲原位置；胜利短句等待升级奖励和战后剧情结束，仅播放一次。直接进入结局则保留结局主题。
- **音量与静音保持一致**：音乐、音效独立控制；交叉淡化和短提示暂停／恢复时保留正确状态，没有叠加运行增益。
