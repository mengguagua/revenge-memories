- [story_armaments.json](../../data/story_armaments.json)集中记录六件名称、原名、专用人物、来源与交付对白；原ID、威力、重量、命中、必杀、射程、特效和阶段恢复数值保留。
- 引光剑改为艾琳专用，守约剑保留胡纳普专用；装备预览解释正确归属。引霆剑依旧固定攻击力15对魔防，曜锋枪没有吸血，定潮枪没有无视防御，镇关枪仍不适配士兵。
- M33、F33、S42、M52、S51胜利后通过固定事件收入来源队行囊；F44后H48地方循环验证时直接交付引光剑。D42在同一据点确认进阶的既有路径也执行同一交付检查，事件键防止重复。

- 六件不进入普通或旧稀有随机奖励，流星枪的既有来源保留。邀请、战前和交付有线索，S42／S51关闭前有尚未取得的兵装提醒；玩家仍可主动跳过支线，终战继续允许普通武器与法术。
