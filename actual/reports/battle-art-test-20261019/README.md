下载：../../dist/RevengeMemories-0.8.10-BattleArtTest-20261019-macOS.zip

## 素材与导入

原尺寸帧保留且无损压缩，尺寸/字节数与哈希见 import.json。佣兵合并图集为 5120×512，盟军 62,538 字节、敌军 73,165 字节；为保留已验收的透明边缘和所有动作帧，未采用有损减色压缩。图集超出 50KB 优化参考，符合视觉质量优先约定。原始生成源图保持在美术审核目录，未加入游戏包。

Godot 默认 alpha 边缘处理会改写佣兵低透明度像素的 RGB，现已仅对双方佣兵战斗图集关闭该选项，最终导入纹理与审核图一致。未修改任何渲染或战斗逻辑。
