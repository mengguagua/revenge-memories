# 行囊换装预览 · 0.8.15

在部队整备的「装备行囊 → 领取装备」中选择目标道具后，角色列表按「姓名 · 当前职业 · 当前装备武器」显示。职业取当前职业ID；带盾、戒指或法器时，同时显示正在使用的默认武器或攻击法术。

选择角色只打开比较页，不移动物品。页面显示目标适配与否、当前值、换装值和带符号的增减值。增加为绿色，降低为红色，不变也明确标示。可用方向键、确认键或鼠标操作；完整队伍支持翻页。

## 实际数值与条件

- 攻击力、命中基础、必杀、攻速、物防、魔防、幸运、移动与射程，均复用现行道具与战斗公式。命中基础不含敌方回避，攻击力不等于对具体目标的伤害。
- 钢弓相对铁弓的示例：攻击力13→14（+1）、命中81%→76%（-5%）、攻速4→3（-1）、射程1—3→1—5（+2）。盾会移除原武器加成，法器重量会影响攻速。
- 「装备特性」按钮或Tab可查看当前／目标的条件效果，包括专属武器、士兵的特殊枪限制、魔物防御、法术命中、戒指效果、法器不增加法术或治疗等。特殊效果不会冒充无条件属性加成。
- 不适配或濒死成员不能确认换装。不增加原规则中不存在的等级或力量门槛。

## 确认与物品保存

按「确认换装」后，新物品装备到角色；旧装备替换回本队行囊原位置。空手领取只移除目标物品。满40件时仍可完成等量替换，不丢失旧装备，也不跨队领取。

确认时重新检查当前物品、队员及条件，并保存进度。目标已变化、条件不符或保存失败时保留原装备与行囊。预览、查看特性和返回都不改动装备。
