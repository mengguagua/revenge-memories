# iPhone横屏修复 · 0.10.2 · 2026-10-22

0.10.2已更新安装到连接的iPhone 16。两个游戏记录及各自恢复副本共4个文件，更新前后逐字节一致。IPA为现有开发签名，签名有效至2026-10-29 00:28（北京时间）；同一应用标识沿用手机沙盒进度。

## 本轮结果

- 按用户2556×1179真机截图对应的安全区(177,0,2202,1116)，中间视口由326×240扩至406×240，保持4倍整数像素显示；可玩画面宽度增加约24.5%。左右控制区各72逻辑像素，确认／返回／菜单／状态排列紧凑，触区均在游戏之外。
- 据点说明优先放在底部空白处，避让实际人物精灵、移动扫掠、任务物件、交互箭头与出口标记。人物素材的native_density按真实绘制比例计算，避免错误保护范围。出生点即可看见赫兰。
- 战术场景增加“切换我方”：浏览时定位下一名未行动成员，己方状态页可切换队员；移动、行动与选择目标期间灰显，不撤销当前操作。
- 战前弹框中文和数字使用原生12像素完整字形，显示当前／最大HP、伤害、命中、必杀与不能反击的原因。双方HP格统一尺寸：普通4×4，高HP时双方一同使用2×2。横向放不下时使用侧置卡，iPhone406宽案例均避开双方角色和目标箭头。
- 战斗动画显示独立“按住加速”。持有期间约3倍速度，松开、拖出、失焦或切场景恢复正常；不转发确认键，不跳过奖励选择。203帧真实攻击在两条动作时钟路径中均保持帧序列、HP结果及一次接触结算。
- 战斗菜单新增“保存并返回主菜单”。保存当前记录成功后才返回；继续游戏可接续当前战斗。保存失败仍停留在战场。部队整备原先删除的“返回标题”没有恢复。
