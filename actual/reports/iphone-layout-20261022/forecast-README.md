# 战前弹框清晰度与血条 · 2026-10-22

- 所有战前字段使用原生12像素中文。数字与百分号来自现有12像素字库的完整原生笔画，只去掉字格左右空白，不缩放字形；每一列包含姓名、当前/最大生命、伤害、命中、必杀或不能攻击/反击原因。
- 双方按同一生命密度选择HP格：最大生命不超过52时都为4×4；任一方超过52时都为2×2。格子大小不再根据各自的行数缩放，仍一格对应一点生命。数字、HP格与边框分别保留安全间距。
- 常规240×112卡优先；需要紧凑布局时使用240×86，中文仍为12像素，最后文本与HP格留2像素间隔。上下容不下时用128×180侧置卡，双方上下排列。
- 两名交战者按实际 `frame_size/native_density` 的逻辑图像边界加2像素保护，目标选择箭头保留原保护区。iPhone406×240的所有本轮样例均同时露出双方角色。
- 最低256×240画布中，部分分散的远程站位没有足够空间容纳完整卡且露出双方；该情况下继续显示全部字段和目标／选择箭头，记录 `fallback_reason=minimum_canvas_combatants_do_not_fit`，不会静默隐藏预览。此限制有单独截图，不属于iPhone406画布样例。
