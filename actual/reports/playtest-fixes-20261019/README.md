## 修复

1. 双方佣兵与截图中的首关流民战斗图统一为2×2四倍画布像素块，移除细碎半透明边缘；每组所有动作共用至多14种不透明颜色。保留衣装身份、姿势、腾空高度与原动作时序，枪兵作为颗粒和配色层次参考。更新33个姿势帧、33个动作与36段视频，其余514个对照动作摘要不变；地图形象不变。
2. 新版地图素材此前绕过了原有敌军待机调色分支；现在敌军已行动后为偏红色，友军仍为灰色。透明轮廓和动作姿势保持。
3. 攻击预览框根据目标位置在周围选择空位，目标角色与箭头区域为不可遮挡区；完整尺寸无法放下时，使用现有8px小字体的紧凑布局，保留预测信息。大生命值的血条限制高度，避免挤出内容安全区。
4. 首关两支流民队只在血量与落点风险允许时主动进攻。低于60%生命不发起攻击；预测反击及下一敌方回合的伤害后，至少保留最大生命35%（最少5点）。落点受三名及以上敌人威胁时不攻击；两名敌人威胁时还要求总损失不超过最大生命30%。评估包含敌人实际可移动位置、地形、占位、近远射程、追击及可能暴击，不假设敌人打空或目标必死。风险过高时沿用护送等待/安全路线，健康且安全时仍会接近敌人攻击。

此规则仅针对M11_refugees0/1；职业、阵营、属性、奖励、撤离与流民死亡判负条件均保持，存档格式未改。
