## 音频制作与验收边界

6条运行OGG：5条独立主攻击声、1条拉弓声。离线复用本机 Stable Audio 3 sm-sfx/same-s，使用原制短攻击引导声、FP32音色纹理生成，再以引导72% / 生成28%混合并掌握包络、短收尾和电平。源文件、提示词、种子和权重路径记录在 `source/map-20261029/audio/v2`；权重和推理环境没有进入游戏资源。

`audio.json` 记录最终哈希、电平、时长和来源。`audio-signal-review.json` 显示6条无非有限采样或削波，起音在首个10ms检测块内。Qwen2-Audio已检查最终6条；Qwen3-Omni检查了候选和校准输入。两个本地模型对短音效的语义/音色描述不可靠，Qwen3甚至将静音误报为持续音调，不能据此给出听感合格证明。原始回执全部保留；`audio-review-summary.json` 明确记录限制，`human_listening=false`。有声预览用于后续实际听感确认。

视频按真实演出记录的音效键和触发时间、游戏音量0.65混合，便于检查而省去BGM。每段保持真实演出长度，输出结尾15ms淡出；这不是增加游戏等待。视频为正式Godot phone视口、演示摆位、30fps固定时钟导出，完整画面1280×592，特写等比例裁切460×360并以邻近采样放大；不是iPhone录屏。
