“不能行动”按本回合已完成行动处理；濒死／死亡单位不会变为可掩护对象。掩护者自己必须尚未行动，仍受原近战职业条件约束。首次命中分担一半、奇数向上取整、分担不超过掩护者剩余HP、未命中不消耗、相邻与阶段期限等规则保持。

旧档若保存了对仍可行动队友的掩护，续读时只清除无效保护，不返还已用行动、不改伤势。合法掩护正常保存和续读。目标离开、阵亡、重新获得行动能力或下次己方阶段开始时解除保护。
