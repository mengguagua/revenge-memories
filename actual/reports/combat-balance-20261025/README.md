## 与《外传》的公式核对

物防和魔防独立。普通魔法单击为 `clamp(力量＋法术威力（含适配法器）－目标魔防, 1, 60)`，不读取物防。普通物理攻击读取物防；皮盾只增加3物防。特殊法术和固定威力魔剑按各自规则处理，暴击不包含在这条普通单击说明中。

依据：[《外传》反汇编 bank009](https://github.com/minirop/fe2/blob/main/src/bank009.asm)的`L09825E`伤害与`L09835F`双防选择；本工程保存的[原表与来源提交](../../data/legacy/rules_full.json)及[当前结算](../../core/combat_rules.gd)。新增断言验证力量10火球（威力3）对物防20、魔防2造成11伤；加皮盾仍11伤，加双防13盾后变1伤。旧原作复现的[既有公式测试](../../../tests/test_full_rules.gd)也保留了同一个11伤例子与剑豪抗性+15的转职检查。
