# 第一关流民重叠修复 · 0.8.14

第一关初始是两组自动护送流民。首次只读检查用户的第3回合战斗记录时，`M11_refugees0` 与 `M11_refugees1` 均位于 `(9,12)`，生命分别为24与21；两者都未隐藏、未撤离，任务结果为空。截图少一人是两个精灵重叠，并非死亡或撤离。用户之后继续进行的战斗记录仍在自行更新，本次没有写入用户存档目录。

## 原因与修改

护送寻路允许经过友军，也会在靠近敌人时截短路径。旧逻辑把截短前最后一个安全路径点直接当作终点，却没有重新检查该格是否被友军占用。确定性复现：流民在 `(10,13)`，友军在 `(10,12)`，敌人在 `(10,7)`；旧AI选择 `(10,12)`，但 `can_stop` 返回false。

- 截短路径只记录可停靠的安全空格，仍允许经过友军。第二章俘虏、病人、船员的相同分支共用此检查。
- 落脚检查遍历所有有效占格者，避免旧档里先找到自己就漏掉同格友军。
- 读入尚未结束的战斗时，仅恢复与友军重叠的、可自动移动的护送单位：保留先前单位，将后出现的护送单位安置到最近可达空格，同距离优先远离敌人。保留身份、血量、属性、行动标记、回合、随机数和任务状态；已死亡、已撤离、锁定及正常位置不搬动。
- 不改失败及胜利条件：任一流民死亡仍判负，两组撤离并击败队长才获胜。
