# 新音效运行接入 · 2026-10-24

本轮将旧音效入口改为新资源，保留《外传》已核实的请求时序、控制请求与双声道复用方式。没有操作 iPhone、重跑关卡或截图。

## 范围与映射

| 项目 | 数量／策略 |
| --- | --- |
| 新独立音效 | 41 个，`res://assets/sfx/20261024/rm_sfx_<hex>.ogg` |
| 覆盖旧物理 OGG | 42 个；`menu_move` 与 `hp_tick` 都是 0x12，旧文件字节相同，共用一个新资源 |
| 源音效请求 | 41 个，ID 和真实动画帧调用顺序保留 |
| 命名入口 | 9 个；7 个有效入口使用新资源，未经证实的泛用 `attack`／`death` 别名继续禁用 |
| 源控制请求 | 15 个：00 停止全部；56 按原 128 NTSC 帧淡出音乐；其余 13 个只停止音效 |
| 空音乐指针请求 | 74、75、92、97、B1，继续保持当前播放，不伪造资源 |
| 新配乐 | 保留上一批 28 首配乐、战场连续播放、交叉淡化、升级与胜利提示的既有行为 |

`sound_effects.json` 的 canonical ID、numeric request 和有效命名别名共享一个缓存 AudioStream，重复触发仍依原时序发生，不因缓存合并而丢失音效事件。普通音效、法术循环内的重复请求、生命刻度均没有增加猜测调用。

运行不读取旧音效作为兜底：仅从新音效目录加载；新文件缺失会报告失败，旧文件即使仍在源码目录也不能被替代加载。`legacy/full_audio.json` 仅提供控制、空指针和请求路由等来源元数据。

## 发现并修正的绑定问题

旧清单把泛用 `attack`／`death` 别名的“尚未证实”标记同时用于 numeric 21／53，导致已有真实动画程序发出这两个请求时也静默。本轮查明了具体 ASM 与效果程序，因此按入口区分启用策略：

| 入口 | 处理与依据 |
| --- | --- |
| `attack`、`death` | 仍禁用，不能把现有资源当作任意挥击或任意死亡音 |
| request 21／canonical 21 | 恢复与风刃程序真实调用，启用该具体请求；不添加触发点 |
| request 53／canonical 53 | 箭雨／过渡程序真实调用，启用该具体请求；保持有限 4 秒资源、不改为无限循环 |
| 53 → 普通命中 03／未中 43 | 播放反馈前只清理当前 53 声部，另一声部和背景音乐保留；依据原驱动新反馈替换旧过渡音 |
| 动作结束／离开交锋 | 清理尚未停止的 53，避免过渡底音跟随返回地图。动作收尾通过兼容现有 mock 的 helper 执行；不添加猜测计时器 |

精确源码位置、程序参数与帧序列见 [21／53 证据](evidence-21-53.md)。完整请求、旧路径及语义索引见 [映射表](mapping.md)、[计划](plan.json)、[实际调用索引](usage-index.json)。

10 个 `manual_stop` 效果继续采用有限时长和原有停止请求；没有按该标志自动启用循环。双声道数量与替换顺序保持，生命刻度等高频音效对既有声部的复用方式不扩大。

## 代码与验证

修改 `core/original_audio.gd`，增加新 `data/sound_effects.json`；`core/battle_animation.gd` 仅增加动作结束时清理 53 的一行调用。对原配乐测试中“音效条目完全等于旧资源”的断言，更新为新资源及来源策略预期，音乐状态和数值验证保持。

最终 **478 项音效检查通过**，覆盖 41 请求／42 旧路径／9 别名、15 控制／5 空指针、禁用别名无法绕过已缓存 raw request、音量与独立静音、有限音效停止、双声道上限、4 份真实动画帧请求序列、11 个地图特效起止，以及同帧播放／停止的顺序。新增 21／53 发声、53 → 命中／未中、动作完成和离开交锋的检查通过。

41 份最终 OGG 已逐文件核对字节数与 SHA-256，全部可由实际 Godot 音效加载路径读取，时长与清单一致、循环关闭、有限时长不超过计划上限。新音效总计 **1,302,534 字节，93.71 秒**。详情见 [生成与信号检查](generation-report.json)及[逐音效列表](tracks.md)。信号检查不等于主观试听，本轮不声称已经完成全套人工听感验收。

上一批配乐的 **547 项回归检查通过**，包括 28 首实际资源加载、循环与时长，以及战场连续播放、切换队伍与剧情、独立静音、淡出、升级提示与待播放胜利提示的顺序。音效替换没有改变这些已验证行为。

复核入口：`tests/sound_effects.gd`、`tests/soundtrack_routing.gd`。证据：[音效检查](integration-tests.json) · [配乐回归](music-regression.json)。使用 headless 和 Dummy 音频驱动，不播放到用户扬声器；仅重放音频状态和已有帧请求，不执行战役通关、渲染截图或任何 iPhone 操作。
