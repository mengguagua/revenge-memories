## 除换素材外修正的问题

- **恢复、风刃与箭雨漏音**：早期提取脚本把泛用 `attack`／`death` 别名的待确认标记复制到具体请求 21／53。现已用 ASM、效果程序和实际帧序列确认，启用具体请求；两个未经证实的泛用别名继续禁用。
- **箭雨底音拖尾**：原驱动在命中／未中时替换 53。现双声部播放器补上针对 53 的停止处理，并在动作结束和离开交锋时清理，避免底音带回地图。
- **短音与响度**：按原资源的活动 RMS、峰值和触发频率区分 UI、命中、法术及持续效果。即时起音为 0–4.989 ms；最高真峰值为 −6.2 dBTP。不是把所有声音统一推到满响度。
- **持续效果**：10 个手动停止音效保留有限长度和原停止指令，不改为无限循环；频繁触发的雷电、火球等只制作单次脉冲，重复次数仍由现有动画控制。
