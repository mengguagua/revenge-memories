## 玩家看到的规则

- 在标示的恢复格驻守，下次轮到所属阵营行动时恢复5点生命；不是落脚或按待机立即恢复，也不在敌方阶段恢复我方生命。
- 不需要选择“占领”。生命不超过上限；地形、恢复装备与邻接医护的普通回血条件不叠加；不能解除濒死。
- 敌军站在恢复格也沿用相同规则。
- 四关开场对白和战场目标说明加入点位与恢复时机。空地信息显示“己方阶段开始恢复5生命”，有人驻守时也显示恢复时机，避免角色遮住后规则消失。
- M12开场“焚毁兵第5回合开始行动”更正为实际配置的第7回合；代码时限保持，第6回合预警仍有效。
- S12赫维继续在北岸诊所(24,5)照护伤者；访问门前(22,5)、交付点(22,6)、药车与运药员、送药获胜后的交接邀请均保留。南村包扎用品只提供基础休整，不替代北岸药品任务。
