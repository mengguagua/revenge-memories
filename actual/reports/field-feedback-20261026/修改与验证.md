# 粮站、按钮音效与南岗押送所修复

2026-10-26。六项反馈及追加的骑兵2级要求已完成，两轮针对性抽查和原生游戏试玩通过。

## 修改结果

| 项目 | 修改内容 |
|---|---|
| 粮车碰撞 | 从1格改为2×1格；两半都不能穿入，两半均可面对确认分粮。旧记录若停在原来漏掉的一格，会移至相邻空格。 |
| 牌子遮挡 | 按脚下地面位置排列人物与物件的绘制顺序。角色在牌子后方会被挡住，走到前方正常显示。 |
| 触摸音效 | 方向、菜单、确认、返回、状态及可用的切换按钮都有按下反馈。一次按下只播一次，抑制同一次操作的重复菜单声；禁用按钮不触发。 |
| 邀请成功 | 修复新建记录替换游戏状态后，入队事件仍绑定旧对象的问题。成功入队播放现有专属短乐《同行的新约》，画面与输入暂停2秒，再继续接受邀请对白。 |
| 停帧接管 | 在等待2秒短乐前就取得对白流程控制权，避免停帧结束瞬间，被连续点击抢先触发移动或菜单。 |
| 旧存档 | 对正在进行的战斗及重试快照使用有版本号的属性更新，重复读档不叠加增益，保留原有伤势和死亡状态。 |

此次复用已经制作的2秒原创入队短乐，未重新生成音乐。源文件为44.1kHz双声道、精确2.000秒，平均电平−20.9dB、峰值−10.6dB；运行检查确认实际音乐播放器启动，场景BGM暂停并在短乐结束后恢复。音乐和音效的手动静音设置继续生效。
