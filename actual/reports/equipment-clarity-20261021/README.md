# 装备领取字体与部队保存入口 · 2026-10-21

装备领取界面原先除标题外大量使用8像素中文，复杂字形在角色、装备特性和按钮中难以辨认。现统一使用已有的原生12像素中文位图，不对8像素字形拉伸，不新增或重压缩字库。说明文字提高明度，背景与柔和焦点阴影沿用原材质。

宽屏人物名单保留每页5名；宽度不足或长姓名／职业／装备超出单行时，改成每页3名、姓名与职业一行、当前武器一行。调整窗口大小后，选中成员仍保持可见。属性比较保留全部9项及实际带符号增减；箭头使用字库中完整的原生符号。按钮保留背景内容安全区内的居中间距。

装备特性按12像素实际字宽换行，按每页6行显示完整内容。上下方向键或左右页箭头翻页；Tab或第三个按钮切换特性／属性比较。换装规则与数值口径保留在特性说明中，避免把脚注重新压回小字。只浏览和翻页不修改装备或行囊。

部队整备的“保存进度”此前调用旧 `_camp_action("save")`，直接写入当前记录槽，并强制将据点模式改成世界模式；S菜单则已接入五槽选择，因此两个入口行为不一致。现部队入口复用现有五槽保存控制器：选空槽后保存，已有记录先确认覆盖，默认选“返回”；取消不写入，失败保留当前目的槽，据点保存仍保留原据点。成功选槽后，后续自动保存跟随所选槽。该菜单底部的“返回标题”已删除，其他系统菜单的该入口保持现有用途。

验证：48项已有装备流程检查、23项部队保存定向检查及17项画面交互检查通过；20张后台截图包含3张原8像素画面对照及17张当前画面。覆盖宽／窄视口、完整名单翻页、窗口变窄、增加与降低、不适配、说明的所有页面、错误说明、整备菜单、保存选槽及覆盖确认。文字安全区域、实际字形覆盖与文字之间重叠检查均通过，并人工核对代表画面。保存测试包括真实键盘与鼠标选槽、取消、另存、确认覆盖、据点续读、失败保留及其他记录字节不变。

测试使用独立临时记录，未写入玩家记录；未进行完整战役回归。Godot逻辑检查结束时存在资源清理提示；断言均通过，后台图形检查正常退出。现有0.10.0安装包未重新导出，本轮交付为源码与对照记录。
