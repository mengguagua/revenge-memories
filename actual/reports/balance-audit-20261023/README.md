## 平衡判断

没有调整职业基底、武器/饰品数值、敌人属性、地图布局或胜败条件。当前证据支持修复以上判定错误；下列合法收益与明确设计相符。

- 一人一个携带槽。兵装、盾与戒不能同时装备；艾琳没有个人吸血法术。术法精熟不授予法术、不改伤害或辅助费用，主动、反击、追击均逐次检查HP支付。
- 以34HP且无治疗、承伤为纯费用上限，艾琳雷电最大施法次数16→33、圣光8→11、风刃11→16、诸神黄昏仍为3；这是已规定减耗的直接结果，不等于实战每轮可施放这些次数。
- 普通队员仍有明确兵装收益。J54历史队伍对首领的零地形回避样本：兰斯铁枪单击11，曜锋枪27；希雅镇关枪20，均有速度追击条件；卡洛引霆剑2格单击9。主角进阶没有在这些样本中消除其他队员的贡献。
- 续愿戒只放大成功的成长项，保留属性上限，不追溯旧成长；有效幸运不写回永久属性。其固定第四章支线来源与剩余培养空间保持。

### 需要保留观察的强组合

**护途盾使终战的单体威胁明显降低。** 最低进阶基底艾琳持盾为21物防、23魔防；J54首领半血强化后的翼喙与聚光总威力为21，两种攻击对她均只造成1伤。贴身普通剑不耗HP，若仅与首领交锋，双方各行动一次时承伤可由5HP阶段恢复覆盖。

这项收益可以实际形成：J53/J54共同战场允许两队成员正常邻接交换，尽管整备行囊仍分队。受控交换用例已验证护途盾、续愿戒分别转交及roster同步；合流前F43/S42不能据此提前使用西队饰品。

本轮保留该强度，因为护途盾是第五章双组伤兵救援后的唯一可选奖励，且占用武器槽；其双防+13、恢复5均为已确认设定。新增AI修复也会使敌人识别护盾防御，其他队员与目标仍需要保护。**尚无完整自然实玩证据证明整关被该组合消除挑战，故不据单挑公式全局削盾或抬高首领。** 若后续实玩显示可稳定忽略其他威胁，应针对这个组合复核，不把负担转嫁给未取得支线奖励的队伍。

此外，J54首领既有移动0、身体射程1–2；三格以上攻击具备距离优势。该限制早于本轮职业/兵装调整，其他敌人及半血援军的实际压力须结合走图判断。任何施法续航估算均须计入敌方阶段反击费用，不能只拿一次主动双击费用与阶段回血比较。

采用五份历史真实部署队伍，通过当前 `start_battle` 重开当前部署。装备比较改变假设携带物，公式地形回避取0；命中结果、追击可能与伤害上界不是自然交锋或通关记录。

| F33 | 提炼院新骸卫与已有队员/装备公式对照；引霆剑在通关后取得，未提前加入该关样本 | 按实际奖励时点核对 |
| F43 | 初始10敌＋既有士兵波次3＋新骸卫4＋裂目子代1，最高18；新生体24HP/力量9/速度4，出生不能行动，无经验、无掉落 | 未越20槽上限；旧波次和新能力分别计入压力 |
| F43 / S42 | 未进阶艾琳现有圣剑对新裂目兽/骸翼兽单击16，罗恩银弓单击25；目标分别27/30HP | 取得新支线兵装前已有克制手段 |
