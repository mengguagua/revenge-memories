`import.json` 记录双方图集逐帧一致性。`neutral-import.json` 记录中立版本与已验收佣兵形状及配色一致性。`scope-verification.json` 验证仅四份既有佣兵地图图集被替换，其他 64 份既有图集和 183 份游戏数据文件保持原哈希；战斗场景、其他角色地图与元数据保持。

`actual/tests/mercenary_map_revision.gd` 通过真实场景和实际角色选择器验证：原生待机节奏、四向槽位、脚下阴影、双眼与侧眼、向左行走上半身固定、站直／跨腿差异、中立角色属性与护送速度、实际 UI 选择器及作用范围限制。比较导入纹理时忽略完全透明像素的 RGB 填充，只比较可见 RGBA 和透明度。

源工程与导出包分别检查，结果为 `runtime.json` 和 `pack-runtime.json`。实际包内纹理后台截图在 `visual/`；包含两名真实村民、头颈两个相位，以及与男主、弓箭手、枪兵并排对照。截图使用已验证的不激活窗口保护，不替换纹理缓存。并排展示时仅临时摆放测试角色。
