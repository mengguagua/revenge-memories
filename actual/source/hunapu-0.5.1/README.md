# 胡纳普重绘源文件（不导出）

仅胡纳普本人。首要身份参考为用户提供的蓝发、青甲、米白披风画像；角色为当前未转职步兵剑士。`contract.json` 保存12色、原动作时序、足点及既有雷电剑程序。

使用内置 `image_gen` 参考图编辑/透明背景模式，每次一个姿势。`generation-log.json` 保存23条成功生成与修订的完整提示词、默认生成结果绝对路径和本地副本名；19个不同姿势，另有待机、收势和两个背面步态的4次修订。连接失败的调用没有产物，不计入成功次数。

参考顺序：用户画像负责身份；审核后的 `battle-0.png` 负责简化服装与武器比例；`poses/battle-N.png` 等旧素材裁图负责对应的骨架姿势。方向小人参考相同身份及对应旧据点/地图帧。所有原始PNG继续保存在这里及生成工具默认目录，早期版本保留 `-initial.png` 副本。

`tools/build_hunapu_assets.py` 仅做透明边整理、最近邻注册、统一调色板和图集组装。原始大图不是游戏运行尺寸；最终设计稿以 `assets/hunapu-0.5.1/frames/` 为准。原动作帧8的斩击弧和124的上升剑影来自旧素材，作为原效果保留，不冒充全新生成姿势。

本目录 `.gdignore` 隔离Godot导入，导出规则排除 `source/*`；原图和旧帧裁图不打入应用。
