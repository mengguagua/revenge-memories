# 0.3.0 战场重构与建筑访问验收

15张战场均按所在地形、任务和建筑用途重排。海峡旧塔堡现在是扼守海峡的塔堡半岛，包含三塔主堡、堡门、西崖缺口和港侧栈道；海上拦截与押送舰扩大为可集结的大甲板，保留上下两条登舰线。矿道和海洞通过内部岩体分成主巷、支巷与岩室；军港采用木码头、草地、土质车道和少量石台。

## 建筑尺度和交互

- 22处普通建筑为16×16的一格地形，可以由我方或敌方占据。屋舍、仓房、军帐回避20；营垒、舵楼哨位及甲板掩体回避40，并沿用原地形218的每本方阶段恢复5生命。没有额外加入防御数值或修改战斗公式。
- 14处较大建筑提供门前访问。主堡4×4格，其他主要访问建筑2—3格宽、2—3格高；舱室3×2格。完整剪影保持比例，入口有独立门图和访问指示，只有正面门前一格可以访问，侧后方无效。
- 塔堡、军帐、守灯人和洞口等提供战术信息；其他部分访问提供皮盾、钢枪、钢剑或钢弓。访问者有空装备栏且职业可用时直接装备，否则沿用队伍/运输队的接收规则。装备与战场单位同步；存档后不能重复领取。
- 运输队满时显示提示，保留奖励和角色行动；整理后可以再次领取。可选访问既不能代替囚门/占领目标，也不会成为主线通关条件。
- 囚区、城门、桅杆、船舷和岩体按实际结构占多格。门与通道使用对应的碰撞和开门后地面，并非普通可占据建筑。

## 检查与修复

- 几何和资源：1360项通过；普通地面连通、全部角色/出口、前门、事件船水路、素材范围、图层索引和完整透明轮廓检查。
- 存档/交互规则：670项通过；15份旧开局、0.2.1中途存档、重试重新部署、读写、正面与侧后方访问、奖励幂等、满库存、双方地形效果、可选访问不影响主目标。
- 视觉：50张后台GPU实际视口，全景15张、正常横屏31张、真实访问菜单与画像对白4张；文字安全区0错误。全景使用与地图相符的实际视口并隐藏悬浮地形卡，未移动角色拼接假图。普通视口426×240，保留正常界面。
- 独立应用：0.3.0导出包从工程目录外运行86项检查与43次菜单输入通过，验证章节过渡、真实伤亡装备、旧场景续玩和正常重试进入新版；代码签名有效。包内不包含测试和源图。
- 所有交付PNG均使用无损压缩，50张截图最大171805字节；20个新/复用模块最大2232字节。原生成源图与提示词隔离保留，实际像素尺寸与体积见清单。

扩大地图后，粮站焚毁兵出发改为第7回合、第6回合预警，仍需连续两次在门口焚毁才失败。船战增加与原恢复规则一致的轮换位置，礁岛留守营地移近登陆处，未改单位基础数值。囚船初次尝试存在伤员轮换和队伍脱节，试玩助手的布阵评分也会阻止健康法师跟上前排，已修正后重跑。矿道初次布局的护送失败保留；补充岩室分流后的两轮结果见最终表。

旧试玩助手曾在读取失败时写回来源检查点，已恢复原件，并把诊断写入隔离目录。最终71份正式自然战役存档均与Git HEAD逐字节一致。原版和0.2.1兼容地图共用冻结输入，避免另存一套重复基线。
