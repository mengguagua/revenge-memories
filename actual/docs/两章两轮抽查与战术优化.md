## 修复与调整

1. **建筑、箱车和碰撞对应。** 第一章部分箱袋、粮车、药车和火盆原先继承地面通行，人物可以穿过图案。现在完整占格阻挡地面部队；角色部署、门前交互位置和出口仍保持可达。飞行部队沿用原职业的地形规则。
2. **未开牢门的俘虏。** 将第二章已经采用的“守军管理被关押者”语义应用到第一章押送所与旧塔；未获释者不会被守军自动当成战斗目标。开门后按正常规则受到攻击，属性没有增加。
3. **地形信息可见。** 空地检查、移动选格和人物卡显示地形、回避与当前角色的移动消耗。林地沿用物理回避40，石铺地20；林地对骑兵、步兵、飞行部队的消耗分别为3、2、1。魔法命中继续使用原来的独立规则。
4. **战场路线形成选择。** 押送所增加土院、两处两格缺口和东侧外廊；旧塔增加内院建筑与防线，保留中路缺口；军港增加完整仓库和箱袋，形成单格通道及侧路；海洞延伸完整岩脊，两侧仍可绕行；粮仓外增加一处完整林地。
5. **跨场景提示遮挡。** 从整备进入战场时清除上一场景的短提示；短提示显示时暂时收起地形卡，避免两个面板互相遮挡。人物卡扩大安全区并补上所在地形。
6. **旧存档保留原战场。** 0.2.0的进行中战斗继续使用当时的布局，避免新增墙体出现在已保存的角色脚下。正常重试或返回整备再进场时采用0.2.1布局；新存档保存地图版本。队伍、装备、伤亡和存档目录继续保留。

地形与建筑调整保留原有部署点、敌人数目、敌人属性、目标位置和目标条件。押送所、旧塔、军港从初始部署到首领的最短地面距离分别仍为34、30、42格。近战占位、远程射程、命中、伤害和成长继续使用既有《外传》规则。
