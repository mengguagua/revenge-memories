## 实现

- 据点标题与提示改用现有原生12px中文点阵字，重新按实际字宽换行、居中并扩大面板，至少保留12px水平内容间距。使用现有位图边角与最近邻整数显示。
- 据点与世界/战场小人使用原版个人1号六帧步态，保留各方向原始手、脚、头部及黑色轮廓的每个像素，只按原生像素标注颜色。战场24×24与据点32×24之间只转换整数地块原点。没有缩放整个人物、压缩包围盒或填掉四肢之间的空隙。
- 战斗133帧全部保留原版透明轮廓、四肢空隙及武器位置。按原生像素重新配色，动作素材仍控制为12色＋透明；蓝发、青蓝轻甲与米白肩披风保持身份对应。
- 胡纳普 present / memory / victory 三张画像分别修复鼻、眼与闭合嘴线，运行版仍为48×48、每张24色，嘴线在实际显示尺寸可见。既有其他45张画像继续复用。

画像使用内置 `image_gen` 的参考图编辑模式，输入为原48px画像的整数放大稿；要求只修复面部像素簇，保留身份、服饰、角度和构图。原图、输入稿及完整提示词分别保存在 `source/clarity-0.5.2/` 的三组生成记录中；运行画像在 `assets/portraits-0.5.2/`。动作使用用户要求的原版像素骨架复刻与索引配色，不再使用0.5.1的大图缩人流程。
