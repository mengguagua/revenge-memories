# 第一章升级与属性成长：现行实现

本次只整理规则，没有改变成长算法、角色成长值或存档数值。

## 升级触发

- 经验达到100且当前等级低于20时，升1级并扣除100经验。截图中的90+25=115，因此升到2级后剩余15经验。
- 每次升级分别判定生命上限、防御、幸运、速度、技巧、攻击六项。不是固定分配属性点，也不是每级必涨多项。
- 每项产生一个1～99的随机整数；只有随机数**小于**该角色的成长值才成功，相等也失败。例如胡纳普攻击成长值35，随机数1～34成功，35～99失败。下表是代码中的成长判定值，不能直接当成精确百分比。
- 每项成功通常+1；持有天使戒（物品55）时，成功项+2。生命上限最高52，其余五项最高40，增加量受上限约束。
- 六项判定全部失败时，保底增加生命上限1（天使戒为2），同样受52上限约束。
- 已到上限的属性即使判定成功也不会显示增加，但它仍算一次成功，因此不会再触发生命保底。高属性角色存在一次升级没有可见加点的情况。
- 生命上限成长时，当前生命增加同样的数值，不会因此自动回满。移动力、抗性没有普通升级随机成长。

成长值来自角色数据，升为进阶职业不会把普通升级变成“职业固定加点”。晋升是另一套规则：等级重置为1、经验重置为0，六项属性至少提高到目标职业的晋升基准，原本较高的属性不降低；若六项都不需要提高，生命上限未满52时再+1。

## 截图中只涨幸运的原因

胡纳普的幸运判定成功，另外五项失败，所以仅幸运+1。这是现行规则允许的正常结果；因为已有一项成功，生命保底不会触发。本轮边界检查覆盖了单项成功、六项失败、相等失败、上限、天使戒等情况。
