# 序章与第一章交付

范围：正式39据点/40路线大地图；505格战斗图集、40个完整模块；可操作P00序章，M11—M15主线及S11/S12支线；对应据点、招募、物资、剧情、转职、整备、保存、失败重试和近景对战。第二章及以后本轮没有实施；其地图节点和连接已经安排，运行中按章节封闭。

## 运行

独立macOS应用：`../dist/RevengeMemories.app`。本机工程启动：`../运行游戏.command`或Godot打开`../project.godot`。应用未发布到外部服务。独立用户目录`revenge-memories-actual-campaign`，存档`revenge-memories-ch1.json`；不迁入/覆盖旧复刻存档。

方向键（W/D也可上/右）移动，Z/Enter/空格确认，X/Esc返回，S菜单，Tab/A状态，M音乐，F1提示。战场移动后可以攻击、魔法、交换、交互或待机。目标格/牢门要用动作菜单明确确认；用S查看目标或“返回整备（重置本战）”。后者回滚本战，保留此前实际进度。

序章面对赫兰/艾琳交谈，进入半年前。雪原村先在墓前确认，出村北行。林路胜后两条支路开放。粮站分粮后可邀芙拉；押送所取军令、邀请存活蕾娜，再去东侧教堂合作；兰斯加入。塔堡击败科兰后，先安置伤者，再确认日返。支线在日返前可往返，放弃时有明确提示。死人不补入队伍。

本轮数值是新战役的明确初版：普通敌人Lv1、HP22/24、力量7/8、防御3；指挥官Lv3/HP27；科兰HP32/力量12/防御8。回合、追击、反击、射程、法术HP支付与成长使用既有规则。S11工具箱中的军备为钢枪(ID2)，过关另得钢剑(ID11)，均为普通物资，不是主线钥匙；药箱不占装备槽。

## 三轮验收

1. 目标与阻塞：400项定向检查通过，含各关独立目标、一次性增援、奖励幂等、真伤亡、重试/整备回滚、独立保存及损坏数据拒绝。这是声明的逻辑夹具，不冒充自然实战。
2. 道路、地形与视觉：1782项检查通过；40路线共420个连接步、142个陆路格，移动格均有道路像素，完整山林模块不遮通路。全职业地形表核对；40完整模块像素一致重组。实际运行图检查文字内边距、角色/物件、门道与地形。对标《外传》复杂图块，使用砖纹城墙、屋顶门洞、多格山林、物资和专用情节物件，移动范围提示关闭后仍保留材质结构。
3. 自然输入试玩：实际控制器4236次输入，七关自然取胜。M11第14回合，S11第13，S12第7，M12第13，M13第13，M14第5，M15第6；剧情与据点由实际行走/面对确认推进，并完成日返及章节保存。修复时从真实检查点接续，不改玩家/敌人属性、不强制判胜，不重打不受影响的胜利。药车身份修正后另从真实S12开局补测，第6回合自然取胜，238次输入。

测试途中发现并解决：撤离流民仍占出口、局部旧地形表使弓手不可动/地形错判、护送者闯入敌阵、守军未按剧情守位、招募晚回调切回据点、焚毁兵错误直接站粮门、页脚文字超安全区、药车被当人物反击、职业资料加载缺失。失败尝试原样保留在attempt报告，没有隐去后改为胜利。

真实试玩阵亡保留：芙拉、蕾娜。后续对白/招募按缺席分支，第一章仍能完成。阶段成长、物品与实际队伍均在报告和存档中；本次不声称全部人物无损招齐或平衡已适配所有玩家策略。

补充8项菜单检查通过，使用通关存档的测试副本验证续玩、状态、转职、取消及快速招募转场；原始自然试玩存档未被转职测试覆盖。
