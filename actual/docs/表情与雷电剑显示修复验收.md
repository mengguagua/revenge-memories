## 雷电剑人物消失原因与修复

原版 class21 的背景姿势60—64是局部 8×8 图块上传，不是五张独立完整人物图。之前将每次上传单独生成透明图片，最后的上传只含剑，因而在蓄力时替换掉了人物；前几个准备姿势也缺少没有再次上传的腿脚。

0.5.3 从待机背景初始化，按原顺序累积写入这些图块。上传中明确的空白图块会清空相应区域，未写入的身体图块继续保留。修复 atlas 中120—124五帧，其余128帧与0.5.2逐像素相同。身体轮廓来自原版 CHR 和背景表；只按现有12色个人调色板换色，不缩放人物骨架。
