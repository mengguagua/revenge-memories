# 0.3.7 实机交互修正与《外传》差异

2026-10-16。适用于 `actual` 中序章、前两章全部15张战场及据点、世界整备；共享控制器统一生效，独立存档路径保持原样。

## 本次修正

| 用户问题 | 当前行为 |
|---|---|
| 时间、地点和长期提示过大 | 左上角小框，原生8像素中文字形；提示自动换行，留足边框安全距离。底部临时通知和剧情框不再与其重叠。 |
| 快速找未行动友军 | E向后、Q向前，按队伍顺序循环定位；跳过阵亡、已行动、隐藏及自动行动单位。确认后才进入移动，不消耗行动。菜单、目标选择、动画和敌方回合不会被快捷键打断。 |
| 人物状态切换 | 在战场、据点和世界整备状态页按左右切换当前队伍，首尾循环。查看敌人或任务NPC时不混入己方名单。修复据点状态菜单原先无效的动作名及返回位置。 |
| 战斗下方黑线、文字变形 | 使用既有干净边框的固定尺寸角块，重新排布红蓝面板，不拉伸含旧标签和横线的HUD纹理。伤害、防御、命中和HP格完整位于安全区。防御显示本次攻击对应的装备后物理/魔法防御。 |
| 敌方结束后镜头留在敌人 | 新的己方回合将光标和镜头归到本队主角；主角缺席时选择首位存活、可操作队员。 |
| 悬停敌人不显示移动范围 | 默认显示红色可移动格，使用当前地图的地形消耗、碰撞、装备移动力和单位占位计算。表示移动范围，不表示攻击范围。 |
| 经验条和音效 | 50个离散小格，每格2点经验，奇数点显示半格；结算填充过程中播放现有原版音色的短提示音，限制触发频率，升级音乐保留。 |
| 弹框被光标压住 | 先绘制地图光标，再绘制攻击/支援预览和状态面板。临时通知不再盖住状态页或战斗信息；回合标题不再覆盖已打开的攻击预览。 |
| 双方行动后都变同一种灰色 | 我方保留原灰色，敌方改为暗红灰色。只替换两种灰色调，原黑色描边、像素形状和透明度完整保留。 |
| 弓手贴身反击 | 保留。普通弓为1—3格，钢弓、圣弓、银弓为1—5格；弓骑士为1—5格。1格可以攻击也可以反击，且仍受存活、是否允许反击等条件限制。 |
| 装备系统不明显 | 已有一人一件携带物系统；相容装备自动生效。整备入口明确为“交换装备”“装备行囊”，补“装备说明”，状态页底部明确显示装备，战中相邻交换入口也更名。武器、盾、戒指共用一个携带位置；空手仍有职业默认攻击，无耐久和购物式武器维护。 |

快捷键定位不撤销已经确认的移动或行动；只有尚未确定目的地的移动选择可直接切换。状态页不改变队伍顺序、行动状态、装备、成长或随机数。

## 原版核对依据

本地反汇编为 `/private/tmp/fe2-analysis-20261012/src/`，来源 [minirop/fe2](https://github.com/minirop/fe2)，固定修订 `956365ef33c63751e7afd03f05e600d7728549da`。

- `bank009:L09844A—L0984DE` 对双方采用“曼哈顿距离减1”的射程判断：普通弓阈值2、三种装备弓/弓骑士阈值4。相邻距离减1为0，并没有禁止1格的分支。对应实现是 `core/combat_rules.gd` 的 `attack_range`、`default_counter` 和 `strike_sequence`。
- `bank015:L0FF460—L0FF507` 和 `data/legacy/rules_full.json` 核对职业、个人武器及HP门槛；携带不等于职业可以使用。`core/item_rules.gd` 与 `core/battle_inventory.gd` 保持单物品字段及现有交换/结算规则。
- [任天堂《外传》说明书](https://www.nintendo.co.jp/data/software/manual/man_tcgj.pdf)第3节写有快速定位未行动友军；第10—11节说明队伍参数、携带物交换/存放/领取；第13—14节说明邻接交换、射程及交锋后的经验；第17—19节列出武器、防具、戒指和魔法。
- 小提示字体直接复制 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 2026.09.25 的8像素BDF字形，不缩放12像素正文。完整授权位于 `assets/fonts/OFL.txt`、`assets/fonts/LICENSES/`。

## 另外发现、保持现状并交由用户决定的差异

| 项目 | 原版与本作当前差异 |
|---|---|
| 状态信息分页 | 原版可进一步查看装备造成的能力变化和可用魔法。本作当前状态页仍以基础能力、HP及携带装备为主；可用魔法列在战斗行动菜单，尚无同等的装备变化/魔法分页。 |
| 近景数值含义 | 原版ATC栏表达攻击力；本作沿用“伤害”，显示针对本次目标防御后的预计伤害。本次修了排版和防御显示，没有改成ATC式文案。 |
| 动画与等待设置 | 原版有攻击动画开关和消息等待设置；本作目前保留动画，按住Z/空格可加速，没有提供同等的独立开关。 |
| 世界敌军行动 | 原版世界地图上有敌军行动与再出现。本作39节点按剧情和章节开放，目前没有原版式世界游荡敌军系统。 |
| 胜利目标 | 原版多数战斗以清敌为基础；本作另有护送、释放俘虏、控制道路、守灯和船团抵达等组合目标，属于已确定的改编设计。 |
| 保存与重试 | 本作自动保存，并能从开战快照重试或返回整备；与原版记录/战中中断的限制不同。没有收紧当前便利功能。 |

以上不是宣称完成原版全部细节复刻，也没有为了统一外观而改动伤害、命中、掉落或成长公式。
