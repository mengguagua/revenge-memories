# 0.4.0 濒死留队与前两章泉水救治

2026-10-16。根据[全战役设定](../../docs2/泉水与濒死救治设定.md)接入现有序章至第二章应用。第三、四章尚未开发，本次没有加入会合营站、最后补给、共享库存或第五章入口。

## 在队与作战

已招募正式成员HP归零进入“濒死”，保留原队名册、人物身份与现有成长，不能出阵、不占实际部署槽。状态菜单包含全部成员；整备另显示可出阵人数。濒死者不能领取、交换装备、转职或使用属性泉，战场普通治疗不将其救回。

战中立即保存伤者实际等级、经验、属性、职业、法术和训练字段；不退回战前成长，也不额外领取战后胜利经验。携带装备只归还一次到原队行囊，不复制、不丢弃；救治后按原有装备规则重新分配。

濒死状态不会因下一战满HP、过章、返回据点、重新读档而解除。重试恢复真正的战前快照：只撤销本战造成的伤情及本战进度，不救回战前已经濒死者。胡纳普、艾琳濒死仍立即判本场失败，不消耗泉水份额。

未入队的招募NPC、普通NPC和敌军保留真实生死。凯尔、薇娅的既定死亡不改写，泉液不能使死者复生。

## 剧情

D12合作与岛民安置由固定医者说明泉液额度、个人限制、留队照护及不能救回真正死者。救治不绑定芙拉、米蕾等治疗角色的招募或作战状态。伤者现场交谈采用照护短谈；需要出战、修船、治疗或交接工作的原对白由现有固定工作人员承接。

卡洛濒死时，由固定舵手代为履行遗物交接，不再写成他留下身后遗物；S22旧船员对白也明确卡洛正在接受照护。遇难船员及其家属的真实遗物保留。第三章之后的关系和结局变体仍为设计稿，未宣称已经实现。

## 旧存档

新保存格式为schema 3，新增伤情、曾濒死、个人救治次数、来源及本队使用记录。读取schema 1/2时先验证原记录，再迁移副本并验证，成功后才替换当前状态。只有原队正式成员的阵亡或HP零记录转为濒死，保留原队、成长和装备。原存档未保存过的成长无法凭空补回。

进行中的战斗采用最新战术角色记录保留当场成长；战前重试快照独立迁移，不把本战新伤情写进战前。装备已归队则不再添加，仍携带的装备转回原队行囊。未招募NPC死亡不补招募。

第一次原路径覆盖旧存档前，完整原文件复制为`原文件名.pre-casualty.bak`，已有备份不覆盖。备份或保存失败不会完成救治，也不消费份额。历史验收存档在测试中仅供读取，所有测试写入独立临时目录；旧报告的阵亡表述仍描述当时实现。
