# 现代像素世界地图 · 审阅版01

本轮按「改编设计」最新定稿制作；原参考位于 `../docs2` 和 `/private/tmp/revenge-docs2`，原复刻工程与剧情文档未改写。

## 画风与分层

采用高位俯视的现代像素幻想地图：清楚的方形像素簇、左上日照、冷青阴影、砂岩石墙、青绿屋顶与琥珀灯光。现代指美术质量与层次，不改变故事的幻想时代。地图保留西大陆、东群岛、大断裂、神幕与乌库布·卡基的定稿关系。

生成使用内置imagegen，没有使用收费API脚本或以代码图形替代地点美术。地形与地点分别生成；地点轮廓按alpha连通区域提取，避免等格切图削掉塔尖、旗帜或邻图串入。几乎透明的底色残留经过alpha清理，独立运行图标使用最近邻采样并保留透明留白。道路为单独的设计几何层，不属于地形绘画。

生成提示词全文及迭代约束在 `source/prompts.json`。采用的源图为 `source/terrain-generated.png`、`source/landmarks-generated.png`、`source/supplement-generated.png`，原图离线保留且不导入Godot。运行版本在 `assets/`。

## 世界布局

39个节点的ID、名称、章节、道路关系和门槛与定稿一致。海峡城继续承担旧塔堡、庆典与第三章两队脱围；两队在会合营站交换调查结果；北境日塔停用仍依赖盐原观测台；第五章通过双方入口到达前庭与神座。

新地形采用1176×1344固定画幅，保持7:8比例。原56×64格坐标保留为 `source_grid`；适应岸线、山口和港湾的新像素锚点保存在 `position`。这是显示坐标调整，不改变节点拓扑和战斗顺序。后续战术图使用各自局部坐标，不把世界地图像素当战术格。

地图背景是专用完整世界图，只按统一比例缩放，不用于九宫格或其他长宽比；角花、云台、海岸不会被独立拉长。地点图标保持自身比例；可复用的独立图标有24种。碎石海洞S04使用底图中的天然海洞轮廓和独立交互锚点，没有额外贴入不合语义的矿洞图标。

当前路线显示用于确认通行关系；陆路绕湖、经山口，海路沿海峡与岛链，登天通道使用独立颜色。完整地图默认隐藏路线和多数文字，点选时只显示当前名称；开启名称后按实测矩形隐藏相交标注，可放大查看。神宫在完整审阅图可见，篇章筛选是设计工具，不宣称实现了战役解锁。

## 文件大小与视觉验收

`reports/asset-manifest.json`逐图记录用途、尺寸及实际字节数。24个独立地点图标均小于20,000字节。地图PNG经过oxipng无损优化，无损WebP作为较小副本；复杂地形背景超过200KB参考值，保留清楚的山体、林缘、海岸和像素纹理，按2026-10-03的视觉质量优先规则记录例外，不强制量化或降低分辨率。

PNG运行图和高质量压缩截图分开保存，`reports/world-map-review.webp`及路线版是审阅副本。原PNG截图继续保留。

本轮验收包括图标深浅背景轮廓、素材路径、39节点/40道路一致性、节点可达、全部Godot地点面板与视口边界、代表性地点点击、五章筛选、桌面和390px窄屏文字标注。选中及键盘焦点使用柔和发光/阴影，没有黄色矩形或简单焦点描边。

不需要全量复刻游戏回归：本轮是独立美术/地图预览工程，没有改存档、奖励或原核心玩法。战役逻辑、人物动画、战术地图、正式操作界面及新存档属于后续里程碑。
