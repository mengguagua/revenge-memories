# 0.5.0 首关节奏、战场提示与画像重绘

2026-10-17。对应现有序章、第一章7关及第二章8关。第三章之后仍未开发。直接运行包为 `actual/dist/RevengeMemories.app`，无需解压；更新后退出旧进程再打开。

## 信息框和目标位置

人物信息框改为144×92逻辑像素。定位器以人物24像素精灵和上方箭头的完整范围为硬排除区，在左右、上下候选位置中选择，限制在视口内；有位置可用时同时避开其他人物。出口标签也作为排除区，并自行避开光标和周围单位，按上、右、左、下寻找可用位置。回合横幅和临时通知出现时暂时收起信息框。地形卡、船只卡共用定位器，沿用现有位图面板及像素字形。

出口使用绿旗和文字标签，离开视口后显示方向及“S定位”；S菜单可直接定位出口或当前首领。首领有橙旗，菜单名称来自实际单位。首关原“指挥官”统一为“追击队长”，目标说明与状态页一致。胜利界面改为“战场目标已达成”，避免把护送胜利误写成敌军全灭。

## 首关与其他关卡

M11保留雪谷、两座桥、村舍和访问奖励，将地图从36×28收紧至22×18；地图显示层、碰撞、访问入口与出生位置一起调整。10名初始敌人，另有第4回合两名增援；首接敌距离由23格缩短至3格。新增敌人的经验值为50，队长为100。胜利追加60训练经验，正式存活成员可以正常跨过100经验升级，使用原成长率、随机成长、属性上限及法术学习规则，结算只执行一次。没有直接指定等级或固定成长，濒死成员不领取胜利经验。

追击队长4级、32生命、10力量、6技巧、4速度、5防御，携带实际生效、击杀必掉的铁枪；普通首轮敌人为18生命、6力量、2防御。队长守在东北出口唯一入口(16,4)，出口为(16,3)，两侧和后侧是实际不可通行的岩石。必须先击败队长才能护送通过。

弓手改为按真实武器射程寻找合法射击格，有目标就移动射击，否则沿可达路径接近射击位置；不再以近战相邻格为唯一追击目标，也不因旧“guard”配置永久原地等待。射程、命中、反击、伤害和装备规则继续使用现有战斗系统。

其余14关逐关调整合法部署点，开场最近敌军距离控制在8—9格，保留各关建筑、战术目标和剧情。护送者基础移动3格，全部敌军及增援清除后移动5格，仍沿真实道路前进、遇敌停步；不传送、不救回濒死者。F26居民船在沿岸清场后由每回合3格加速至6格，危险区仍停船。

2026-10-19，0.8.9 针对首关 `M11_refugees0`、`M11_refugees1` 单独调整：两名持剑村民在自动友军回合中，本回合能接近并攻击敌人时使用现有友军选敌和战斗流程；没有可攻击目标时继续原安全路线护送，已站在出口则优先完成撤离。此项按用户确认的主动战斗预期调整，不属于佣兵换皮变更；保留职业、属性、移动点、阵营、护送胜负条件及其他关卡护送 AI。定向回合、旧存档副本与包内验证记录在 `actual/reports/m11-villager-behavior-20261019/`。

F21将指挥官移至登船路线附近：5级、28生命、10力量、5防御；普通海兵19生命、6力量、2防御，保留首领差异。移动一处既有恢复地形到上层跳板内侧(25,13)，标为“船医补给点”，普通伤势每回合恢复5生命；原有恢复格总数不增加，不消耗救治泉份额，也不能治疗濒死。通关追加35训练经验。

F22俘虏接应点改为敌舰中段囚舱总闸旁(29,16)，避免必须绕回己船末端；仍须开闸、救出三名普通俘虏并击败首领。S22旧船员与伤者放在藏身处旁，救人目标与画面位置对应。复杂关卡仍包含战斗、开闸、探索与护送，未承诺所有回合都有交战。

## 画像及剧情阶段

当前实际使用画像全部重绘为48张，统一48×48逻辑像素，保留主要人物发色和身份特征，以较清晰的像素块、有限色阶及轮廓表现年龄和服饰。通过内置 image_gen 逐张生成，再制作运行副本。现有战斗动作没有随画像改动。

普通敌人按西部雪国、东部海岛的服饰区分步兵、弓手、重装、佣兵和法师；西队另有骑兵，魔物独立使用石像鬼和亡灵形象。黄金骑士按骑兵分配。普通平民、医者、管理员、船员、矿工等有对应身份；科兰和军港裴萨使用具名画像。登船关普通指挥官不冒用裴萨。

## 存档和验收范围

旧版进行中的战斗保留原地图、部署与当场成长，首关队长只同步名称和首领标记，不回填生命、装备或重置经验。正常重试、返回整备重新进场后采用新版地图；各旧修订的地图数据保存在compat目录。0.4.0濒死留队、装备归队、救治次数及schema 1/2/3兼容规则继续保留。

两轮使用真实按键操作，合计抽样16场、覆盖全部15个现有战场；其中第二轮首关从标题新开档，经序章、墓地、正常世界交通入场。其余从历史真实部署检查点返回整备再入场，不冒称两次连续从头通关。两轮包含普通战斗、自动护送、开锁、补给、升级、胜利和存档；未改生命、属性、坐标、随机种子或强置胜利。自然伤亡照实保留。第一轮F21失败后进行了上述平衡修正并补测，原失败记录保留在attempt索引中；首关村舍访问和F22接应路线另作补测。

另外进行全部15关开场、物件及通路检查，弓手追击、队长阻路、升级结算、旧档重试，48张画像资源和剧情标志检查；回归伤情救治、装备及第二章规则。256×240与426×240检查信息框和文字实测安全区，后台真实渲染全部地图、画像状态页及试玩截图。包检查仅加载签名应用内嵌PCK，验证版本、资源、旧档和新规则。具体数量和结果以[交付汇总](../reports/playtest-0.5.0/delivery-summary.json)为准。
