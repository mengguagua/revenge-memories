# 胡纳普像素重绘 · 0.5.1

本轮只处理胡纳普本人。按用户选定的蓝发画像，统一为年轻步兵剑士：短蓝发、浅青领口、青色轻甲、米白及腰短披风、棕靴、普通单手直剑。当前48张画像及胡纳普已有剧情阶段画像继续复用；本轮重绘地图、据点和近景战斗小人，使其与已选画像一致。

## 配色与素材

- 所有新动作共用 **12个不透明实色＋透明色**，无渐变、无抖动纹理，透明度仅0/255。发色2阶、披风2阶、轻甲3阶、肤色2阶，另有轮廓、皮靴和剑刃各1色。
- 地图24×24、据点32×24，各6帧；朝下/上/侧面各两步，左行镜像。内容沿用16×16地块尺度、原足点和步频，静止与已行动状态均可显示。
- 战斗80×72、足点[40,64]；16个当前动作/效果帧，含待机、助跑、举剑、下劈、收势和现有雷电剑姿势。大地图、据点、战场、近景战斗均绑定胡纳普个人ID，其他队员与敌人不串用。
- 原始生成图保存在 `source/hunapu-0.5.1/`，有 `.gdignore`，导出排除；生成工具默认目录也保留原件。运行版与切帧在 `assets/hunapu-0.5.1/`，三张运行图集分别为469、474、8590字节，完整尺寸/颜色/字节/哈希见 `reports/hunapu-0.5.1/asset-manifest.json`。

图像制作使用内置 `image_gen` 的参考图编辑模式（透明背景）。参考包括用户选定画像、审核后的待机姿势及对应原动作姿势。实际提示词与23条成功生成/修订记录见 `source/hunapu-0.5.1/generation-log.json`。其中19个不同生成姿势，经透明边清理、最近邻原生尺寸整理及统一12色，形成最终像素设计稿；原图不直接装入游戏。

## 动作与结算对应

这是战棋剑攻击，现行实现没有出牌系统；按实际武器定义核对动作，不添加不存在的卡牌或能力。

|角色ID|现行武器/行为|动作|效果触发|
|---|---|---|---|
|hunapu|铜剑等普通剑，普通近战|助跑→举剑→单次下劈→收势/退回|85个准备tick后调用原contact一次，随后104个收势tick；命中、落空均保持一次结算调用|
|hunapu|现行可装备雷电剑，近/远攻击|原有准备、举剑及上升剑影|使用原298 tick程序，contact位于原226 tick边界；原特效单独播放|
|hunapu|据点/世界/战场移动|上下侧各两步、左行镜像|沿用原输入、路径插值和16 tick步态，不增加战斗效果|
|hunapu|已行动|相同个人轮廓的灰褐配色|仅反馈回合状态；仍使用同一12色调色板中的3色|

原战斗帧编号、位移、镜像偏移、播放程序、单次命中、受击/落空与回位逻辑均保留。第8帧保留原97像素斩击弧，第124帧保留原上升剑影轮廓，并映射为同一剑刃色；它们不代表额外攻击。未开发章节、转职与弓箭能力不新增；已转职记录走原资源回退。

## 对比及两轮验收

1:1核对对象为**最终原生像素设计稿与引擎显示**。生成大图经过上述12色与原生尺寸整理，不宣称其与运行截图按大图分辨率逐像素相等。31个明确标记的冻结姿势/朝向夹具检查，累计4975个不透明前景像素差异为0；同时检查文字安全区。夹具不作为自然通关证据。

52项无窗口动画检查通过：资源、12色透明边、个人ID隔离、帧/足点/镜像契约、普通剑命中/落空、雷电剑近/远程序、单次contact与特效清理。独立签名包另有20项检查通过，验证实际内嵌PCK的版本、素材、旧存档、成长/经验/装备及动画程序。`codesign --verify --deep --strict` 通过。

|轮次|实机范围|结果|动作及画面|
|---|---|---|---|
|1|从新游戏、序章、据点及世界行进进入M11；实际键盘移动/攻击|第3回合流民队1被击倒，任务失败；记录保留|前两次胡纳普攻击完整播放原程序，捕获0—9及60号姿势，截图文字检查无异常|
|2|读取真实历史M15部署存档，经正常整备、装备、重新入场与攻击|第4回合胜利；正常成长与装备保留|前两次胡纳普攻击完整播放原程序，捕获0—9及60号姿势，截图文字检查无异常|

两轮均由真实输入驱动；没有改HP、数值、位置、随机种子或强制胜利。其他战斗展示加速，前两次胡纳普攻击使用非instant播放。第一轮败局不是重绘缺陷，本轮不调整平衡，也不把两轮写为全胜。检查范围是本次角色外观与动作接入，未重复两章15关全量回归。

所有图形运行均启用既有后台防抢焦点保护，以离屏视口捕获，不激活游戏窗口。实机图、12色稿、旧/新动作程序对比、两轮结果及原始JSON在 [验收画廊](../reports/hunapu-0.5.1/index.html)。连续实机帧动图为便于观察的慢放，不能作为墙钟帧率测量；原动作时序重放另列。

画廊已核对本地图片、链接及动态姿势路径。当前浏览工具禁止自动打开 `file://`，因此未声明画廊的浏览器渲染验收；游戏画面已通过上述引擎截图与像素核对。
