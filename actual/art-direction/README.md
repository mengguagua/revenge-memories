# 经典像素画风候选

日期：2026-10-14。状态：用户已选定B「朴素复古」，并要求世界地图瓦片向《外传》示例的地理符号与粒度看齐。现行瓦片资源位于 `../assets/world_tiles/`。

用户修正：不要太锐利的现代，改为类似《火焰纹章》的经典像素风。此前现代细节较密的样稿撤出候选，源图归档保留。

| 候选 | 视觉特点 | 剧情适配 |
|---|---|---|
| A 清爽掌机 | 蓝灰屋顶、清澈蓝海、较明确的柔和色块层次 | 少年冒险、故乡与港城的日常；神教建筑清楚但不过分奢华 |
| B 朴素复古 | 灰紫屋顶、橄榄绿、灰蓝海、旧铜；减少碎纹理 | 复仇、失散、旧世界与神教责任，较沉静 |
| C 温暖古典 | 奶油色墙、陶红屋顶、柔和青绿水、圆润轮廓 | 普通人的家园、真实恩情与灾后生活，使失去保护有情感对比 |

三张从左到右均为西大陆雪原村、海峡港城及传光日镜、东群岛沉没祭所与盐地。村舍、松林、墓碑、城门、码头、船、祭所、芦苇等元素对应已定稿剧情，使用原创幻想建筑和太阳意象。没有新增角色、战斗动作或剧情能力。

这是图像生成的画风样稿，展示色彩、形状和细节密度。图中并不包含已验证的瓦片图集、真实32色索引或运行地形ID；提示词中的原生像素密度与色数是美術方向约束，不能作为素材规格已经实现的证明。正式瓦片尺寸、拼接邻接、边缘转角、地形类别和运行验证在选定画风后制作。

通过内置imagegen生成，原PNG及完整提示词保存在 `../source/style-studies/`；该目录已有上级 `.gdignore` 隔离。当前目录的WebP是同尺寸、高质量压缩审阅副本，图像未裁切、未降低分辨率。实际像素尺寸与字节数见 `manifest.json`；超过200KB参考值时保留三场景的像素轮廓与颜色层次，遵循视觉质量优先规则。

打开 `index.html` 可以离线比较；本机服务开启时也可查看 `http://127.0.0.1:8765/art-direction/`。本轮没有改动Godot场景、战役逻辑或既有素材。
