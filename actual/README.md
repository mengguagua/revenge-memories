# 复仇与回忆 · 序章至第二章

当前版本 **0.4.0**，在本目录独立开发。正式世界图39据点/40路线、可操作序章、第一章7场战斗与第二章8场战斗已实现，共15场战斗。第二章包含F21—F26六个主线关卡、S21/S22两条支线，以及东群岛据点、招募、整备、剧情和海峡城收束。人物、头像和近景动作先复用《外传》，世界与战斗地形使用已选的朴素复古新素材。

运行：双击 `dist/RevengeMemories.app` 或 `运行游戏.command`；独立存档，不覆盖旧复刻。
