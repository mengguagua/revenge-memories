# 复仇与回忆 · 序章至第二章

当前版本 **0.2.2**，在本目录独立开发。正式世界图39据点/40路线、可操作序章、第一章7场战斗与第二章8场战斗已实现，共15场战斗。第二章包含F21—F26六个主线关卡、S21/S22两条支线，以及东群岛据点、招募、整备、剧情和海峡城收束。人物、头像和近景动作先复用《外传》，世界与战斗地形使用已选的朴素复古新素材。

运行：双击 `dist/RevengeMemories.app` 或 `运行游戏.command`；独立存档，不覆盖旧复刻。

0.1.x旧存档可继续使用，存档位置与名称保持不变。第一章结束后选择“开始第二章”，从风灯岛进入东队剧情；第一章真实成长、装备与阵亡保留，东队独立记录。更新后重新启动游戏。

0.2.2 修复ASCII加减号被显示成问号的问题，复用现有像素字形并保持原字距；人物卡、地形卡和截图已刷新。

0.2.1 完成两章两轮抽查：箱车和建筑碰撞与画面对应，人物/移动检查显示地形回避和移动消耗，押送所、旧塔、军港和海洞补充可守缺口及绕行路线。15张战场检查通过，实际抽样10关、11次通关，详细范围见[两轮抽查报告](docs/两章两轮抽查与战术优化.md)和[更新实机截图](reports/review-0.2.1/index.html)。旧版进行中战斗保留原布局；正常重试或整备重新进场后使用新布局。

第二章新增可复用船体、船舷、跳板、船舱、桅杆、灯塔、渔屋和事件船。场景分别呈现双舰甲板、礁岛、黑昼海灯岛、潮狩军港、断航古道与海洞。囚舱栏杆、开门后的缺口、放下的跳板和不可步行海面与通行规则对应；黑昼降低环境亮度，人物、航灯和文字保持可读。

第二章三轮验收分别记录规则与阻塞、实机视觉夹具、真实控制器输入试玩。最新真实试玩保留八关自然胜利及伤亡；F26经实际整备交换装备后重打，第24回合完成。完整范围和证据见[第二章交付与验收](docs/第二章交付与验收.md)。

0.1.1 显示与行走修正版：旁白使用完整文字区；人物对白含画像；据点使用参考工程16 tick/格的平滑移动与双帧步态。默认1280×720，移动端设为横屏，按窗口宽高扩展逻辑视口，像素等比整数缩放；原地图边界外补山林/海洋，不能行走。手机横屏画幅已模拟验证，尚未制作移动端安装包或真机验收。更新后需重新启动游戏，存档路径不变。

0.1.2 修复外围树丛/岩壁在场景交界处被切成半块的问题，改为绘制完整模块；10处据点、7张战斗地图、3个世界视角完成抽查。

0.1.3 自然地形修正版：新制完整成年松、幼松、雪松及高低峰岩；树丛改为疏密错落的固定群落，岩体改为断续弯曲的山脊，去除世界图直角林缘。10处据点、7个战场和正式世界图同步更新；道路、出口、建筑和角色保留避让。更新后重新启动应用生效。
