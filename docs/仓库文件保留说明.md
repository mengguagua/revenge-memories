当前开发入口是 `actual/scenes/main.tscn`，版本与已完成范围见 [actual/README.md](../actual/README.md)。根目录保留《外传》复刻参考工程；剧情以 `docs2/` 为准。当前完成序章和前两章，第三章尚未实施。

## 继续提交到 Git

- 运行代码、剧情与关卡数据、素材，以及资源旁的 `.import` / `.uid` 元数据。根目录和 `actual/` 的原版资源副本服务于两个独立工程；Git 对相同内容共用对象，不按重复目录盲删。
- `actual/source/`：生成源图、提示词、画风选择记录，以及 `natural-0.1.3`、`tactical-review` 中的地图基线。后两者是地图构建工具的输入，不能当作临时备份删除。
- 开发记录、问题结论、规则检查、验收汇总、正式截图画廊与行走动图。保留失败与验证限制，不把旧报告改写成新版本通过。
- 正式试玩检查点：`actual/reports/campaign/natural-*.json`、`actual/reports/chapter2/play/natural-*.json`。保留部署、战中物件、胜利和章末状态，供续接、截图和迁移检查使用。
- 第二章完整通关轨迹 `attempt-7.json` / `attempt-8.json`，以及两章两轮抽查的报告和输入存档。第一章旧尝试仍是部分 `--resume-*` 分支的输入，保留。

优先阅读 [开发记录](../actual/docs/开发进度.md)、[第二章验收](../actual/docs/第二章交付与验收.md)、[两章抽查与战术优化](../actual/docs/两章两轮抽查与战术优化.md)。第二章重试过程见 [精简索引](../actual/reports/chapter2/play/attempts-index.json) 和 [最终摘要](../actual/reports/chapter2/play/round3-summary.json)，无需反复展开整份单位快照。

## 留在本机，忽略 Git

- `.godot/`、`.reference/`、Python 缓存与虚拟环境、`dist/` 中可直接运行的应用。导入缓存和本地参考文件保留，避免重复导入与准备环境。
- `actual/reports/` 中测试反复覆盖的工作存档、探针存档、截图中间存档。
- 第二章 `attempt-1..6.json` 的早期详细轨迹，以及 `attempt-*-checkpoints/` 历史快照副本。失败原因、结果、累计输入数、原始 SHA-256 已提炼到上述精简索引；当前正式检查点仍在顶层并继续跟踪。
- 旧大图方案的原始截图、地标透明底检查大图和两章调整前的临时拼图。本机保留，需要时可对照；正式画廊及其引用图片继续提交。

忽略规则按用途列出，不使用 `reports/*.json` 或 `*-save.json` 之类一刀切规则，以免漏掉实际回放证据。再次生成的工作文件、逐帧截图和打包产物不会混入普通提交。

从 Git 索引移除 365 个派生/临时文件，原始内容合计 24,285,776 字节（约 23.2 MiB）；其中 110 个有排障价值的文件继续保留在本机。新增的精简索引和本文用于保留结论与维护背景。

本地逐项清单与清理前哈希在 `.cache/repository-cleanup-2026-10-15/plan.json`，不提交。旧详细记录也可从精简索引记载的 `source_commit` 恢复；本次不改写 Git 历史，因此不会立即缩小已有 `.git` 历史体积。

## 重建与复用

- 当前独立应用保留在 `actual/dist/RevengeMemories.app`。需重新打包或再次进行独立 PCK 检查时，先运行 `bash actual/tools/package_local.sh`；它会重新生成外层 PCK。参考工程的包由 `bash tools/package_local.sh` 重建。
- 行走原始帧由 `bash actual/tools/capture_campaign.sh res://tools/capture_display_fixes.gd` 重新捕获；此入口在启动前禁止窗口显示和获取焦点。不要直接启动可见 Godot 窗口截图。
- 新一轮试玩直接选正式检查点和最新报告接续。第二章旧编号重试需要前一编号的详细轨迹；这些原始缓存留在本机，新克隆可从记录的历史提交恢复。正常从第一章章末开始或从第 8 次记录继续不依赖早期缓存。
- 清理缓存前先查 `actual/tools/`、`actual/tests/` 的读取依赖。不要为清理而重跑全章节、全量重建地图，或覆盖正式试玩检查点。
