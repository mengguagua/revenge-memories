# 《火焰之纹章 外传》完整游戏流程

版本依据：本工程 Godot 原生复刻 0.6；整理日期：2026-10-13。本文包含完整剧透。

本文描述当前工程已经接入的流程、关卡和推进条件，供游玩、内容核对和后续验收使用。它不是逐关自然通关的验收证明，也不是固定回合数的战术攻略。敌军位置、增援和战果仍会随世界行动及实际操作变化。

## 一、先理解关卡编号

游戏由五章、阿尔姆与赛莉卡两条路线、世界地图、据点探索和战术战场组成。

- 下文的 `B01` 等表示战术地图 ID。第一场战斗是 `B01 拉姆森林`；真正的最后一战是 `B62 多玛祭坛决战`。
- `W49` 等表示世界地点 ID；同一地点可以先打战斗，再进入同名据点。例如南方要塞战场是 B04，据点入口是 W50。
- 世界地图 B01～B48 所在的地点并不都常驻敌军。纯通路也能因流动军队出现遭遇。
- B49～B80 包括洞窟、神殿、森林、塔和地下终章战场。B80 不是故事的最后一关。
- 第三、四章可以交替推进两队。沙漠、利盖尔和迷宫存在分支，不应把数据表的编号排序当成唯一行走路线。

流程标记：**主线**为推进故事所需的步骤；**支线**为招募、宝物、训练等可选探索；**条件遭遇**表示有敌军时发生战斗。

## 二、从开局到结局的总路线

1. **第一章「前往索菲亚！」**：阿尔姆在拉姆村加入解放军，穿过南方战场，攻下索菲亚城，与麦森交谈，切入赛莉卡篇。
2. **第二章「赛莉卡启程」**：赛莉卡离开修道院，渡海抵达索菲亚，与阿尔姆重逢；两人因解决战争的方式产生分歧，分头行动。
3. **第三章「解放战争」**：阿尔姆讨伐多哲并解救迪尔德；赛莉卡击败基斯、前往米拉神殿。先打开米拉备用水闸，再打开西侧水门，进入第四章。
4. **第四章「悲伤的大地」**：赛莉卡穿越亡者沼泽、迷失森林和多玛之塔，进入祭坛并受困；阿尔姆进入利盖尔，突破龙之火山口、击败鲁道夫，进入利盖尔城了解身世。
5. **第五章「重逢，然后……」**：阿尔姆与麦森进入多玛地下神殿，探索地下战场、取得法尔西昂，抵达祭坛；两队合军，击败多玛，观看全篇与人物结局。

## 三、操作与每场战斗的收尾

| 操作 | 键盘 |
|---|---|
| 行走、选择人物、移动光标 | 方向键 |
| 确认、交谈、继续文字 | Z / Enter / 空格 |
| 返回、取消未结算的移动 | X / Esc |
| 查看人物状态 | Tab / A |
| 世界、战场或据点的系统／队伍菜单 | S |
| 查看按键帮助 | F1 |
| 音乐开关 | M |
| 加速战斗动作 | 按住 Z / 空格 |

世界地图按白箭头指向的道路移动，抵达敌军或据点后确认进入。战场中选择未行动人物，移动，再选择攻击、魔法、交换或待机。胜利后读完经验、升级、战利品和剧情页面，选择「继续前进」。

据点内要站到人物或机关前方，并朝向目标确认。进入地点不等于完成该地点的故事：牢房人物、楼梯、备用水闸、塔内出口和祭坛触发点都可能需要继续探索。

普通战斗以敌军清空为胜利条件，特殊事件可让部分敌人撤离或整支部队投降。阿尔姆或赛莉卡在战场阵亡会导致败北。失败菜单可重试本关；重试回到本关开战状态，不会复活之前关卡已经阵亡的人。

## 四、第一章：前往索菲亚！——阿尔姆路线

### 4.1 拉姆村：正式出发之前

主线顺序如下：

1. 看完麦森的剑术训练开场。
2. 与卢卡斯交谈，得知索菲亚政变和解放军的处境。
3. 找麦森，得到他反对参战的答复。
4. 再找卢卡斯，阿尔姆决定代替麦森加入解放军，卢卡斯加入。
5. 分别找格雷、托宾、克里夫，可让三人加入。
6. 离开村子，前往拉姆森林。

招募三位村民属于可选动作，但队伍规模、职业选择和后续培养会因此改变；准备完整游玩时建议出发前完成。

### 4.2 第一场到索菲亚城门

| 推荐推进顺序 | 战场 | 过关及后续操作 |
|---|---|---|
| 第一关 | B01 拉姆森林 | 第一场正式战斗。利用卢卡斯承受攻击，给村民分配安全的击杀机会。胜利后继续前进。 |
| 第二关 | B02 盗贼森林 | 打通森林。可从这里转入盗贼神殿支线。 |
| 第三关 | B03 拉姆山谷 | 穿越山谷，注意狭窄地形的堵路和敌方射程。 |
| 第四关 | B04 南方要塞 | 打下要塞后进入 W50 同名据点，解救并招募克莱尔。 |
| 第五关 | B05 索菲亚南部一 | 向城堡继续推进。 |
| 第六关 | B06 索菲亚南部二 | 胜利后可进入 W51 解放军基地，完成招募和整备。 |
| 第七关 | B07 索菲亚城门 | 对抗斯雷达与多哲的替身。斯雷达倒下会使替身撤退；击倒替身则有另一段揭穿替身的事件。仍需处理留在战场的敌军。 |

**盗贼神殿支线（W80）**：从盗贼森林进入。内部对应 B55 洞窟战斗；找到被囚禁的希尔克，与她交谈招募。探索女神像、泉水等设施，可以为达到条件的村民转职。

**解放军基地（W51）**：进入洞窟内部，经过 B49 的遭遇区域，可找到解放军成员。与克莱贝交谈，由阿尔姆担任领袖；可招募福尔斯与派森。角色加入需要完成各自交谈，不会因只走进基地而全部自动获得。

### 4.3 第一章结束条件

进入 W52 索菲亚城，探索城内并沿楼梯进入上层房间，与麦森完成主线交谈。游戏进入第二章标题与记录进度流程，控制队伍改为赛莉卡队。

城门战中的多哲是替身；真正的多哲仍在第三章的堡垒。不要把这场胜利理解为已彻底结束叛乱。

## 五、第二章：赛莉卡启程——赛莉卡路线

### 5.1 修道院与诺瓦港

在 W53 修道院完成出发剧情，分别与洁妮、波伊、梅伊交谈招募。诺玛说明米拉失踪、土地失去收成的背景。离开修道院，经诺瓦墓地到 W54 诺瓦港；与塞巴交谈，邀请他保护队伍，并通过港口的乘船操作出海。

### 5.2 海上推进

| 推荐推进顺序 | 战场／地点 | 过关及后续操作 |
|---|---|---|
| 出海前第一战 | B08 诺瓦墓地 | 第二章在墓地放置章节遭遇军。击败魔物，再进入诺瓦港。 |
| 海上第一战 | B09 海上一 | 迎战海盗。船上空间有限，保护法术角色。 |
| 海上第二战 | B10 海上二 | 继续航行，注意敌方远程攻击。 |
| 海盗要塞战 | B11 海盗要塞 | 巴尔博、卡姆伊、雷欧以不可手动控制的友军参战。保护他们；击败达哈会使特定海盗逃走，其余敌人仍可能留场。 |
| 战后招募 | W55 海盗要塞 | 与存活的巴尔博、卡姆伊、雷欧分别交谈，正式编入队伍。 |
| 海上第三战 | B12 海上三 | 对付龙僵尸。圣光等魔物特效手段有用，但法术要付出生命。 |
| 可选绕行 | B13 海之神殿 → W56 海之神殿 | 海上三附近的神殿分支。击败守卫后探索内部，可遇 B50、B63，取得圣剑等资源并利用神殿设施。 |
| 海上第四战 | B14 海上四 | 回到主航路，向索菲亚港推进。 |
| 海上第五战 | B15 海上五 | 清除靠港前的敌军，抵达 W57 索菲亚港。 |

海之神殿是资源与训练支线，不要把它与第二章必须经过的五段主航线混为一谈。已清理的墓地和航路也可能受后来世界敌军影响。

### 5.3 索菲亚港与第二章结束

索菲亚港的帕奥拉与卡秋娅说明妹妹艾丝特被海盗带走。此时先完成信息交谈；两人的正式加入在第三章的港口招募事件中完成。

从港口前往索菲亚城门区域，再进 W52 索菲亚城。找到麦森，沿楼梯上去，与阿尔姆重逢。完整读完两人的争执和离别剧情，进入第三章。

从此两队分开行动：阿尔姆对抗军队、寻找被囚者；赛莉卡调查米拉神殿和饥荒。在世界菜单中可以「切换队伍」，各队保存自己的位置、成员与行囊。

## 六、第三章：解放战争——双路线协同

这一章可以穿插推进。两条路线各有战果，但章末的水闸需要配合；只让一队一路向前，可能会遇到合理的剧情封路。

### 6.1 阿尔姆路线：讨伐多哲、解救迪尔德

| 顺序 | 战场／地点 | 必要操作与可选内容 |
|---|---|---|
| 1 | B16 北方城门 | 索菲亚城北侧通路；没有固定常驻军，不要求凭空打一场。 |
| 2 | B17 索菲亚北部 | 迎战北方敌军，开始森林方向的推进。 |
| 3 | B27 索菲亚森林 | 清除森林军队。 |
| 4 | B28 森林村庄 → W64 森林村庄 | 战后进入村庄，与琉特交谈，得知妹妹被塔塔拉操纵。村内还有救援与托运相关支线。 |
| 5 | B29 多哲要塞 → W65 多哲要塞 | 这里是真正的多哲。牢中的玛蒂尔达处于危险中，要保护她；胜利后在据点交谈招募。 |
| 6 | B30 索菲亚森林二 | 继续北进，注意这段较大的敌军编组。 |
| 7 | B31 森林北部 | 打通水门前的道路。可绕入 W66 森林神殿，探索 B53 及女神像设施。 |
| 8 | B32 水门 → W67 水门 | **先击败塔塔拉，并让迪尔德活着。** 她会解除控制并离开敌阵；战后在据点交谈招募。若杀死她，就失去该招募分支。 |

阿尔姆打下水门后，还要找水门守卫。若米拉备用水闸未打开，守卫会拒绝直接放水，原因是单独开启会造成洪灾。此时切换到赛莉卡队完成对应主线。

### 6.2 赛莉卡路线：沙漠、基斯与米拉

| 顺序 | 战场／地点 | 必要操作与可选内容 |
|---|---|---|
| 1 | B18 索菲亚西部 | 第三章开始时赛莉卡侧的通路地点；没有固定常驻军。 |
| 2 | B19 索菲亚海岸 | 帕奥拉与卡秋娅的友军／救援事件发生在这一路段。保护她们，随后回索菲亚港完成正式招募。 |
| 3 | B20 山间墓地 → W58 山间村庄 | 向东推进；墓地的章节遭遇编组随随机选择变化，后来也可能受流动军影响。村内与阿特拉斯交谈，他为寻找被掳走的弟妹加入。 |
| 4 | B21 沙漠要塞 → W60 沙漠要塞 | 战后解救并招募杰西，了解索妮娅与迪恩互相牵制的局面。 |
| 5，二选一 | B22 沙漠北部，或 B23 沙漠南部 | 北部击败迪恩，之后可招募索妮娅；南部击败索妮娅，之后可招募迪恩。幸存者会撤往吉斯要塞，不能从这一分支同时招募两人。 |
| 6 | B24 吉斯要塞 → W61 吉斯要塞 | 击败盗贼王基斯，救出艾丝特，并招募沙漠分支的幸存者。探索并完成神殿修女的母亲遗物剧情，赛莉卡戴上王冠，承认公主身份。 |
| 7 | B25 通往米拉的山谷 | 返回山谷方向，打通神殿道路。可绕行 W59 龙之神殿，探索 B51、宝物及复活泉支线。 |
| 8 | B26 米拉神殿 → W63 米拉神殿 | 击败守卫神殿的米卡埃拉及魔物，入内了解米拉被鲁道夫封印。 |

W62 沙漠神殿是这一地区的额外探索入口，对应 B52。它不是沙漠分支中第二个必须击杀的角色关卡。

### 6.3 两座水闸：第三章真正的推进锁

1. 赛莉卡完成公主身份／王冠剧情，抵达米拉神殿。
2. 探索神殿地下的备用水闸房间，与守卫交谈。守卫认出王室标志并开启备用水闸。
3. 切换阿尔姆队，在已经打下的水门据点找守卫。
4. 守卫确认备用水闸已开，开启西侧水闸，完成排水剧情。
5. 进入第四章标题与记录流程。

排水后，阿尔姆可向利盖尔国境北进；赛莉卡可从米拉神殿内部的**北出口**进入亡者沼泽。神殿的世界地图入口和内部北出口承担不同用途。

**诺玛招募支线**：探索米拉神殿地下，由备用水闸房间通往相邻地下房间，找到追来的诺玛并交谈。他在这里加入，而非在多玛之塔。可以在离开神殿北进前一并完成探索。

## 七、第四章：悲伤的大地——北进、森林与两人的命运

### 7.1 赛莉卡路线：从米拉到多玛祭坛

| 顺序 | 战场／地点 | 推进方式与重要条件 |
|---|---|---|
| 1 | B43 亡者沼泽 | 从米拉神殿北出口进入。毒沼泽消耗生命；敌方祈祷师会召唤，不能只顾不断击杀召唤物。 |
| 2 | B44 沼泽墓地 | 沼泽路线中的章节遭遇战，编组随随机选择变化，后来也可能受流动军影响。 |
| 3 | B45 多鲁克要塞 → W74 多鲁克要塞 | 击败多鲁克并探索要塞后的道路，衔接迷失森林。 |
| 4 | B46 迷失森林／W75 迷失森林 | 世界地点与内部迷宫共同组成森林。B46 本身没有固定常驻军；内部另有 B78～B80 的遭遇区域。 |
| 5，重要支线 | W68 贤者村 | 在森林中找到村落，见哈尔克。赛莉卡请求他帮助阿尔姆，触发阿尔姆的勇者提升；村中还能取得朱达每四回合露出破绽的线索。 |
| 6 | B47 多玛之门 | 从森林出口回到世界路线，突破多玛之门。 |
| 7 | B48 多玛沼泽 | 向多玛之塔推进。若与朱达交战，要在第 4、8、12……回合利用可伤害窗口；无敌期间他仍可能反击。 |
| 8 | W77 多玛之塔；B59～B61 | 塔的三个战场分别位于不同楼梯／楼层段。每段打完回到探索，继续走楼梯；不能把胜利界面当成自动直达塔顶。 |
| 9 | 塔内与祭坛剧情 | 继续探索朱达引导的道路和祭坛，完成赛莉卡被捕／受困的主线事件。诺玛的招募在此前米拉神殿地下完成。 |

森林有循环出口与岔路。若只是训练或取宝，可能绕回入口；要继续主线，需要到达通往多玛之门的出口。贤者村由森林内部到达，世界地图上没有普通邻接道路。

赛莉卡首次到达多玛祭坛是**受困并切回阿尔姆队的故事阶段**，不是两队合军的最终战。该事件解除阿尔姆在龙之火山口一带的剧情封路；被捕期间不能自由切回赛莉卡队。

### 7.2 阿尔姆路线：利盖尔与鲁道夫

为保护吉克并完成招募，建议先走努伊巴巴馆支线，再打利盖尔平原。以下列出这条较完整的路线；不招募相关人物时可以选择较短的主线。

| 顺序 | 战场／地点 | 推进方式与重要条件 |
|---|---|---|
| 1 | B33 国境 | 从水门北上，进入利盖尔。 |
| 2，可选北东支线 | B38 利盖尔森林 | 由国境分路，朝恐山方向前进。 |
| 3 | B39 恐山 | 打通努伊巴巴馆前的区域；可进入 W70 恐山神殿及深处洞窟取宝、训练或使用泉水。 |
| 4 | B40 努伊巴巴馆 → W71 努伊巴巴馆 | 对付美杜莎等危险法术。战后进入据点解救并招募蒂塔。 |
| 5 | 返回国境 → B34 利盖尔平原 | **先救蒂塔**会使吉克一方以自动行动盟军身份对抗杰罗姆。保护吉克存活。 |
| 6 | W69 利盖尔村 | 战后与吉克交谈。他认出阿尔姆右臂印记后加入。未完成正确救援分支时，不能假定此招募仍可获得。 |
| 7 | B35 利盖尔山谷 | 继续穿过村庄以北通路；没有固定常驻军。 |
| 8 | B36 龙之火山口 | 龙僵尸及增援相关区域。若道路仍被剧情锁住，要推进赛莉卡的多玛祭坛事件。 |

### 7.3 第四章应完成的关键条件

- 赛莉卡侧：完成多玛之塔与祭坛受困事件。
- 阿尔姆侧：击败鲁道夫，进入城内完成麦森交谈。
- 推荐准备：完成哈尔克的阿尔姆提升，培养治疗者、整理道具、保留能在终局出战的治疗与终结成员。

阿尔姆已经到达封路处而赛莉卡仍在森林或塔中时，应继续赛莉卡路线；不能用反复清理同一批龙僵尸替代必要的剧情推进。

## 八、第五章：重逢，然后……——地下神殿与最后一战

### 8.1 利盖尔城内出发

与麦森交谈后，阿尔姆得知自己是鲁道夫的儿子阿尔拜因，也是利盖尔王室的继承人。接受第五章标题与记录流程，从城内楼梯进入多玛地下神殿。

### 8.2 地下战场与法尔西昂

地下神殿由走廊、传送点、楼梯、战场房间、宝物库与祭坛组成；房间网络有岔路，以下层名是资源名称，并非一条只准按数字走的走廊。

| 地下战场名称 | 战术地图 ID | 说明 |
|---|---|---|
| 多玛地下神殿第 1 层 | B75 | 地下入口之后的战场段。 |
| 多玛地下神殿第 2 层 | B76 | 通过相连房间继续探索。 |
| 多玛地下神殿第 3 层 | B77 | 与宝物库及其他通道相连。 |
| 多玛地下神殿第 4 层 | B72 | 宝物库另一侧的战场段。 |
| 多玛地下神殿第 5 层 | B73 | 通往更深处的连接战场。 |
| 多玛地下神殿第 6 层 | B74 | 与法尔西昂所在探索房间相连。 |

每次战胜后回到原探索位置，再实际行走到下一个出口。选择岔路时可能改变遭遇这些战场的顺序；不必为了编号连续而强行绕回已通过区域。

探索法尔西昂所在房间，完成赛莉卡受困的相关场景，再面对剑的拾取位置确认。若全队每个人都已携带道具，先整理出空手成员，才能取剑。取得后确认法尔西昂交给阿尔姆，或由最终实际出战的同伴携带、准备战中交给阿尔姆。

**取得剑、看过剑房剧情、已经把剑带入出战队伍，是三个不同状态。** 仅看完剧情不会自动完成取剑和装备。

### 8.3 祭坛前的最终整备

抵达多玛祭坛，完成必要的重逢／求救剧情，再进入决战触发区域。第五章在祭坛的队伍菜单中可以使用「双方整备」。

进入前核对：

1. 两队各自按顺序选取的前十名存活成员，就是最终实际部署成员；把重要人物排进该范围。
2. 让法尔西昂的携带者进入实际部署队伍，阿尔姆也必须出战；或者让能够使用吸血的角色进入实际部署队伍。
3. 法尔西昂放在行囊或后备成员身上，不等于已经具备终结手段。通过双方整备取出、交换或调整顺序。
4. 最终战无法按普通地图方式撤退。确认治疗、生命和道具后再入场。

当前原生版在入场前检查终结手段，准备不足会说明操作路径，并保留继续探索的入口。旧版已经进入无终结手段的最终战存档，可使用「返回准备（重置本战）」回到祭坛南侧；这会回滚本战，不保留本战收益。

### 8.4 最后一关：B62 多玛祭坛决战

两队在祭坛合军，每队最多十名存活成员，共同对抗朱达、多玛与魔物。赛莉卡队的受困生命状态会被保留，阿尔姆队按最终合军规则部署；开场不要假定所有人都满血。

- **朱达**：只在第 4、8、12……回合能被正常伤害；其他回合的保护不会阻止他反击。
- **多玛完整形态**：开战时 182 HP。以至少 52 HP 开始的一次交锋不能直接杀死他；规则会调整该次命中／必杀结果，而不是简单把 HP 锁定在 52。
- **多玛最终形态**：HP 低于 52 后拒绝普通武器和普通攻击法术。可用阿尔姆的法尔西昂，或实际能攻击的吸血，完成终结。
- **支援**：阿尔姆邻接存活的赛莉卡时可得到对应的强力攻击支援，但仍须遵守射程、生命和首领特殊规则。
- **真正结束条件**：多玛死亡触发全篇完成；清掉其他普通敌军不能替代这一条件。

胜利后依次阅读多玛遗言、全篇叙事和参战人物结局。未招募者不显示个人结局；阵亡者与同伴生死会改变后日谈。完成记录会保存，标题「继续游戏」可回到结局页面。

## 十、容易误解为卡住的推进点

| 现象 | 应核对的流程 |
|---|---|
| 拉姆村不能出发 | 是否完成卢卡斯 → 麦森 → 卢卡斯的参军顺序。 |
| 打赢索菲亚城门却不进入第二章 | 是否进入城内上层，与麦森交谈。 |
| 赛莉卡抵达索菲亚仍不进入第三章 | 是否走上楼梯并完成阿尔姆重逢剧情。 |
| 阿尔姆水门守卫不肯放水 | 赛莉卡是否先打开米拉神殿地下备用水闸。 |
| 米拉神殿外面看不到北方道路 | 是否从神殿内部北出口离开，且双水闸已开。 |
| 沼泽或森林打完没有自动换地图 | 战胜返回探索后，继续走实际出口、机关或楼梯。 |
| 龙之火山口反复出现敌军、路仍不通 | 赛莉卡是否完成祭坛受困事件。 |
| 不能切回赛莉卡队 | 被捕期间是主线约束，要继续阿尔姆路线。 |
| 鲁道夫倒下后敌人还活着 | 该关按指挥官死亡触发胜利，其余部队投降。 |
| 宝剑在眼前却没有取得 | 是否面对宝物确认，且存在空手的存活成员。 |
| 最终祭坛拒绝入场 | 是否把法尔西昂或吸血使用者安排在真实出战范围内。 |
| 最终战普通攻击不再伤害多玛 | 已进入低于 52 HP 的最终形态，换终结手段。 |
| 胜利后停在升级或战利品页 | 继续确认页面，处理物品选择，最后选择继续前进。 |

这些是已接入的规则与剧情条件。如果已完成对应条件仍不能继续，应保存具体位置和操作作为缺陷证据，而不是反复重打前面的关卡。
