# 外传 · Godot 原生复刻 0.6

以原版素材复刻《火焰之纹章 外传》的两条路线和五章内容。当前是**全篇可玩测试版**：从开篇到最终战、人物结局的流程已接入；玩法由 GDScript 实现，运行时不读取 ROM，不运行 NES 模拟器。

## 启动与旧存档

macOS 打开 `dist/FE2Campaign.app`，或双击 `运行全篇.command`。窗口标题带 `0.6`。原来的 `dist/FE2Opening.app` 保留为0.5版；`运行首战.command`仍可用本机Godot运行当前工程。

新版沿用同一个本机存档位置 `user://opening_and_ram_woods.json`，兼容旧版首战/第二战存档。首次读取v1/v2存档会在同目录保留`.v1.bak`/`.v2.bak`，保存后升级为v3。请关闭旧游戏再使用新版，避免两个版本同时写同一个存档。重试恢复本关开战快照，保留此前成长与阵亡，撤回当前关的经验、掉落、剧情旗标和战场变化。

## 本版覆盖

- 双路线、五章、80张原战术地图、80个世界地点、原版据点与迷宫连接。战场ID和据点ID分别管理。
- 原始敌军编组、阵形、地形、移动与回避；世界增援、封路、路线切换与最终合军。
- 全篇已提取的中文对白、战斗事件、死亡对白与分支人物结局。原文和源地址保留在数据中。
- 据点行走、正前方交谈、招募、宝箱、泉水、复活、转职、信使、登船、机关与迷宫进出。
- 物理/魔法攻击、武器射程、反击与追击、必杀、支援、恢复、传送、召唤、驱逐、敌方治疗/分裂/震击。
- 装备与特效、战中邻接交换、战利品替换/存仓、阵亡物品回仓、撤退及残兵继承。
- 经验、升级、职业成长、法术学习、过关经验；阵亡、救援、二选一招募、鲁道夫与多玛等特殊规则。
- 全职业原版地图/战斗形象、近景动作、投射物、法术、地图特效、头像及音乐音效。中文为12像素点阵字体，画面256×240整数放大。

HP每点一格，普通人物沿用原4×8像素格；大血量首领使用2×4像素格，完整展示多玛182HP。所有新增图片均由原版提取，无AI代绘。

## 操作

| 操作 | 按键 |
|---|---|
| 行走、光标、选择 | 方向键 |
| 确认、交谈、翻页 | Z / Enter / 空格 |
| 返回、取消移动 | X / Esc |
| 人物状态 | Tab / A |
| 系统/整备菜单 | S |
| 音乐开关 | M |
| 按键提示 | F1 |
| 加速战斗动作 | 按住 Z / 空格 |

鼠标可选择战场格子和菜单；右键返回。主要流程均支持键盘。

开篇先与卢卡斯交谈，找麦森，再找卢卡斯加入解放军；格雷、托宾、克里夫分别招募。离村后按世界地图白箭头方向走，确认进入战场或据点。胜利选择「继续前进」。第三章起世界菜单可「切换队伍」。据点仍需与人物交谈、探索出口和触发机关推进剧情；米拉神殿的北出口连接后续路线。

战场选择人物、移动，再选择攻击/魔法/交换/待机。白魔法消耗生命，不能以施法耗尽自身HP；召唤幻影和非受控友军在己方结束时自行行动。自动进攻是辅助操作，不保证成员生存。

## 验证范围

无窗口测试覆盖规则、保存兼容与损坏数据拒绝、特殊事件、全部地图部署、重试与奖励幂等。实际main控制器/剧情VM测试经过全部80张战术地图的进入、结算和返回，覆盖四次分章、祭坛捕获切换、最终合军、结局及继续游戏。前两战另有未修改敌人属性的自然自动战斗验证。

**这些检查不等于后续每一关都已逐场自然实战通关。** 交付前另以启动前禁止窗口/抢焦点的保护程序运行后台SubViewport截图，检查文字、血格、肖像、法术与菜单安全区。

主要报告：`reports/campaign-continuity-audit.json`、`reports/campaign-runtime-verification.json`、`reports/full-campaign-flow-verification.json`、`reports/campaign-visual-verification.json`、`reports/full-battle-controller-verification.json`、`reports/full-delivery-verification.json`。

2026-10-13两轮抽查修复了战斗子菜单取消后卡住、迷宫返程机关无法再次触发、免疫首领丢失反击、切换队伍残留战场、被捕队伍仍可切换、最终结局重复结算，以及暗黑剑反噬的受击反馈。军队现有独立身份：同模板两军可共存，伤亡、撤退与胜利清理分别管理；旧地牢存档的伤亡不会迁到同模板世界军，新地牢遭遇按原版重建编制，读取存档与重试则保留当前编制。新增存档预检会拒绝损坏结构和身份错配，读取失败不覆盖当前状态。自身防御完全抵消暗黑剑反噬时，正常伤害与必杀仍保留。最新回归、后台截图和交付汇总见`reports/spot-round2-regression.json`、`reports/spot-visual-verification.json`及`reports/spot-review-completion.json`。

## 与原版的已知差异

- 世界援军以世界行动调度，未复现NES每一帧的移动随机时序。旧版未保存独立身份时已经合并的历史伤亡，迁移时无法还原各军真实归属；按当前战场优先迁到单支军队，不复制到同模板其他军队。
- 战术AI保留源模式、目标评分、概率和特殊行为；同代价路径的前驱/平局次序未与原版完全一致。原版随机算法已使用，但原生帧时序不同，不能与NES操作录像逐帧对齐。
- 地图特效使用原OAM姿势、节拍和音效；共享10分频器从完整相位起播，可能比某些原版相位长0～9帧。NES强调色以固定RGB近似，未模拟模拟视频信号/逐扫描线PPU。
- 原音乐/音效离线渲染为Ogg，调度保持原请求，但声道抢占和瞬时混音不逐条模拟。
- 标题剑旋转、部分转场、中文菜单排版、世界镜头和结局呈现为原生适配，尚非逐像素1:1。
